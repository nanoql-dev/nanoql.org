# Security

## Reporting a vulnerability

Please report a vulnerability privately, never in a public issue:

- through GitHub's private vulnerability reporting, on nanoql's repository:
  [report a vulnerability](https://github.com/nanoql-org/nanoql/security/advisories/new); or
- by email to security@nanoql.org.

Say what is affected, how to reproduce it, and the impact as you see it. We aim to acknowledge a report within two
working days, and to fix a confirmed vulnerability as quickly as its severity requires. A fix is published with a
GitHub security advisory, and a CVE where one applies; we credit the reporter unless asked not to.

A wrong numerical result is a bug rather than a vulnerability: please report it as an
[issue](https://github.com/nanoql-org/nanoql/issues), unless it can be exploited.

## Supported versions

Until 1.0, fixes go into the latest 0.y release only.
