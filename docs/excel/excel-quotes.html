nqlEurodollarFuturesImpliedStdDevQuote

Initializes a new instance of the EurodollarFuturesImpliedStdDevQuote class.

Argument Description
forward The futures price, 100 less the rate forward (a number)
callPrice The call's price, read where the rate strike isn't above the rate forward (a number)
putPrice The put's price, read where the rate strike is above the rate forward (a number)
strike The strike, 100 less the rate strike (a number)
guess Optional. The solve's starting point (a number)
accuracy Optional. The solver's accuracy (a number)
maxIter Optional. The solver's maximum number of evaluations (a whole number)

Returns handle. C#: EurodollarFuturesImpliedStdDevQuote

Argument Description
self a EurodollarFuturesImpliedStdDevQuote handle
