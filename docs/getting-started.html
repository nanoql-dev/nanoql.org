Getting started

nanoql is a .NET 10 library, and Python, C and C++ reach it through its C interface (in Python below). From C#, add its package to a project:

dotnet add package NanoQL

The conventions' XML format and QLNet's additions are in a second package, NanoQL.Extensions (conventions.md); a first price needs only the first.

A first swap

Price a five-year SOFR swap on a flat curve. The evaluation date goes in an EvaluationContext, the curve and the swap are values, and the engine is a static function of them:

var today = new Date(15, Month.October, 2026);
var context = new EvaluationContext { EvaluationDate = today };
var curve = new FlatForward(today, 0.036, new Actual365Fixed());

OvernightIndexedSwap swap = new MakeOIS(new Period(5, TimeUnit.Years), new Sofr(curve))
    .WithFixedRate(0.036)
    .WithNominal(10e6)
    .ToOvernightIndexedSwap(context);

OvernightIndexedSwapResults result = DiscountingSwapEngine.Calculate(swap, context, curve);

The results:

NPV Fair rate
7,041.24 3.6154%

MakeOIS takes QuantLib's defaults for every option it isn't given: here, SOFR's own calendar and day count, annual payments, and two settlement days. DiscountingSwapEngine.Calculate returns a results record, whose NPV, FairRate and each leg's LegNPV and LegBPS are read like any other property. The same inputs give the same results, on any thread.

In Python

pip install nanoql

It needs Python 3.11 or later, on Windows x64 or Linux x64, and no .NET runtime (which platforms). The same swap:

import datetime

from nanoql import ConventionSet, DiscountingSwapEngine, EvaluationContext, FlatForward, MakeOIS, Period, TimeUnit

today = datetime.date(2026, 10, 15)
context = EvaluationContext(today)
qs = ConventionSet.quant_lib()
curve = FlatForward(today, 0.036, qs.day_counter("Actual365Fixed"))

swap = (MakeOIS(Period(5, TimeUnit.Years), qs.overnight_index("Sofr", curve))
        .with_fixed_rate(0.036).with_nominal(10e6)
        .to_overnight_indexed_swap(context))

result = DiscountingSwapEngine.calculate(swap, context, curve)
print(f"NPV {result.npv:,.2f}, fair rate {result.fair_rate:.4%}")

It prints NPV 7,041.24, fair rate 3.6154%, the C# example's results. In Python a preset such as SOFR or Actual/365 (Fixed) comes from ConventionSet.quant_lib() by name, where C# constructs its class.

That swap, a bootstrapped SOFR curve, €STR and Euribor curves with their swaps, a SABR smile, an American put and a CDS run in a notebook you can open in Google Colab, with nothing to install; locally, pip install nanoql jupyter matplotlib runs it. The bindings guide gives the Python layer's rules.
