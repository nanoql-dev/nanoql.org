Calibrates the model to a set of instruments: QuantLib's calibrate, returning the calibrated model, of the receiver's type, with QuantLib's record of the calibration.

public static CalibrationResults<TModel> Calibrate<TModel>(this TModel model, IEnumerable<CalibrationHelper> helpers, OptimizationMethod method, EndCriteria endCriteria, EvaluationContext context, Constraint? constraint = null, ReadOnlySpan<double> weights = default, ReadOnlySpan<bool> fixParameters = default) where TModel : ICalibratedModel

Type Parameters

TModel

The model's type.

Remarks

QuantLib's sequence and counts: the checks of the helpers, the weights and the flags, in that order; the projection of the fixed parameters and the projected constraint; the minimization of the square root of the weighted sum of the squared calibration errors, each evaluation pricing the helpers against a new model built from its trial parameters; the model built from the optimum; and one more evaluation of the cost function's values for the problem values, which the count of function evaluations includes, as QuantLib's does.

QuantLib's writes the trial parameters, and then the result, into the model, whose helpers' engines hold it, and keeps the record in the model; here the receiver never changes, and the helpers price against the model they are given.

Exceptions

ArgumentNullException

An argument but the constraint is null.

ArgumentException

No helper is given, or a null one; the weights aren't one per helper; the flags aren't one per parameter; or every parameter is fixed.

NanoQLException

The optimization or a helper's pricing fails.
