Remarks

Each strike is stripped on floors up to the last floor strike and on caps above it. Its first volatility is solved by Brent, between 0.001% and 8% to 1e-7, so that a linear curve from the surface's base date to a week past its first maturity, sloping by the slope in proportion to its level, prices the first maturity's quote; then a piecewise curve starting at that level less the slope's change over the first maturity's time is bootstrapped on a helper per maturity, each an integer number of years long, over a strike range of ±0.1% of the strike (at least 0.002%). The instruments read a generic year-on-year index on the surface's year-on-year curve, with the surface's lag and frequency, observed flat.

QuantLib's generic index takes the empty currency, which nothing reads; nanoql's inflation indexes take a currency, so it takes the surface's index's. QuantLib binds each helper to a constant volatility at the first level before the bootstrap, which only sets the shared engine's volatility that the bootstrap then resets; here each trial passes its own volatility, so the binding isn't made.
