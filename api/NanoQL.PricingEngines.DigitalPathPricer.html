Remarks

A working type, as in QuantLib: it draws a new uniform sequence for each path it prices, from a copy of the generator it is given. References: Beaglehole, Dybvig and Zhou, "Going to Extremes: Correcting Simulation Bias in Exotic Option Valuation", Financial Analysts Journal, Jan/Feb 1997; El Babsiri and Noel, "Simulating path-dependent options: A new approach", Journal of Derivatives, Winter 1998.

Two documented divergences. A step's crossing probability reads the volatility at the step's start, (t_i, S_i), where QuantLib reads it at the step's end time, diffusion(timeGrid[i+1], S_i), whose comment calls it the initial one (Divergences/McDigitalStepVolatilityTests.cs): the same on a volatility constant in time. And crossings count from the exercise window's opening, a path already past the strike there paid at it, where QuantLib counts them from the start (Divergences/McDigitalWindowTests.cs); a window open from the start is QuantLib's.
