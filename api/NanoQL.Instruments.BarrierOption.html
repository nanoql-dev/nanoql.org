Remarks

An extension point, as in QuantLib: the quanto barrier option derives from it. A knock-out pays its rebate when the barrier is hit, a knock-in at expiry when it never was. Dividends are an engine argument, as in QuantLib 1.44.

Remarks

The solve prices through the analytic engine as nanoql fixes it (a negative rebate priced, each rate on the volatility's clock, a knock-out's rebate under negative rates integrated), so it moves where those fixes move the price. QuantLib's warning: the result is consistent only with prices from the same engine.
