Class FourierIntegration

Namespace
NanoQL.Numerics
Assembly
NanoQL.dll

The Fourier integration of characteristic-function pricing engines: a quadrature or an adaptive integrator, with the change of variables that maps the semi-infinite integration range onto the domain the algorithm expects. The decay rate c_∞ of the characteristic function along the integration contour drives the mapping.
