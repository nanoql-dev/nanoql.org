Class GaussJacobiPolynomial

Namespace
NanoQL.Numerics
Assembly
NanoQL.dll

The Gauss-Jacobi polynomial, with weight w(x; α, β) = (1 − x)^α·(1 + x)^β on [−1, 1], α, β > −1. Unsealed: QuantLib's Legendre, Chebyshev and Gegenbauer polynomials derive from it.
