Remarks

A static class: Calculate runs QuantLib's four steps (playbook §2.1) and returns the swaption's results, with QuantLib's eleven additional results, read by Result<T>(string). The engine assumes that the exercise date lies before the start date of the passed swap, and fully supports an overnight-indexed underlying.

QuantLib's constructors on a volatility value and on a quote coincide once a quote is a double: the overload on a double builds, at each call, the constant volatility QuantLib's builds, on no calendar and with its reference date the context's evaluation date. Its day counter defaults to QuantLib's, Actual365Fixed, for null; QuantLib's empty day counter, which fails at the volatility's first conversion of a date to a time, has no spelling.
