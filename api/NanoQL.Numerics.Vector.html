A 1-D array used in linear algebra: QuantLib's Array, renamed. It implements the concept of a vector as used in linear algebra, and is not meant to be used as a container.

Remarks

A working type: mutable, owned by one computation and not thread-safe, as an array is. The indexer sets elements, and the compound assignments (v += w, v *= x, ...) change the vector in place, so every reference to it sees the change; the binary and unary operators return new vectors. Clone() is the deep copy, where QuantLib copies an Array by value. v += x and the other operations with a scalar apply it to every element; v *= w and the other operations with two vectors work element by element, and need vectors of the same size.

A collection expression builds one, as QuantLib's initializer list does: Vector v = [1, 2, 3];. QuantLib's iterators are AsSpan() and GetEnumerator(), and its reverse iterators (rbegin(), rend()) indexed loops run backwards.
