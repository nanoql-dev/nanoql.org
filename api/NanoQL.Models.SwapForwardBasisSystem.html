The quadratic basis functions in the next forward rate x, the coterminal swap rate after it y and the discount ratio to the last rate time z at each exercise: 1, x, y, z, xy, yz, zx, x², y², z²; at an exercise on the second-to-last rate, 1, x, the last forward y, x², xy, y²; on the last, 1, x, x².

Remarks

A working type.

Each exercise's number of functions follows its own rate (a documented divergence): QuantLib adjusts only the last exercise's count (swapforwardbasissystem.cpp:53, :56), so an earlier exercise in the last periods reports 10 functions where Values(CurveState, Span<double>) gives 6 or 3 (Divergences/BasisSystemFunctionCountTests.cs).
