The stochastic collocation inverse cumulative distribution function: an inverse cumulative function approximated by a Lagrange polynomial in a standard normal deviate, collocated at the Gauss-Hermite nodes.

Remarks

References: L.A. Grzelak, J.A.S. Witteveen, M.Suárez-Taboada, C.W. Oosterlee, The Stochastic Collocation Monte Carlo Sampler: Highly efficient sampling from “expensive” distributions, http://papers.ssrn.com/sol3/papers.cfm?abstract_id=2529691.

Immutable: the nodes, their scale and the collocated values are computed once, at construction, where the inverse cumulative function given is called once per node.

Parameters

invCDF Func<double, double>

The inverse cumulative distribution function to approximate.

lagrangeOrder int

The number of collocation points, at least 1.

pMax double?

The probability the largest node collocates, or null; the nodes are scaled so that it does.

pMin double?

The probability the smallest node collocates where pMax is null, or null; with both null the nodes are the standard normal's.
