The Longstaff-Schwartz path pricer for early-exercise options (Francis Longstaff, Eduardo Schwartz, 2001, "Valuing American Options by Simulation: A Simple Least-Squares Approach", The Review of Financial Studies, Volume 14, No. 1, 113-147): in its calibration phase it stores the paths it is given and pricing nothing; Calibrate() regresses the continuation values backwards over them; in its pricing phase it prices each path, exercising where the exercise value beats the regressed continuation.

Remarks

A working type and an extension point, as in QuantLib: a Longstaff-Schwartz engine builds one per calculation, its stored paths, regression coefficients and exercise statistics the calculation's own, and PostProcessing(int, IReadOnlyList<TState>, IReadOnlyList<double>, IReadOnlyList<double>) is QuantLib's protected hook. Each calibration path is copied, since a path generator's path is a view of its buffer.

The pricer exercises only at the grid's exercise times, given beside the grid, and at its last time; QuantLib's exercises at every time of the grid, so a Bermudan option on a grid with steps between its dates, or an American option whose exercise window opens later, prices as an American option exercisable throughout: a documented divergence (Divergences/LongstaffSchwartzExerciseTimesTests.cs). Where every time of the grid is an exercise time, the bits are QuantLib's.
