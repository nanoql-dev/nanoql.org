PseudoSqrt(Matrix, SalvagingAlgorithmType)

The pseudo square root of a real symmetric matrix: the matrix S such that S·Sᵀ = M. If the matrix isn't positive semi-definite, it can return an approximation of the pseudo square root using a salvaging algorithm.

public static Matrix PseudoSqrt(Matrix matrix, SalvagingAlgorithmType sa = SalvagingAlgorithmType.None)

RankReducedSqrt(Matrix, int, double, SalvagingAlgorithmType)

The rank-reduced pseudo square root of a real symmetric matrix: the result has rank ≤ maxRank. If maxRank is at least the size, the given share of the eigenvalues out of the eigenvalues' sum is retained. If the matrix isn't positive semi-definite, it can return an approximation using a salvaging algorithm.

public static Matrix RankReducedSqrt(Matrix matrix, int maxRank, double componentRetainedPercentage, SalvagingAlgorithmType sa)

Parameters

matrix Matrix

The matrix, symmetric.

maxRank int

The largest rank, at least 1.

componentRetainedPercentage double

The share of the eigenvalues' sum to retain, in (0, 1].

sa SalvagingAlgorithmType

The salvaging algorithm: None, Spectral or Higham.

Returns

Matrix

A new matrix of the matrix's rows and as many columns as the factors retained.

Remarks

A retained eigenvalue below 0, which None accepts down to −1e-16 and Higham's adjusted matrix keeps to its projections' tolerance, contributes a zero column, its root floored at 0 as Spectral's is: a divergence, QuantLib taking its square root, a NaN column that leaves the others unnormalized. The result equals QuantLib's root at the rank that keeps the non-negative eigenvalues, with zero columns appended.

Exceptions

ArgumentOutOfRangeException

sa isn't one of the three, componentRetainedPercentage is outside (0, 1] or maxRank is below 1.

ArgumentException

matrix isn't square, is empty, or has a negative eigenvalue where sa is None.
