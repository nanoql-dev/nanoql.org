The triangular angles parametrization of correlation matrices (Rapisarda, Brigo and Mercurio, "Parameterizing correlations: a geometric interpretation"): a pseudo-root of the correlation matrix whose rows are unit vectors in spherical coordinates.

Remarks

QuantLib's general parametrization checks its angles' count against the rank's formula, which holds for a rank from 1 to the matrix's size, and at size + 1, whose count and loops are rank size's, so its matrix is rank size's; beyond, and for a matrix of size 0, it writes or reads outside its arrays, and its LMM form reads its angles unchecked. Those are refused here.

TriangularAnglesParametrization(Vector, int, int)

The triangular angles parametrized pseudo-root (equation (24)): row i is cos(θ) times the sines of the row's earlier angles, to the rank, its last element the sines' product.

public static Matrix TriangularAnglesParametrization(Vector angles, int matrixSize, int rank)

Parameters

angles Vector

The angles, (rank − 1)·(2·size − rank)/2 of them.

matrixSize int

The matrix's size, at least 1.

rank int

The rank, from 1 to matrixSize + 1, rank size + 1 giving rank size's matrix.

Returns

Matrix

The pseudo-root, a new matrixSize square matrix.

Exceptions

ArgumentNullException

angles is null.

ArgumentOutOfRangeException

The size is below 1, or the rank is outside [1, size + 1].

ArgumentException

The angles' count doesn't match the size and rank.
