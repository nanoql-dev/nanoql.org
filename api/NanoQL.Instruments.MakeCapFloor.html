Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToCapFloor(EvaluationContext) builds the instrument, in place of QuantLib's conversion operators. The leg is the floating leg of the MakeVanillaSwap the builder holds, built at 0% with a yearly Actual/365 (Fixed) fixed leg, which only spares that builder its currency's default fixed tenor; the first caplet is excluded unless a forward start or the effective date's flag keeps it, and an optionlet keeps the last coupon alone.

With no strike, the instrument is struck at the money: at the leg's at-the-money rate on a discount curve, at the curve's reference date and without the flows paid on it. QuantLib reads that curve out of the Black or Bachelier engine given to withPricingEngine; an engine here is a function, which hides its curve, so the builder takes the curve itself through WithDiscountingTermStructure(YieldTermStructure?), which computes the strike and is never stored. WithPricingEngine(Func<CapFloor, EvaluationContext, InstrumentResults>?) is kept and changes nothing: the instrument holds no engine. The strike comes before the instrument is built, so a Collar is refused by the instrument's constructor after the at-the-money rate, as QuantLib refuses it. A builder has no value equality.

An option the builder isn't given that QuantLib's builder fixes takes the builder's provider's default (Defaults(ConventionProvider)), read when the instrument is built: QuantLib's values with nothing configured.
