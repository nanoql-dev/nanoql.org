Remarks

A working type: each draw changes it, it isn't thread-safe, and its draws are views of its own buffers, valid until its next draw, allocating nothing. Both seeds are explicit, in [1, 4294967295] (QuantLib's defaults are 42 and 43); the scrambling seed feeds the Mersenne twister, where 0 would draw from the clock. Unlike SobolRsg, it takes two seeds, so it offers no Create(dimension, seed).
