Remarks

Immutable, its twiddle factors computed at construction by QuantLib's double-angle recursion (accurate to about 3e-11 relative at order 18). The transforms write into a caller's span of at least OutputSize points, the input in bit-reversed order at the first positions and the rest left as the caller gave them, as QuantLib's iterators do, so a shorter input is zero-padded where the caller's span is zero.

A documented divergence (the playbook's undefined-behaviour row): an input longer than 2ᵏ points is refused before anything is written, where QuantLib writes past the output's end and then refuses.
