Remarks

It copies its inputs, as every Interpolation does; its barycentric weights depend on the x values alone. The x values must not repeat, which QuantLib checks only under its extra safety checks.

At a node the value is the node's y. QuantLib finds the node by a binary search for the first x not below x − 10ε|x| and returns its y when that x is less than 10ε|x| above (lagrangeinterpolation.hpp:114-120): at x = 0 the band is empty, so a node at zero falls through to the barycentric sum, which divides by zero, and on descending x values (QuantLib's own Chebyshev-points test gives them) the search never lands on a node, so every node's value is NaN. Here the band is closed and the nodes are scanned in order: on ascending x values the node is QuantLib's, and the value off the nodes is QuantLib's on any order. Documented divergences (Divergences/LagrangeZeroNodeTests.cs).
