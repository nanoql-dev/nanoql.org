ExponentialCorrelations(ReadOnlySpan<double>, double, double, double, double)

The exponential correlation of the forwards alive at a time: L + (1 − L) exp(−β |(tᵢ − t)^γ − (tⱼ − t)^γ|), with L the long-term correlation, β the decay between far-away forwards and γ the exponent of the time to go.

public static Matrix ExponentialCorrelations(ReadOnlySpan<double> rateTimes, double longTermCorr = 0.5, double beta = 0.2, double gamma = 1, double t = 0)

Parameters

rateTimes ReadOnlySpan<double>

The rate times, strictly increasing and positive.

longTermCorr double

The long-term correlation, in [0, 1].

beta double

The decay, not negative.

gamma double

The exponent, in [0, 1].

t double

The time; a forward that has fixed by then has a zero row and column.

Returns

Matrix

A new matrix, one row and column per forward.

ArgumentException

An input is outside its range.
