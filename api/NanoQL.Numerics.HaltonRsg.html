Remarks

A mutable working type: each draw changes the generator, and it is not thread-safe. A draw returns a view of the generator's buffer, valid until its next draw.

The seed, in [1, 4294967295], is only used when randomStart or randomShift is true; QuantLib's seed 0, which there draws a seed from the clock, is refused. The counter and the random start add as QuantLib's unsigned longs do under MSVC, in 32 bits, so their sum wraps at 2^32.
