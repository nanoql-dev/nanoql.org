Remarks

An extension point, as in QuantLib. The optimizer copies its topology (Clone()) for each minimization, so each starts from its seeds, where QuantLib's continues from the last; it calls SetSize(int) and binds the copy to that minimization's swarm, which the protected members read and change. A topology sets GlobalBestX's positions in place.
