Remarks

All fixed coupons with a start date greater than or equal to the respective option expiry are considered part of the exercise into right, and so are all floating coupons; a redemption flow takes the start date of the regular coupon period with the same payment date. Cash-settled (par yield curve) swaptions are not supported. A compounded overnight coupon reads the model's compounded rate. The option-adjusted spread, continuously compounded on the model curve's day counter, discounts each flow from the exercise; the probabilities, an additional result, are QuantLib's.

Immutable, a BasketGeneratingEngine: Calculate(NonstandardSwaption, EvaluationContext) prices with the engine's model and parameters, and the static Calculate builds the engine for one call. The model reads a discount curve on another clock by date at every instant QuantLib derives from a date (an exercise's numeraire and the Digital probabilities' discount); flat payoff extrapolation's right tail reads the last node; and the calibration basket's initial guess refuses fixed nominals that are positive but none above 1e-8, over whose count QuantLib's average divides (#2845's class).
