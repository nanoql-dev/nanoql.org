Class OisDefaults

Namespace
NanoQL.Instruments
Assembly
NanoQL.dll

The defaults MakeOIS takes for an option it isn't given, on an overnight index, which ResolveOisDefaults(string, Func<OisDefaults>) returns: QuantLib's, its settlement days by the index's class. The calendars and the fixed leg's day counter are the index's, the payment calendar each leg's, the end-of-month flags the start date's and the lookback the index's fixing days, so they aren't defaults.
