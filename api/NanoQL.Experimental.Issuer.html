Remarks

Immutable. QuantLib's curve handles are the curves themselves; QuantLib's empty handle, which its first read refuses, is refused at construction.

The events are kept in date order, every one of them: two events on one date both count, in the order given. QuantLib's event set orders by date alone (issuer.hpp:36-38), so it keeps one event per date and drops the second, where its own documentation lets several events take place on one date. A documented divergence (Divergences/IssuerEventsOnOneDateTests.cs).
