Remarks

QuantLib's class implements both of its process families' discretization interfaces. A C# class has one base, so this one is a StochasticProcess1DDiscretization, declares the multi-dimensional members too, and converts implicitly to a StochasticProcessDiscretization that forwards to them: a multi-dimensional process is given new EulerDiscretization() as QuantLib's is.
