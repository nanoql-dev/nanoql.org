Remarks

A static class, as BlackSwaptionEngine is, with the same results; the engine assumes that the exercise date lies before the start date of the passed swap.

The overload on a double volatility keeps QuantLib's behaviour: its constructors pass their model to the base's four-argument constructor, where it lands in the displacement, so the volatility's shift is the model's integer, which a normal volatility never reads, and the cash annuity model is always DiscountCurve, whatever model is given.
