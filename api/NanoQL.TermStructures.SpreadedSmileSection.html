Remarks

Every inspector answers the underlying section's. QuantLib's spread is a quote; here it is its value, and a new spread is a new section. QuantLib default-constructs its base, so its converted volatility (Volatility(double, VolatilityType, double)) compares the type wanted with an uninitialized one; here the base is given the underlying's exercise time, day counter, type and shift, so it compares the underlying's type.
