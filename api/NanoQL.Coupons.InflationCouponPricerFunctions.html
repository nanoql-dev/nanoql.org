SetCouponPricer(ImmutableArray<CashFlow>, InflationCouponPricer?)

A leg with a pricer set on each of its inflation coupons; every other cash flow is kept as it is.

public static ImmutableArray<CashFlow> SetCouponPricer(ImmutableArray<CashFlow> leg, InflationCouponPricer? pricer)

Parameters

leg ImmutableArray<CashFlow>

The leg.

pricer InflationCouponPricer

The pricer.

Returns

ImmutableArray<CashFlow>

The new leg; this one is unchanged. All or nothing: a coupon refusing the pricer leaves no leg.

Remarks

QuantLib's setCouponPricer sets the pricer on the coupons in place, one after another, so a coupon refusing it leaves the earlier ones holding it, and its cast skips a null cash flow (inflationcouponpricer.cpp:27-34). Here the leg is immutable: the new leg is all or nothing, and a null cash flow is refused, as every nanoql leg refuses one, a documented divergence.

Exceptions

ArgumentException

An inflation coupon refuses the pricer, with QuantLib's "pricer given is wrong type"; or the leg holds a null cash flow, or is default(ImmutableArray).
