Remarks

Every inspector but AtmLevel() answers the source section's, and so do the volatility and the variance; the option prices are the base's formulas on the given level. QuantLib copies the source's base into its own; here the base is given the source's exercise time, day counter, type and shift, so its converted volatility (Volatility(double, VolatilityType, double)) compares the source's type, as QuantLib's copy does.
