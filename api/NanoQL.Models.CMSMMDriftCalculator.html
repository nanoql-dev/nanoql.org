Remarks

A working type: QuantLib's mutable scratch is the calculator's own, so it is owned by one computation and isn't thread-safe. The drifts' size is checked at every computation, QuantLib's extra-safety check.

A spanning of no forwards is refused: QuantLib's drifts then read each swap's cross variation from its own uninitialized entry, an undefined read (Divergences/MarketModelUndefinedReadsTests.cs).
