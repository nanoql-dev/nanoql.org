Remarks

A working type. Its own spanning's swap rates and annuities are set with it; the forwards, the coterminal swaps and another spanning's swaps are computed at each read into the state's own buffers, as QuantLib's are. A rate read at the number of rates, which QuantLib's index check admits and reads past its vectors, is refused with QuantLib's text.
