The xoshiro256** uniform random-number generator, of period 2^256 − 1. For more details see https://prng.di.unimi.it/ and its reference implementation https://prng.di.unimi.it/xoshiro256starstar.c.

Remarks

A mutable working type: each draw changes the generator, and it is not thread-safe. The correctness of the returned values is tested by checking them against the reference implementation in C.

Its seed is QuantLib's 64-bit std::uint64_t, taken as a long's 64 bits: unchecked((long)10108360646465513120UL) draws QuantLib's sequence for that seed. It is the one generator whose seed isn't confined to [1, 4294967295]; seed 0, which QuantLib reads as a seed drawn from the clock, is refused, and so is the all-zero state, from which the generator draws 0 forever.
