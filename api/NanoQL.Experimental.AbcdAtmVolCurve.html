Remarks

QuantLib's LazyObject computes at construction: QuantLib fits the abcd function when its constructor builds the interpolation and again at the first calculation, from the first fit's coefficients (update(), which checks no guess), so the curve fits twice, the second through AbcdInterpolation's internal refit. Quotes are values. QuantLib's moving reference date is the factory's, dated by the context. QuantLib's acyclic visitor isn't ported.
