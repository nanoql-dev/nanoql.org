The product A·x, one element per row of A.

The sparse matrix.

The vector, as long as A has columns.

Returns

Vector

A new vector with A's number of rows; zero in each row beyond the last row written to.

Remarks

QuantLib sizes the result by the columns and writes it by the rows (sparsematrix.hpp:51-69), so a matrix with more rows than columns writes past the result, undefined, and one with fewer pads it with zeros: an 8×4 matrix's product is a vector of 4. Here the result has a row's length; each row QuantLib computes is its value. A documented divergence.
