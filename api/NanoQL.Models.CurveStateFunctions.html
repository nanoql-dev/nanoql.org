ConstantMaturityFromDiscountRatios(int, int, ReadOnlySpan<double>, ReadOnlySpan<double>, Span<double>, Span<double>)

The constant-maturity swap rates and annuities of discount ratios, each swap spanning spanningForwards forwards (fewer near the end), from the first valid index on.

public static void ConstantMaturityFromDiscountRatios(int spanningForwards, int firstValidIndex, ReadOnlySpan<double> ds, ReadOnlySpan<double> taus, Span<double> constMatSwapRates, Span<double> constMatSwapAnnuities)

Parameters

spanningForwards int

The forwards each swap spans.

firstValidIndex int

The first swap computed, below the number of swaps.

ds ReadOnlySpan<double>

The discount ratios, one more than the swaps.

taus ReadOnlySpan<double>

The accrual periods, one per swap.

constMatSwapRates Span<double>

The swap rates written.

constMatSwapAnnuities Span<double>

The annuities written, one per swap.

Exceptions

ArgumentException

The sizes don't match.

ArgumentOutOfRangeException

spanningForwards is negative, or firstValidIndex is negative or not below the number of swaps.
