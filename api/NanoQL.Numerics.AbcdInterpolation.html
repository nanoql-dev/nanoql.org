Remarks

The fit runs when the interpolation is built: QuantLib's construction followed by its update(), which every QuantLib user calls at once. A new fit is a new interpolation, so update() isn't ported. A guess given as null takes QuantLib's default and is free, as QuantLib's Null<Real>(). QuantLib's abcd volatility curve calls update() a second time, a refit from the first fit's coefficients without the constructor's guess check; an internal refit gives it.

Immutable and thread-safe once built.
