Class RandomizedLDS

Namespace
NanoQL.Numerics
Assembly
NanoQL.dll

QuantLib's seed constructors of RandomizedLDS<TLds, TPrng>, which build its generators from seeds: C++ instantiates them only where a caller uses them, so each is a generic method here, with its own constraints. Its pseudo-random generator is QuantLib's default, a RandomSequenceGenerator<TRng>.

Create<TLds, TRng>(int, long, long)

Builds a randomized sequence over generators built from seeds (QuantLib's RandomizedLDS(dimensionality, ldsSeed, prsSeed), whose seeds QuantLib defaults to the clock's).

public static RandomizedLDS<TLds, RandomSequenceGenerator<TRng>> Create<TLds, TRng>(int dimensionality, long ldsSeed, long prsSeed) where TLds : class, ISeedableRsg<TLds> where TRng : class, ISeedableRng<TRng>

Parameters

dimensionality int

The dimension of each sequence.

ldsSeed long

The low-discrepancy sequence generator's seed, in [1, 4294967295].

prsSeed long

The pseudo-random generator's seed, in [1, 4294967295].

Returns

RandomizedLDS<TLds, RandomSequenceGenerator<TRng>>

The randomized sequence.

Type Parameters

TLds

The low-discrepancy sequence generator, which can be built from a seed.

TRng

The pseudo-random generator, which can be built from a seed.

Exceptions

ArgumentOutOfRangeException

dimensionality is out of the generators' range, or a seed is outside [1, 4294967295].
