A matrix used in linear algebra, stored by rows. It implements the concept of a matrix as used in linear algebra, and is not meant to be used as a container.

Remarks

A working type: mutable, owned by one computation and not thread-safe, as an array is. The indexer sets elements, and the compound assignments (m += n, m *= x, ...) change the matrix in place, so every reference to it sees the change; the binary and unary operators return new matrices. Clone() is the deep copy, where QuantLib copies a Matrix by value. The matrices of a sum or a difference need the same size.

QuantLib's iterators over the whole storage are AsSpan() and GetEnumerator(); its row iterators are Row(int), a span over a row's elements; its column iterators are Column(int), a copy of a column, and indexed loops; its reverse iterators (rbegin(), rend(), over the storage, a row or a column) are indexed loops run backwards. m[i][j] and m(i, j) are both m[i, j].
