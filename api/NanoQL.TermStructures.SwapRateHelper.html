Remarks

The helper builds its swap when it is constructed, through MakeVanillaSwap, so it reads the context's at-par switch then, which also moves the default pillar, the last relevant date, through the last coupon's fixing end date. A coupon pricer given is set on the swap's floating leg.

Bound to a curve, its copy holds a swap whose floating coupons are copies on a clone of the index on that curve, each keeping its pricer and so its at-par choice: QuantLib relinks the index's handle under the built swap. The swap is discounted on the curve, or on the discounting curve given. Its dates follow the evaluation date unless explicit start and end dates are given.

InitializeDates(EvaluationContext)

Computes the helper's dates for an evaluation date: QuantLib's initializeDates(). A helper whose dates follow the evaluation date overrides it and calls it from its constructor; the bootstraps call it on a fresh copy to re-date the helper for a curve built under another evaluation date. The base does nothing.
