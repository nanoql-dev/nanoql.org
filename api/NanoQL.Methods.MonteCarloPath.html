Remarks

Read-only to its users. A path built from a time grid and values copies them, and is immutable. A path a PathGenerator<TGsg> returns is a view of the generator's own path, valid until the generator's next draw, which changes it; a caller that keeps one copies it, as new MonteCarloPath(path.TimeGrid, [.. path]).

GetEnumerator() is QuantLib's begin() and end(). Its reverse iterators, rbegin() and rend(), are an indexed loop run backwards: for (int i = path.Length - 1; i >= 0; i--).
