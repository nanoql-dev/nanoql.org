The random spot recovery rate latent variable portfolio model: N. Bennani and J. Maetz, "A Spot Stochastic Recovery Extension of the Gaussian Copula", MPRA July 2009; H. Li, "Extension of Spot Recovery model for Gaussian Copula", MPRA October 2009; adapted to many factors and any copula. Its variables are the n names' defaults, then their n recoveries.

Remarks

Immutable: ResetBasket(Basket) returns a copy bound to a basket's live names, default row i with recovery row i + n kept, the live count the new n. A model parameter A of 0 is refused: the conditional recovery divides by it (spotlosslatentmodel.hpp:271-276). A default probability before a curve's reference date reads 0.

The conditional recovery is QuantLib's formula, whose documentation claims the single-name expected loss pdef·(1 − R) and which reads E[R | default] 0.361 for R = 0.40 at A = 0.8, at equal betas too: kept, recorded for revisiting.
