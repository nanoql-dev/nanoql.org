The uniform random-number generator of L'Ecuyer with added Bays-Durham shuffle (known as ran2 in Numerical Recipes). For more details see Section 7.1 of Numerical Recipes in C, 2nd Edition, Cambridge University Press (available at http://www.nr.com/).

Remarks

A mutable working type: each draw changes the generator, and it is not thread-safe. Its seed is explicit, in [1, 4294967295]: QuantLib's seed 0, which draws a seed from the clock, is refused.

It computes in 64 bits, as QuantLib's long does on Linux. On Windows, where QuantLib's long and the Python wheel's seed are 32 bits wide, a seed of 2^31 or above wraps to a negative one, which draws other numbers; the two builds agree on every seed below 2^31.
