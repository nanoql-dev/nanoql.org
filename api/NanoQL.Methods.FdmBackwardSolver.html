The backward solver of a finite-difference problem: rolls values back from maturity under the described scheme, after implicit Euler damping steps, applying the step conditions at every step.

Remarks

A working type. QuantLib builds its schemes and model at each rollback; the solver here builds them at its first rollback and reuses them, a scheme's state being only its step, which each rollback sets, and the buffers it holds, so a later rollback of the same size allocates nothing.
