Remarks

The target forward over the target tenor is a weighted sum of the base forwards over the base periods it covers; a target optionlet's normal variance is the weights' quadratic form in the base volatilities, at the base strikes the target strike maps to, under the correlation of the base forwards by their start times. The target tenor must be a whole number of base tenors.

A smile section is built per query, as QuantLib's, from the indexes' fixings and forecasts at the option date: its fixings are read in the context the structure was built with, which it keeps, since the smile-section and volatility queries take no context. The structure takes the base structure's reference date, calendar, convention and day counter.

A volatility is the smile section's at the strike, the range checked once, by the query with its own extrapolation flag (Divergences/TenorOptionletExtrapolationTests.cs). QuantLib's builds the section through smileSection(optionTime), which checks the range again without extrapolation, so a query allowed to extrapolate past the base structure's last date refuses: QuantLib's own testTenoroptionletvts asks for its 30-year caplets from the base structure's reference date, two business days after the evaluation date, and on QuantLib 1.44 refuses ("time (30.0219) is past max curve time (30.0137)") on every evaluation date of 29 October to 11 November 2026 but the two Wednesdays. On its test runner's date, 16 September 2015, a Wednesday, the case passes, so QuantLib's own run doesn't refuse. QuantLib's swaption structure builds its section unchecked, as here; where QuantLib's doesn't refuse, the value is its.
