Remarks

An option is given by its tenor from the reference date, its date or its time, and the swap by its tenor or its length in years, so each query has QuantLib's six overloads. A tenor's option date is the reference date advanced on the structure's calendar; a swap tenor's length is SwapLength(Period).

The smile sections pass the extrapolate flag as QuantLib does: those by an option time and a swap tenor, and by an option tenor or date and a swap length, check the query with the flag and then call the overload by option time or date and swap length without it, which checks the query again without extrapolating.
