Remarks

For n = 1 the method is linear interpolation with flat extrapolation. A missing value at a corner of the grid is the weighted mean of its neighbours along each direction, which generalizes Numerical Recipes' eq. 3.8.6: on linear data the corner reads 2.5 where the line says 1, the book's rule. Reference: Numerical Recipes, 3rd edition, ch. 3.8.

Solved at construction: the linear system by BiCGstab, once. A coordinate whose grid has a single point is left out of the system; with every coordinate left out, the value is the given one, or 0 where it is missing.
