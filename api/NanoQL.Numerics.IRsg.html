QuantLib's random sequence generator concept, the USG or RSG its templates take (InverseCumulativeRsg, PathGenerator): a generator of sequences of a fixed dimension, uniform or Gaussian, pseudo-random or low-discrepancy.

[WorkingType]
public interface IRsg

Remarks

A generator is a mutable working type: each draw changes it, and it is not thread-safe. A draw's sample is a view of the generator's buffer, valid until its next draw, which changes it; a caller that keeps one copies it. Construction from a seed in generic code is ISeedableRsg<TSelf>'s.
