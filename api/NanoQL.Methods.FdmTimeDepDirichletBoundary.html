A time-dependent Dirichlet boundary condition: on one side of one direction of the grid, the value a function of time gives at each step, one value for the whole side or one for each of its points, written into the solution after each application of the operator and each solve.

Remarks

A working type: SetTime(double) evaluates the function and holds its values for the step; the schemes call it in QuantLib's order. Its values before the first SetTime(double) are 0, where QuantLib's are uninitialized.
