MergeTimes(ReadOnlySpan<ImmutableArray<double>>)

The sorted union of sets of times, and for each set which of the merged times it holds.

public static MergedTimes MergeTimes(ReadOnlySpan<ImmutableArray<double>> times)

Parameters

times ReadOnlySpan<ImmutableArray<double>>

The sets, each sorted.

Returns

MergedTimes

The merged times, each once, and each set's presence over them.

Remarks

QuantLib's mergeTimes appends the merged times to the caller's vector and sizes each set's presence to the times before their duplicates are removed, its tail read past the merged ones; here the result is the merged times alone and each presence their size, which changes no value QuantLib's readers see, since they read it only below the merged count. QuantLib's sort of a NaN and its binary search of an unsorted set are undefined, and refused (Divergences/MarketModelUndefinedReadsTests.cs).

Exceptions

ArgumentException

A set holds a NaN, or isn't sorted.
