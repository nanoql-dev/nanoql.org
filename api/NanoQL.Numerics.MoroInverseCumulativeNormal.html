Moro's inverse cumulative normal distribution: given x between zero and one, the y whose cumulative normal probability, for average μ and standard deviation σ, is x. It uses the Beasley–Springer approximation in the central region, with an improved Moro approximation for the tails (Boris Moro, "The Full Monte", 1995, Risk Magazine).

Remarks

It also turns a uniform distribution into a normal one, keeping a low-discrepancy sequence's low discrepancy. Peter J. Acklam's approximation, InverseCumulativeNormal, is better.

A configuration struct: its zero value (default, new MoroInverseCumulativeNormal(), an unassigned field or array element) is QuantLib's default construction, the standard normal (μ = 0, σ = 1).
