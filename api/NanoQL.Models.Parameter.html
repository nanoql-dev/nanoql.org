Remarks

Immutable: SetParam(int, double) returns a copy, so a model whose parameters change is a new model. Its parameters start at 0, where QuantLib leaves an uninitialized array.

An extension point, as in QuantLib: the constant, null, piecewise-constant and term-structure fitting parameters derive from it, as later ports' models' parameters will, each with an Parameter.Impl that computes its value. QuantLib's public default constructor, which serves only containers, has no counterpart.
