Namespace

The type of a double barrier: QuantLib's DoubleBarrier::Type.

public enum DoubleBarrierType

Fields

KIKO = 2

The lower barrier knocks in, the upper one knocks out.

KOKI = 3

The lower barrier knocks out, the upper one knocks in.

KnockIn = 0

The option comes into existence when the underlying reaches either barrier.

KnockOut = 1

The option ceases to exist when the underlying reaches either barrier.

Remarks

QuantLib's stream operator writes "KnockIn", "KnockOut", "KI lo+KO up" and "KO lo+KI up", the last two not the members' names, so it is ToString(DoubleBarrierType).
