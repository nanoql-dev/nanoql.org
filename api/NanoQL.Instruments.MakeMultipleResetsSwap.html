Remarks

An immutable builder: each method returns a modified copy, and ToSwap(EvaluationContext) builds the swap under a context, in place of QuantLib's conversion operators. By default the fixed leg's frequency is the coupons' period, the index's tenor times the resets per coupon. With no fixed rate given, the swap is built at its par rate, priced by the engine set, or by DiscountingSwapEngine on the index's forwarding curve; the engine is never stored on the swap, where QuantLib's builder attaches it. A builder has no value equality. An option the builder isn't given that QuantLib's builder fixes takes the builder's provider's default (Defaults(ConventionProvider)), read when the swap is built: QuantLib's values with nothing configured.
