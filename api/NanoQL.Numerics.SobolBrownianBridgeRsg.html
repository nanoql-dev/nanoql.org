Remarks

A working type, as every IRsg: each draw changes it. Its seed is explicit, in [1, 4294967295], as SobolBrownianGenerator takes it: QuantLib's default 0 draws one from the clock. Every sequence's weight is 1. Clone() builds the generator again from its arguments and draws the paths this one has drawn, the Sobol sequence being deterministic, so the copy's next draw is this one's.
