Remarks

Immutable: it copies the values and the flags it is given. QuantLib's protected mapFreeParameters and its mutable copy of the parameters, which only a class deriving from both CostFunction and Projection reads, aren't ported: a class with one base composes a projection and calls Include(Vector), which computes the same values.

An extension point, as in QuantLib: Project(Vector) and Include(Vector) are virtual, and the fixed values, the flags and the number of free parameters are protected.
