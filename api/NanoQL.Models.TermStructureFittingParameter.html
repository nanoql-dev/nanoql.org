Remarks

Built on a curve, its implementation is a TermStructureFittingParameter.NumericalImpl, the values a tree fits as it is built: a fitted short-rate tree fills them during its construction, step by step, and reads them afterwards, so each tree owns its fitting and a built tree's fitting never changes.

An extension point, as in QuantLib: Hull-White's analytical fitting parameter derives from it.
