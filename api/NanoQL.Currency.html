Remarks

Immutable, and an extension point: each of QuantLib's currencies derives from it, and a user may add one. QuantLib's empty Currency(), a placeholder whose members throw, is a Currency? null.

Two currencies are equal when their names and their codes are, compared ordinally, whatever their other data; the hash is the name's. QuantLib's operator== compares names alone (currency.hpp:179-182), so its BGL and BGN, both named "Bulgarian lev", are one currency there: the code tells them apart, a documented divergence (Divergences/CurrencyNameAndCodeTests.cs). The equality is sealed, so every subclass compares the same way.
