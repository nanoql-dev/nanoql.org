The polar Student t random-number generator: Bailey's polar method ("Polar Generation of Random Variates With the t-Distribution", Mathematics of Computation 62-206, 1994), in the variant of "Random Number Generation and Monte Carlo Methods" (Springer, 2003, page 185), with uniforms remapped to [−1, 1] so that no draw sets the sign.

Remarks

A mutable working type (§2.7): each draw changes it, and it isn't thread-safe. A rejection method: not for a low-discrepancy generator. Its draws are raw Student t, of variance ν/(ν − 2). Its seed constructor is Create<TUrng>(double, long), a seed in [1, 4294967295] with no default, where QuantLib's defaults to 0, the clock.
