Remarks

A working type, as every discretized asset is. Its exercise reads the lattice's grid at each step through Grid(double, Span<double>) into a buffer it reserves at its widest step, where QuantLib's builds an array per step, so a rollback allocates nothing.

The American window is bounded by its two times compared with IsOnTime as well, upstream's fix after v1.44 (#2878): the grid's last time can be an ulp off the maturity the engine starts the asset at, where QuantLib 1.44's plain comparison skips the exercise at expiry, an American option then priced below the European one on the same tree, or rejects a window ending there (Divergences/AmericanBoundsOnTimeTests.cs).
