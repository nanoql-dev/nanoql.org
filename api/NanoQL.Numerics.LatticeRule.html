Remarks

QuantLib checks the number of points against 2.9^20, about 1.8e9, where its message and its tables say 2^20, so it accepts up to about 1.8e9 points; nanoql checks 2^20 (a documented divergence in Divergences/LatticeRsgTests.cs). As in QuantLib, the number of points needn't be a power of 2.

Exceptions

ArgumentOutOfRangeException

n is outside [2^10, 2^20], or name isn't a rule.
