Remarks

It doesn't suffer the numerical instability problem of IncrementalStatistics. The downside is that it stores all samples, thus increasing the memory requirements.

A working type: Add(double, double), Reset(), Reserve(int) and the sorting members change it, where QuantLib's sorts through mutable members of a const object; it isn't thread-safe. QuantLib's Statistics and RiskStatistics typedefs name this class with its Gaussian and empirical risk measures, which GaussianStatisticsExtensions and RiskStatisticsExtensions give it.

Where every sample a member averages weighs 0, the member refuses, with the text QuantLib's percentile gives a set of zero weight, where QuantLib's divides 0 by 0 and returns NaN; and a NaN sample can't be sorted, which QuantLib's percentiles do with a sort that NaN leaves undefined. Both are documented divergences.
