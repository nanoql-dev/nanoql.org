Remarks

The diffusion at a negative state is 0, the root of the state floored at 0, as HestonProcess's partial truncation takes its variance's: a divergence, QuantLib's σ√x being NaN there, so that an Euler path, which can step below 0, turns NaN for good (Divergences/SquareRootProcessTruncationTests.cs). The drift reads the state as it is, as the partial truncation's does.
