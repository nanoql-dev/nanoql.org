Remarks

Immutable: its breaks, counts and frequencies are computed once, at construction. The default construction is QuantLib's empty histogram, of 0 bins and the algorithm Algorithm(-1).

Three fixes of QuantLib's, each documented (Divergences/HistogramTests.cs): the Freedman-Diaconis rule's quantiles are Hyndman and Fan's type 8, as QuantLib's comment says, where QuantLib's interpolation weight drops the method's p/3 term; at the upper boundary's probability the quantile reads the largest sample, type 8's clamp, where QuantLib reads a 0 past its sorted samples; and given breaks that repeat count their bins once, where QuantLib counts the bins before it removes the repeats. Data giving a bin width of 0 under the Freedman-Diaconis or Scott rule (no spread, or an interquartile range of 0) are refused, where QuantLib's bin count is undefined and it throws std::length_error.
