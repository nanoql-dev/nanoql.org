Interface IXabrInterpolation

Namespace
NanoQL.Numerics
Assembly
NanoQL.dll

A fitted XABR interpolation's results: the four SABR-style parameters every XABR model has, the fit's errors, the strikes' weights and the end criteria of the minimization kept. The view a swaption volatility cube reads.

public interface IXabrInterpolation

Remarks

An extension point: SABRInterpolation implements it, and a model's interpolation of one's own does, to be fitted by a cube on that model.
