Remarks

An extension point. A model is an immutable configuration until it is bound: SetBasket(Basket) copies it, restricts the copy to the basket's live names (RestrictTo(ImmutableArray<int>, int)), binds the copy to the basket and runs its ResetModel() there, once. The copy is the model's own memberwise copy, so a derived model keeps its state in fields it writes only while it is built, restricted or reset, and never after.

QuantLib's model holds a relinkable handle to its basket and resets when another basket links it, so a model set on two baskets in turn can keep the first's precomputation (the recursive model's loss weights, the random models' simulations). Each binding here is a fresh model's, bit for bit.
