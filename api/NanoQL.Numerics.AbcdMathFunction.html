Remarks

Immutable; validated at construction (Validate(double, double, double, double)). An extension point, as in QuantLib: AbcdFunction derives from it.

Two of QuantLib's defects are fixed. MaximumLocation() is QuantLib's master's (#2841, after the pin), where 1.44 returns the stationary point unconditionally, a minimum when b < 0; and MaximumValue() is the function at that location, where QuantLib returns d whenever b = 0 or a ≤ 0, so 0.17 for AbcdFunction()'s defaults whose maximum is 0.2657.
