Remarks

The volatility matrix has a row per option tenor and a column per strike; the constructor copies it. The option dates and times are computed from the reference date when the surface is built, and the interpolation is a BicubicSpline over the strikes (x) and the option times (y), which always extrapolates inside the structure's range checks: a time before the first option time, or a strike between the strikes' range and the structure's, extrapolates.

QuantLib's constructors on quotes and on a Matrix coincide once a quote is a double: the Matrix forms are kept, so an empty matrix reaches QuantLib's own checks, where QuantLib's quote forms read its first row first. The floating forms, whose reference date QuantLib moves with the evaluation date, are Create(int, Calendar, BusinessDayConvention, IEnumerable<Period>, IEnumerable<double>, Matrix, EvaluationContext, DayCounter?): a surface under a later evaluation date is a new surface, whose option dates are that date's, where QuantLib's moving surface can keep the previous reference date's option dates (a documented divergence).
