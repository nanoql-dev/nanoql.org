Remarks

A mutable working type: each draw changes it, and it is not thread-safe. A draw returns a view of its buffer, valid until its next draw.

Two departures from QuantLib's, each documented: SkipTo(long) moves to the n-th point, as QuantLib's other sequences' skipTo do, where QuantLib's moves n points on (Divergences/LatticeRsgTests.cs); and a dimension beyond the generating vector's, which QuantLib reads past its end, and a number of points below 1, a division by 0, are refused.
