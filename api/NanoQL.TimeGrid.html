A discrete time grid: increasing times from 0, which contain the mandatory times it was built with.

Remarks

Immutable. The grid starts at 0 and refuses negative times; QuantLib's own note asks whether negative times could be allowed, and keeps the restriction for the time being.

GetEnumerator() is QuantLib's begin() and end(). Its reverse iterators, rbegin() and rend(), are an indexed loop run backwards: for (int i = grid.Size - 1; i >= 0; i--).

TimeGrid(ReadOnlySpan<double>, int)

Initializes a new instance of the TimeGrid class with mandatory time points, which it copies, and further points regularly spaced between each pair of them to reach about the given number of steps.

public TimeGrid(ReadOnlySpan<double> times, int steps)

Parameters

times ReadOnlySpan<double>

The mandatory times, in any order; times close enough to one another count once.

steps int

The number of steps over the whole grid, from which the longest step is the last mandatory time divided by it; with 0, the longest step is the shortest distance between the mandatory times, 0 aside.

Exceptions

ArgumentException

times is empty or holds a negative time, or, with no steps, holds no time but 0.

ArgumentOutOfRangeException

steps is negative; or times holds a NaN, or gives a period whose number of steps isn't a finite int (an infinite time, or no steps and a shortest distance too small), which QuantLib leaves undefined.
