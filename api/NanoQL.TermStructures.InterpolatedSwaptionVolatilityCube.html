Remarks

Each strike spread's volatility spreads are interpolated bilinearly over the swap lengths and the option times, extrapolating linearly. The smile section of an option date and a swap tenor is linear between the at-the-money strike plus each strike spread, at the at-the-money volatility plus the spread interpolated there, from the section's standard deviations on Actual/365 (Fixed); a section by option time rounds the swap length to whole months and adjusts the option date to a fixing date of the swap index the tenor's at-the-money strike uses.

A section's at-the-money strike is a swap index's fixing, which QuantLib computes at the query under the global evaluation date, fixings and at-par switch, and the volatility queries take no context. So the cube keeps the context it was built with, and its sections read it: a query under another context still reads the build context. Its results are QuantLib's whenever QuantLib's query runs under the settings it was built under.

QuantLib's cube computes its spread interpolations on its first query; here they are built with the cube, so a refusal of the grid (a single option or swap tenor) comes at construction. QuantLib's volSpreads(i) reads past its matrices for an index past the strike spreads; it is refused here.

The swap index whose family and conventions give the at-the-money strikes of the swap tenors past the short index's.

The swap index whose family and conventions give the at-the-money strikes of the other swap tenors.

vegaWeightedSmileFit bool

QuantLib's flag, which this cube doesn't read.

context EvaluationContext

The evaluation context, which the cube's sections read for their at-the-money strikes.
