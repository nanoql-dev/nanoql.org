Remarks

Fletcher-Reeves-Polak-Ribiere algorithm adapted from Numerical Recipes in C, 2nd edition. The user has to provide a line-search method and optimization end criteria. The search direction is dᵢ = −f′(xᵢ) + cᵢdᵢ₋₁, where cᵢ = ‖f′(xᵢ)‖²/‖f′(xᵢ₋₁)‖² and d₁ = −f′(x₁). This optimization method requires the knowledge of the gradient of the cost function.

Immutable: each minimization runs on a new line search (LineSearchBasedMethod).
