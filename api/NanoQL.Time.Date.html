Struct Date

Namespace
NanoQL.Time
Assembly
NanoQL.dll

A date, held as QuantLib's serial number: 367 (January 1st, 1901) to 109574 (December 31st, 2199), Excel's numbering. It provides inspectors, a limited date algebra, and conversion to and from DateOnly.

public readonly struct Date : IEquatable<Date>, IComparable<Date>, IComparable

Remarks

QuantLib's null date, Date(), is Nullable<T> null in nanoql. default(Date) (serial 0) is never a valid date: no constructor produces it, and members that read it throw ArgumentException. Equality, ordering, hashing and SerialNumber never throw.
