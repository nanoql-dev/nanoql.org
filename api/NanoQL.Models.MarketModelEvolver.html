Remarks

A working type: it keeps its state between steps, owned by one computation, and isn't thread-safe. Its CurrentState is its own curve state, read only by contract and valid until its next step, as QuantLib's const CurveState& is; a caller that keeps it calls Clone(). An extension point, as in QuantLib.
