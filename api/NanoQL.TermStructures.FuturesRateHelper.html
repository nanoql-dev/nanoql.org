Remarks

The helper's dates don't follow the evaluation date, and it reads no other setting, so it takes no context. Its start date must be an IMM or an ASX date for those types, on either cycle; a Custom one takes any date. The pillar, latest relevant and latest dates are the maturity date.

A Custom helper built from dates with no end date keeps a null maturity, as QuantLib's does, and so null pillar, latest relevant and latest dates, which the bootstraps read as expired and drop. QuantLib computes a year fraction from that null date, which some day counters read out of bounds, and only its implied quote reads it, after discounting to the null date; this helper computes none, and its ImpliedQuote(EvaluationContext) refuses the null maturity before it reads the curve.
