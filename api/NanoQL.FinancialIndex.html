Remarks

An index holds its conventions, and for an Ibor or overnight index its forecasting curve, never fixings: its stored fixings are read from Fixings, which IndexFixings writes. QuantLib's addFixing, addFixings and clearFixings are members of the store, which take the index.

No check is made that a requested fixing is for a date on or before the evaluation date: as in QuantLib, it is up to the caller not to see into the future. Two indexes are never compared as values: QuantLib compares their Name, and so does the port.

An index keeps the ConventionProvider it was built with, Current at its construction, and every clone of it keeps the same one. Whatever is built on the index later (a builder's swap, a swap index's underlying swap) follows that provider.

An extension point. QuantLib's addFixings isn't virtual, so the store's bulk writers store the dates they are given and don't call it.
