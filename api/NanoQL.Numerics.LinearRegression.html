Remarks

GeneralLinearLeastSquares is immutable and built by its factory, so QuantLib's derived class is a factory here, returning it. Its basis is QuantLib's details::LinearFcts: the intercept's constant where the intercept isn't 0, then x itself, or each of a vector's elements, by position. QuantLib reads the first sample's size for that basis, undefined on no samples; no samples are refused.
