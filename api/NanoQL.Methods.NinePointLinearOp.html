Remarks

A working type: mutable, owned by one computation and not thread-safe. Apply(ReadOnlySpan<double>, Span<double>) writes into the caller's span, which mustn't overlap the input; Mult(Vector) returns a new operator, as QuantLib's does, since it runs while an operator is built.

An extension point, as in QuantLib: the mixed second-derivative operator derives from it and fills the protected coefficients in its constructor. A bare operator's coefficients are zero, where QuantLib leaves them uninitialized. QuantLib's swap and move members are C++ value semantics: Clone() and references replace them.
