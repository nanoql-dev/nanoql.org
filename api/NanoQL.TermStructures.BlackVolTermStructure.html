Remarks

An extension point, as in QuantLib: the Black volatility and variance structures derive from it, through BlackVolatilityTermStructure and BlackVarianceTermStructure. A structure is immutable, its reference date fixed at construction.

Remarks

QuantLib's adapter holds a shared_ptr to the structure through shared_from_this, and refuses a structure no shared_ptr holds; a .NET object is always held by reference, so the refusal has no counterpart.
