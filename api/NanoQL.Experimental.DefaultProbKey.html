The key that indexes market-implied credit curves: a proxy for the defaultable bond, or class of bonds, that sets a credit contract's conditions, grouping the atomic default types the contract is sensitive to with the obligation's currency and seniority.

Remarks

Immutable, and an extension point (NorthAmericaCorpDefaultKey derives from it). QuantLib's empty currency is null.

Equality is QuantLib's: the same seniority and currency, and the same number of event types, each of one key's equal to one of the other's (DefaultType's equality). It is sealed, so every subclass compares the same way.
