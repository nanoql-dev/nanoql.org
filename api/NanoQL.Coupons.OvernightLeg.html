Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToLeg() builds the leg, in place of QuantLib's conversion operator; it reads no evaluation date, since the coupons' value dates are always the full daily list. A builder has no value equality: its vectors compare by reference.

A period whose gearing is zero is a FixedRateCoupon at the spread, capped and floored; a period with a cap or a floor is a CappedFlooredOvernightIndexedCoupon. A coupon pricer given with WithCouponPricer(OvernightIndexedCouponPricer?) is set on each coupon and capped coupon; otherwise the coupons keep their default pricers, and the capped coupons have none.
