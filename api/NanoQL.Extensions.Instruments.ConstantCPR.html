Remarks

The SMM is the CPR's monthly equivalent, 1 − (1 − CPR)^(1/12) (SIFMA's Uniform Practices, Chapter SF, SF-5). A CPR outside [0, 1] is refused: SIFMA defines the rate as the fraction of a pool's outstanding balance assumed to prepay, so none outside it is one, where QLNet takes it and returns NaN above 1 and a negative SMM below 0.
