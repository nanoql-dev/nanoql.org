Remarks

Immutable: it copies its initial value. QuantLib's Problem also holds what a minimization changes (the current value, the function value, the evaluation counts); here Minimize(Problem, EndCriteria) returns those as a ProblemResults, and a method works on a ProblemState, built from the problem, which carries QuantLib's API.
