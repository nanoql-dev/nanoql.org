Remarks

One of QuantLib's defects is fixed: QuantLib's primitive divides a sum by 4c³ whose terms cancel to O(c³) when c·T and c·S are small, so the covariance between 0 and 1 of the 1-year rate is out by 2.4e-6 at c = 1e-4 and by 14% at c = 1e-6. Where QuantLib's form rounds by more than 1e-12 of the integral at the last time it reaches, min(T, S), the primitive is the integral from 0 written without the cancellation, each term a polynomial times a decaying exponential; elsewhere it is QuantLib's, bit for bit.

QuantLib's polynomial branch for c = 0 is left out: the base's validation requires c > 0.
