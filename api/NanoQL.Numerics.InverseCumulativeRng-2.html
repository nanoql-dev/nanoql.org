The inverse cumulative random-number generator: it uses a uniform deviate in (0, 1), supplied by TRng, as the source of cumulative distribution values, then the inverse cumulative distribution TIc to calculate the distribution deviate.

Remarks

A mutable working type: each draw changes it, and it is not thread-safe. It copies the generator it is given, so the caller's later draws change nothing in it. Its inverse cumulative is TIc's zero value, QuantLib's default construction, which QuantLib's class never assigns.
