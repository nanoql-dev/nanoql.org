The B-spline basis functions N_{i,p}(x) of degree p, i = 0, 1, …, n, over a knot vector of p + n + 2 nondecreasing points (x_0, x_1, …, x_{n+p+1}). Follows the treatment and notation of Weisstein, Eric W. "B-Spline." From MathWorld, a Wolfram Web Resource, http://mathworld.wolfram.com/B-Spline.html.

Remarks

A linear B-spline has p = 1, a quadratic one p = 2, a cubic one p = 3; n + 1 is the number of control points. The basis functions are defined recursively: N_{i,0}(x) is 1 if x_i ≤ x < x_{i+1} and 0 otherwise, and N_{i,p}(x) = N_{i,p−1}(x)·(x − x_i)/(x_{i+p} − x_i) + N_{i+1,p−1}(x)·(x_{i+p+1} − x)/(x_{i+p+1} − x_{i+1}). Immutable: the knots are copied.

On a repeated knot one of those spans is zero, and QuantLib's recursion divides by it, giving NaN, so a cubic B-spline fit on knots with a repeat throws. Here a term whose span is zero reads 0, the Cox–de Boor convention, the limit of QuantLib's own values as the repeated knots close up; on distinct knots it is QuantLib's arithmetic and bits. A documented divergence.
