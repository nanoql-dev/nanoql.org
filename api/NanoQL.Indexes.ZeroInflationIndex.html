Remarks

The index holds its forecasting curve, null for QuantLib's empty handle; a forecast without one throws QuantLib's "empty Handle cannot be dereferenced". Clone(ZeroInflationTermStructure?) is QuantLib's clone(h), which returns a plain ZeroInflationIndex with the same conventions.

Zero-index fixings are never interpolated: every read keys on the first day of the date's inflation period. Reading never writes, where QuantLib's hasHistoricalFixing on a missing date inserts a null entry that LastFixingDate(EvaluationContext) then reads, a documented divergence. An extension point.
