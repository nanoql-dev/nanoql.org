Remarks

Where QuantLib streams a number with the stream's defaults, the text follows a C++ stream: six significant digits, trailing zeros removed, an exponent of at least two digits (1e-07), and exact ties rounded half to even. A bool is written True or False, where a C++ stream writes 1 or 0; QuantLib streams no boolean through these functions.
