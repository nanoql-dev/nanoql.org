Remarks

An extension point and an immutable object (over McSimulation<TPath, TStats>): a concrete engine's static Calculate builds one per call from the option, the context, the process and QuantLib's settings, with QuantLib's constructor checks, implements the path pricer, and reads Run()'s model and results. The vanilla option is its only instrument, as in every QuantLib instantiation. The control variate's value comes from ControlPricingEngine(), an engine delegate of the engines' form, on the option.

The process is the engine's: the Black-Scholes engines pass the process on their clock, whose times run from the earliest structure's reference date, so TimeGrid()'s times are that clock's.
