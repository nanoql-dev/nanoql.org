Remarks

An extension point: InterpolatedYoYCapFloorTermPriceSurface<TInterpolator2D, TInterpolator1D> derives from it. QuantLib's surface follows the evaluation date (TermStructure(0, …)), so a derived class's factory computes the reference date and passes it in. An option date is the reference date plus its tenor, unadjusted, as QuantLib's. The protected range checks, which QuantLib never calls, are kept; a price past the last maturity or strike extrapolates.
