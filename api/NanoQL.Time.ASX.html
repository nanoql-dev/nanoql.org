Remarks

QuantLib's functions whose date defaults to Date(), read as the global evaluation date, take the context after QuantLib's parameters without a default, and the date as a nullable after it: the context's evaluation date is read only when the date is null.

A code's month letter is upper-cased in ASCII only, so a letter outside ASCII is no month letter, which is what QuantLib's std::toupper gives on the platform the vectors come from. A method of this class is named Date, which hides the type inside it, so the class writes the type NanoQL.Time.Date.
