Remarks

Unsealed, as in QuantLib, where many swaps derive from it; a derived swap passes its legs to the multi-leg constructor. The per-leg results that QuantLib's swap holds (legNPV, legBPS, the start and end discounts, npvDateDiscount) are members of the SwapResults an engine returns.

WithLeg(int, ImmutableArray<CashFlow>)

A copy of the swap holding another leg at an index: SetCouponPricer<T>(T, int, FloatingRateCouponPricer?)'s step, which QuantLib does in place on the leg a built swap holds. The base's copy is memberwise, so a derived swap's terms come along; a derived swap that caches what it derives from its legs overrides it, and an override returns a copy of the same runtime type.
