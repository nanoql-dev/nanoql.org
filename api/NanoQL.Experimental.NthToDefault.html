An n-th-to-default swap: protection against the n-th default in a basket of credits, for premium payments on the protected notional. Priced as a credit default swap whose default probability is the basket's probability of n defaults or more (Hull and White, "Valuation of a CDO and nth to default CDS without Monte Carlo simulation", Journal of Derivatives 12, 2, 2004).

Remarks

Immutable: it holds the basket with its bound loss model, and an engine's static Calculate prices it (IntegralNtdEngine). The product is digital: the basket's tranche doesn't enter its price. Every name has the same weight in the protected notional.

An order of 0 is refused: QuantLib checks only n ≤ size (nthtodefault.cpp:48), and at n = 0 its fair premium is noise, 6.0e-5, its NPV 3.5e-12 (Conventions/CreditPortfolioConventionTests.cs).
