Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToSwaption(EvaluationContext) builds the swaption, in place of QuantLib's conversion operators. It computes the fixing date from the context's evaluation date at every conversion, where QuantLib's builder keeps the fixing date its first conversion computed: a reused builder follows the context it is converted under.

With no strike, the swaption is struck at the money: at the fair rate of the index's own underlying swap, priced without the settlement date's flows on the index's exogenous discounting curve, or on its forwarding curve. That swap is the index's, so it can differ from the swaption's underlying, which the builder's settings build, as in QuantLib: an Ibor index's swap always reads the context's at-par switch, and an overnight index's takes its telescopic value dates and averaging method, which the underlying doesn't.

WithPricingEngine(Func<Swaption, EvaluationContext, InstrumentResults>?) is kept and changes nothing: QuantLib's builder only attaches the engine to the swaption, computing nothing with it, and a nanoql swaption holds no engine. A builder has no value equality.

An option the builder isn't given that QuantLib's builder fixes takes the builder's provider's default (Defaults(ConventionProvider)), read when the swaption is built: QuantLib's values with nothing configured.
