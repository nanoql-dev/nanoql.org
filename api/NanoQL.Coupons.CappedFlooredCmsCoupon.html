Remarks

It is built with no pricer, as QuantLib's is. Its rate needs a CmsCouponPricer, which CouponPricerFunctions sets on it and its CMS coupon, refusing any other pricer as QuantLib's visitor does; the cap's and floor's optionlet rates and the swaplet rate are read from one state of the pricer's.
