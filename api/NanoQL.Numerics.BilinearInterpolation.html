Remarks

The matrix holds a row per y value and a column per x value: the value at (xi, yj) is zData[j, i]. Outside the grid the value extends the nearest cell's bilinear form. A matrix larger than the grid is read in its first rows and columns, as QuantLib's is; a smaller one, which QuantLib reads past its end, is refused. It copies its inputs, as every Interpolation2D does.
