American exercise: the option can be exercised at any time between two predefined dates. The first date might be omitted, in which case the option can be exercised at any time before the expiry.

BermudanExercise

Bermudan exercise: the option can only be exercised at a set of fixed dates.

The market conventions the library's presets and market builders read when they are built: QuantLib's coded values, the system's configured defaults, or a provider of a user's own.

A currency specification: its name, ISO 4217 codes, symbols, fractions and rounding convention.

CurrencyData

A currency preset's data, which ResolveCurrency(string, Func<CurrencyData>) returns: QuantLib's Currency::Data without its minor unit codes, which no preset sets.

CurrencyExtensions

QuantLib's Decimal * Currency operators (money.hpp), so that 100.0 * eur is a Money.

The discretized asset class used by numerical methods: an asset's values on a lattice, rolled back in time.

EarlyExercise

EuropeanExercise

European exercise: the option can only be exercised at one (expiry) date.

Event

The base class of events associated with a given date.

ExchangeRate

The exchange rate between two currencies, given directly or derived by chaining two others.

Exercise

The base exercise class: the exercise's type and its dates.

FinancialIndex

Instrument

InstrumentResults

The results an engine returns for an instrument.

InterestRate

An interest rate with its day-counting and compounding conventions: discount and compound factors, and implied and equivalent rates.

IntervalPrice

The open, close, high and low prices of an interval.

The lattice (tree, finite-differences) base class: a numerical method that rolls discretized assets back.

LocalVolatilityEstimator<T>

A local volatility estimator: a volatility for each date of a series of quotes, from the quotes around it.

MoneyFunctions

QuantLib's free functions of money.hpp: the closeness of two amounts.

MoneySettings

The settings that say how Money amounts in different currencies combine: QuantLib's per-session Money::Settings, as a value that MoneySettings holds.

NanoQLException

The exception nanoql throws when a calculation fails for a reason other than a bad argument: QuantLib's QL_REQUIRE, QL_FAIL and QL_ENSURE, apart from a public method's checks of its own arguments, which throw ArgumentException. The message keeps QuantLib's wording.

Option

The base option class: an instrument with a payoff and an exercise.

Payoff

The abstract base class of option payoffs.

PricesFunctions

QuantLib's price functions: the mid equivalent and the safe mid of quoted prices.

RebatedExercise

An option exercise with rebate payments: in case of exercise the holder receives the rebate (if positive) or pays it (if negative) on the rebate settlement date.

StochasticProcess

A multi-dimensional stochastic process, governed by dx_t = μ(t, x_t) dt + σ(t, x_t) · dW_t.

StochasticProcess1D

A 1-dimensional stochastic process, governed by dx_t = μ(t, x_t) dt + σ(t, x_t) dW_t.

StochasticProcess1DDiscretization

The discretization of a StochasticProcess1D over a time interval: QuantLib's nested StochasticProcess1D::discretization.

TermStructure

Basic term-structure functionality: a reference date, a day counter and range checks.

TimeGrid

TimeSeries<T>

A container for historical data: a datum for each of a set of dates, read by date or in date order.

VolatilityCompositor

A volatility compositor: a volatility series from a series of returns or volatilities, by a model it can calibrate to the series.

WorkingTypeAttribute

Marks the types the playbook calls working types (docs/porting-playbook.md §2.5): mutable, owned by one computation and not thread-safe, as an array is. A type deriving from a marked class, or implementing a marked interface, is one of them too. The bindings keep every such type off their handles, which any thread may share: Matrix and Vector cross as arrays, a generator as an immutable snapshot drawn in batches, and the rest stay inside nanoql (docs/bindings.md).
