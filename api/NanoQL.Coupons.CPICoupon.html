Remarks

The base is the given base CPI or, without one, the index observed on the base date plus the lag. It accepts a CPICouponPricer. No convexity adjustment is made for lags other than the one the curve was built with.

QuantLib's CPILeg gives every coupon start − lag as its base date, which loses the start's day from a month-end start, and its notional flow a base on another convention, so a leg's coupons and notional could price on two base CPIs. Here the leg sets one internal base observation for every flow (with neither a base CPI nor a base date, the schedule's start; with a base date, the base date plus the lag; each at the lag), while BaseDate stays QuantLib's; the public constructors keep QuantLib's convention. A documented divergence.
