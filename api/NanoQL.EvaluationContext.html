The values QuantLib reads from its global Settings, as one explicit input: every function that reads the evaluation date or a setting, directly or through a callee, takes the context.

Remarks

EvaluationDate is required: there is no "today" default. Every other field is an init-only property whose default reproduces QuantLib's default setting. Variations are made with with.

Fields added later follow the same shape, never required, and no default changes once released, so callers keep compiling and running.

Equality is the record's: field by field. Fixings and ExchangeRates compare by content, since IndexFixings and ExchangeRates define value equality, so two contexts holding the same fixings and rates are equal however their stores were built; MoneySettings is a record. So are CommoditySettings and QuantitySettings, and UnitOfMeasureConversions compares by content.
