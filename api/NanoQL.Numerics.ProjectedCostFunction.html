Remarks

QuantLib's class derives from both CostFunction and Projection; this one composes a projection, a copy of the state of the one it is given, so a projection's overrides of Project(Vector) and Include(Vector) aren't the ones it calls, as QuantLib's copy of its base doesn't call them either. It keeps no state between calls: QuantLib's mutable copy of the parameters becomes the new vector Include(Vector) returns.
