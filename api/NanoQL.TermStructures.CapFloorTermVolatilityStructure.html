Remarks

An extension point, as QuantLib's abstract class is: a derived structure implements VolatilityImpl(double, double), which the Volatility members call after their range and strike checks, and the inspectors its base leaves abstract. Its reference date is fixed; a derived structure whose reference date QuantLib moves with the evaluation date passes its settlement days, as its Create factory computes it from the context.
