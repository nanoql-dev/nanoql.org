Remarks

The index holds its forecasting curve, null for QuantLib's empty handle; a forecast without one throws QuantLib's "empty Handle cannot be dereferenced". Clone(YoYInflationTermStructure?) is QuantLib's clone(h).

QuantLib's deprecated interpolated() and its member, which no QuantLib class sets, aren't ported: the index never interpolates, the coupons do. An extension point.
