Remarks

Immutable: its value is Hull-White's convexity bias (ConvexityBias(double, double, double, double, double)) at the context's evaluation date, computed once at construction (§2.2's quote row). QuantLib's quote recomputes when the evaluation date or an input changes; here a new date or input is a new quote. The futures' start and the index's maturity are year fractions of the index's day counter from the evaluation date. QuantLib's isValid isn't ported: a value is always valid.
