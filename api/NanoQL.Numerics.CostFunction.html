Remarks

A cost function implements Values(Vector), and overrides the other members where it knows better than their defaults: Value(Vector), the root mean square of the values; Gradient(Vector, Vector) and Jacobian(Matrix, Vector), by central differences with step FiniteDifferenceEpsilon, written into their first argument; and ValueAndGradient(Vector, Vector) and ValuesAndJacobian(Matrix, Vector), which call those.

A vector a member returns is the caller's own: a new one, which the caller may change. An extension point, as in QuantLib: each problem's cost function derives from it.
