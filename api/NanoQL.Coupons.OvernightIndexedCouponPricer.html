Remarks

A pricer is a stateless function of the coupon and the context (FloatingRateCouponPricer): QuantLib's initialize(coupon), which keeps the coupon (a capped coupon's underlying) in the pricer, and the values QuantLib keeps after a query are computed inside each call from its arguments. A member taking a coupon accepts an OvernightIndexedCoupon or a CappedFlooredOvernightIndexedCoupon, whose underlying it prices.

The caplet volatility and the effective-volatility flag are the pricer's configuration; SetCapletVolatility<T>(T, OptionletVolatilityStructure?) and SetEffectiveVolatilityInput<T>(T, bool) return modified copies.
