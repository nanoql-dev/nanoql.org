Remarks

CPI volatility is always with respect to a base date. An observation lag of null, or QuantLib's sentinel Period(-1, Days), means the structure's own ObservationLag.

An extension point. QuantLib's only constructor computes the reference date from settlement days and the evaluation date; here the derived class's Create computes it and passes it in, so every built structure has a fixed reference date.
