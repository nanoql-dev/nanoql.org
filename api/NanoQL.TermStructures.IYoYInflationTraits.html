Remarks

As IYieldTraits does for yield curves: QuantLib's piecewise curve derives from the interpolated curve its traits name, which C# can't express, so the traits carry the kind's formula and rule, and the interpolated curve and the piecewise curve of that kind both call them. An extension point.
