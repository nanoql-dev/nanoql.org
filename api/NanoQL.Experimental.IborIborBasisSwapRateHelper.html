Remarks

The swap is assumed to pay the base index plus the basis and receive the other index. The helper can be used to bootstrap the forecast curve for the base index (in which case you'll have to pass bootstrapBaseCurve = true and provide the other index with a forecast curve) or the forecast curve for the other index (in which case bootstrapBaseCurve = false and the base index will need a forecast curve). In both cases, an exogenous discount curve is required. A payment lag can also be passed; it is applied to both legs.

Limitation: the forecasting curve can't be bootstrapped with stubs computed off itself for now, so a stub-index selection is refused on the leg whose curve is bootstrapped.

The helper builds its swap, on a nominal of 100, when it is constructed and when it is re-dated, so it reads the context's evaluation date and its at-par switch then. Bound to the curve being built, its bootstrapped leg's coupons are copied on the index cloned onto that curve, what QuantLib's relinked handle gives them.

InitializeDates(EvaluationContext)

Computes the helper's dates for an evaluation date: QuantLib's initializeDates(). A helper whose dates follow the evaluation date overrides it and calls it from its constructor; the bootstraps call it on a fresh copy to re-date the helper for a curve built under another evaluation date.
