Remarks

A working type. The coterminal swap annuities are computed lazily, from the last back to the one asked for, as QuantLib's are, and the constant-maturity swap rates at each read; both into the state's own buffers, reset at each set, so every read is QuantLib's arithmetic in QuantLib's order. A rate read at the number of rates, which QuantLib's index check admits and reads past its vectors, is refused with QuantLib's text.

Remarks

QuantLib's refusal of a first valid index names one more than the number of rates as its bound while checking against the number of rates; the text here names the bound it checks (Divergences/MarketModelTextTests.cs).

Exceptions

ArgumentException

The number of ratios isn't one more than the number of rates.

ArgumentOutOfRangeException
