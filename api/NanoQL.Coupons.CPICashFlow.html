A cash flow paying the performance of a zero-inflation (CPI) index: the notional times the ratio of the index observed on the observation date, with the lag, to its base. It isn't a coupon: it has no accruals.

Remarks

The base is the given base fixing, which needn't agree with the index, or the index observed on the base date with no lag. A CPILeg's notional flow takes its coupons' base instead, as CPICoupon's remarks say; the public constructor keeps QuantLib's convention.
