Remarks

Immutable: the weights are solved at construction, by QRSolve(Matrix, Vector, bool, Vector?), and a residual reaching 1e-10 is refused. The z values are a matrix with a row per x value and a column per y value (zᵢⱼ at (xᵢ, yⱼ)), QuantLib's layout for this interpolation, the transpose of other two-dimensional ones'. The grid's points run through x within each y.

QuantLib's implementation can set another tolerance for the residual, which its interpolation doesn't expose, so 1e-10 is fixed here too.
