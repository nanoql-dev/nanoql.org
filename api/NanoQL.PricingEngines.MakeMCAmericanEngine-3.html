Remarks

An immutable builder: each method returns a modified copy, and ToEngine() the engine as a function of the option and the context, with QuantLib's checks on the steps. QuantLib's defaults: 2,048 calibration samples, a polynomial order of 2, the monomial basis, no antithetic variates and no control variate.

The seed is a constructor argument; the calibration seed is optional, its default QuantLib's documented one, the seed plus 1,768,237,423 modulo 2³², where QuantLib's builder passes its narrowed null.
