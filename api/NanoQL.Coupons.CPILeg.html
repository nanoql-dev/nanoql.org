Remarks

An immutable builder: each method returns a modified copy. ToLeg() builds the leg, in place of QuantLib's conversion operator, and attaches QuantLib's default CPICouponPricer. A period with a zero fixed rate is a fixed-rate coupon paying its floor or cap; a period with a cap or a floor and a non-zero rate is refused, as QuantLib refuses it. The notional flow comes last, even when the schedule has a single date. A builder has no value equality.

With neither a base CPI nor a base date, every flow's base date is the schedule's start less the lag, as QuantLib gives it, but every flow observes its base on the schedule's start with the leg's lag; with a base date, the notional flow observes its base as the coupons do, on the base date plus the lag. So the coupons and the notional flow share one base CPI, where QuantLib's can differ (CPICoupon's remarks), a documented divergence.

Exceptions

NanoQLException

No notional was given; the schedule has periods, or is empty, and no fixed rate was given; the schedule is empty; a period with a non-zero rate has a cap or a floor; a coupon is built with no day counter, with the text QuantLib's coupon fails with on its first accrual ("no day counter implementation provided"); or a date is computed on QuantLib's empty calendar where it can't give one.

ArgumentException

A flow refuses its base: neither a base CPI nor a base date, where the schedule has a single date; or a base CPI below 1e-16 in absolute value.
