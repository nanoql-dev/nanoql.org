Remarks

An immutable builder, as CmsLeg: each method returns a modified copy, and ToLeg() builds the leg through FloatingDigitalLeg<TIndex, TCoupon>(Func<Date, double, Date, Date, int?, TIndex, double, double, Date, Date, DayCounter?, bool, TCoupon>, Func<TCoupon, double?, PositionType, bool, double?, double?, PositionType, bool, double?, DigitalReplication?, bool, CashFlow>, Schedule, IEnumerable<double>, TIndex, DayCounter?, BusinessDayConvention, IEnumerable<int?>, IEnumerable<double>, IEnumerable<double>, bool, IEnumerable<double?>, PositionType, bool, IEnumerable<double?>, IEnumerable<double?>, PositionType, bool, IEnumerable<double?>, DigitalReplication?, bool) in place of QuantLib's conversion operator. The coupons are built without pricers, as QuantLib's are. The leg pays the underlying's rate unless WithNakedOption(bool) is set: QuantLib's builder leaves its flag uninitialized until that call, an undefined read (QuantLib's check, its legs built with withNakedOption(false)). A builder has no value equality: its vectors compare by reference.
