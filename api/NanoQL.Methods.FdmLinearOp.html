Remarks

A working type: mutable, owned by one computation and not thread-safe. An extension point, as in QuantLib: later units derive their operators from it.

Apply(ReadOnlySpan<double>, Span<double>) writes into the caller's span, where QuantLib returns a new array, so that a time step allocates nothing; the result mustn't overlap the input, as PETSc's MatMult requires. Apply(Vector) is QuantLib's value-returning form.
