Remarks

An immutable builder: each method returns a modified copy. ToLeg() builds the leg, in place of QuantLib's conversion operator, each coupon taking the reset schedule's next resetsPerCoupon periods and the compounding pricer, or the averaging one for simple averaging. A builder has no value equality.

Parameters

fullResetSchedule Schedule

The schedule of every coupon's reset periods.

index IborIndex

The index whose fixings are compounded or averaged; it should have the resets' tenor.

resetsPerCoupon int

The number of resets per coupon, which divides the schedule's periods exactly.

Exceptions

ArgumentNullException

fullResetSchedule is null, or index is, QuantLib's "no index provided".

ArgumentOutOfRangeException

resetsPerCoupon isn't positive, where QuantLib's check divides by it.

ArgumentException

The schedule is empty, or resetsPerCoupon doesn't divide its periods, each with QuantLib's text.
