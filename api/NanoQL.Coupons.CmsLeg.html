Remarks

An immutable builder, as IborLeg: each method returns a modified copy, and ToLeg() builds the leg in place of QuantLib's conversion operator. The coupons are built without pricers, as QuantLib's are; a CmsCouponPricer is set with SetCouponPricer(ImmutableArray<CashFlow>, FloatingRateCouponPricer?). A builder has no value equality: its vectors compare by reference.
