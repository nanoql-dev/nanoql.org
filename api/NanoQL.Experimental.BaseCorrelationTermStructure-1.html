Remarks

Immutable: the quotes are values, read at construction, and a structure whose reference date follows the evaluation date is built by Create(int, Calendar, BusinessDayConvention, IReadOnlyList<Period>, IReadOnlyList<double>, IReadOnlyList<IReadOnlyList<double>>, DayCounter, EvaluationContext, TInterpolator) from the context. QuantLib specializes the interpolation for BilinearInterpolation and BicubicSpline alone; any 2-D interpolator builds it here, Bilinear and Bicubic among them. Some interpolators may take the correlation out of [−1, 1].

The correlations hold a row per loss level and a column per tenor, the shape QuantLib's checks enforce, where its header names them correls[iYear][iLoss]. The loss levels are checked as QuantLib's checkLosses checks them, increasing in (0, 1], a check QuantLib defines and never calls, so it interpolates on unsorted levels.

The correlation is read from the interpolation with extrapolation always on, bilinear off the grid where the interpolator is, so off the grid it can leave [0, 1]; the extrapolate flag is QuantLib's and unread there too. The base-correlation model refuses a correlation outside [0, 1).

To be done, as in QuantLib: the relation to a given basket is to be made explicit for bespoke models; a matrix data structure, and the data structure for a basket whose current losses aren't zero. The 2-D interpolator is left open because of the arbitrage issues of its choice: non-local ones like cubic splines affect the past (calibrated) coupons of previous tenors.
