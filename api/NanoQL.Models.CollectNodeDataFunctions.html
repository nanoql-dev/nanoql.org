CollectNodeData(MarketModelEvolver, MarketModelMultiProduct, MarketModelNodeDataProvider, MarketModelExerciseValue, MarketModelExerciseValue, int)

Collects, on each path, each exercise's node data: the exercise value, the data provider's values and the control's value at the exercise, and the product's cash flows from it to the next exercise, each in units of the numeraire portfolio; row 0 holds the cash flows before the first exercise.

public static NodeData[][] CollectNodeData(MarketModelEvolver evolver, MarketModelMultiProduct product, MarketModelNodeDataProvider dataProvider, MarketModelExerciseValue rebate, MarketModelExerciseValue control, int numberOfPaths)

Remarks

It steps the caller's evolver, product, provider, rebate and control, each reset at each path's start, as QuantLib's does; a path that ends before an exercise leaves the exercise's data invalid and zero.

Refused, QuantLib's TODO (collectnodedata.cpp:49-53) narrowed to what it reads, each text the TODO and its remedy: an evolver whose steps aren't the product's (QuantLib throws "invalid index" from inside); a provider, rebate or control with an evolution time outside the product's (QuantLib drops an exercise off the product's times, so the later nodes hold earlier exercises' values); a provider whose exercise times aren't the rebate's; and a control whose evolution misses one of the rebate's exercise times. QuantLib's default nothing control, flagged at every rate time beside a rebate at a subset, is accepted, its node data the matched control's.

Exceptions

ArgumentException

The product isn't one product, or the evolver's, provider's, rebate's or control's times don't fit as above.
