Remarks

Immutable, with QuantLib's defaults: each With… method returns a modified copy, where QuantLib's setters change the configuration and return it. QuantLib's seed isn't here: the seed is the optimizer's own argument, required (Cmaes). Its vectors compare by reference, so two configurations are equal only when they share them.
