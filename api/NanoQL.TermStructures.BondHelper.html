Remarks

The helper prices a plain copy of the bond (Bond), as QuantLib's copies it as its base class, so a derived bond's overrides don't reach its price: a callable bond's helper quotes its straight twin's price. Bond returns that copy, which shares the bond's cash flows. The copy is priced by DiscountingBondEngine on the curve the helper is bound to, and only on that curve: the bond's floating coupons keep forecasting on their own index's curve, as QuantLib relinks only its discounting handle. The engine's includeSettlementDateFlows is unset, so the context's IncludeReferenceDateEvents decides.

It is no relative-date helper: its earliest date, the bond's next cash-flow date, is computed with the context it is built with and never again, while its implied quote reads the context it is given, as QuantLib's reads the current evaluation date through the bond's settlement date. Its latest date is the bond's last cash-flow date, which can be later than the maturity date because of the payment adjustment. Unsealed, an extension point: FixedRateBondHelper derives from it.
