Remarks

A default's recovery is kept in 256ths, QuantLib's rounding, as a value: QuantLib's stores the count in 8 bits, so a recovery of 1, 256/256, reads 0, a full loss for no loss, and its 12-bit name and day fields wrap past 4,095. Bound to a basket, the model simulates the live names. The simulation's rules are RandomLM<TCopula, TInitTraits, TUsng>'s.
