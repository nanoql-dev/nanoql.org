Class VanillaSwapDefaults

Namespace
NanoQL.Instruments

NanoQL.dll

The defaults MakeVanillaSwap takes for an option it isn't given, on an index of a currency, which ResolveVanillaSwapDefaults(Currency?, Func<VanillaSwapDefaults>) returns: QuantLib's by the currency, which the builder fixes. The floating leg's calendar, tenor, conventions and day counter are the index's, and the fixed leg's and the settlement calendar the floating leg's, so they aren't defaults.

Parameters

FixedLegTenor Period?

The fixed leg's tenor, or null where it is unknown for the currency, which the builder refuses when it needs one.

FixedLegTenorThreshold SwapTenorThreshold

The fixed leg's tenor at the swap tenors on one side of a threshold, in place of FixedLegTenor, or null for none. The builder compares the swap's tenor with it when it needs its fixed leg's tenor, as QuantLib compares.
