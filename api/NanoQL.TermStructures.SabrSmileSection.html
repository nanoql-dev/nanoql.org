Remarks

The volatility at a strike below 1e-5 minus the shift is the volatility there, a NaN strike's included, as QuantLib's std::max floors it. QuantLib's date constructor without a reference date, whose section floats with the evaluation date, is Create(Date, double, ReadOnlySpan<double>, EvaluationContext, DayCounter?, double, VolatilityType), which takes the evaluation context and fixes the date. QuantLib reads the parameters unchecked; fewer than four are refused here.
