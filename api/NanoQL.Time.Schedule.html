Remarks

Date(int) is a method, so inside this class the Date type is written NanoQL.Time.Date wherever an expression needs it.

Schedule(IEnumerable<Date>, Calendar?, BusinessDayConvention, BusinessDayConvention?, Period?, DateGenerationRule?, bool?, IEnumerable<bool>?)

Initializes a new instance of the Schedule class from any list of dates and, optionally, meta information that client classes can use. Neither the dates nor the meta information is checked for plausibility in any sense.

public Schedule(Date? effectiveDate, Date terminationDate, Period tenor, Calendar? calendar, BusinessDayConvention convention, BusinessDayConvention terminationDateConvention, DateGenerationRule rule, bool endOfMonth, EvaluationContext context, Date? firstDate = null, Date? nextToLastDate = null)

Parameters

effectiveDate Date?

The effective date. When null, with no first date and the backward rule, a placeholder is placed a whole number of years before the termination (or next-to-last) date, from the evaluation date.

terminationDate Date

The termination date.

tenor Period

The tenor.

calendar Calendar

The calendar, or null for QuantLib's empty calendar, which adjusts only by Unadjusted: a schedule that needs another adjustment, or the end-of-month one, is refused, and the schedule built answers null for Calendar.

convention BusinessDayConvention

The business-day convention.

terminationDateConvention BusinessDayConvention

The termination date's business-day convention.

rule DateGenerationRule

The date-generation rule.

endOfMonth bool

Whether dates stay at month end.

context EvaluationContext

The evaluation context, read when the effective date is null.

firstDate Date?

The first date after the effective date, for an irregular first period.

nextToLastDate Date?

The date before the termination date, for an irregular last period.

Exceptions

ArgumentException

A date or the tenor is inconsistent with the others.

ArgumentOutOfRangeException

A convention or the rule isn't a member of its enum.

NanoQLException

The rule can't generate the schedule, or the calendar is null and a date is adjusted.
