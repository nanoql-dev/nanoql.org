Remarks

Faithful implementation of the algorithm of Byrd, Lu, Nocedal and Zhu, "A Limited Memory Algorithm for Bound Constrained Optimization", SIAM J. Sci. Comput. 16(5):1190-1208, 1995.

Coordinates whose bound is ±MaxValue are treated as unbounded, so with no active bounds the method reduces to plain limited-memory BFGS. Explicit bounds may instead be passed to the constructor, overriding the constraint.

Limited memory trades accuracy of the Hessian model for cost: it stores only the last memory correction pairs, needing O(memory·n) storage and work per step instead of the O(n²) of dense BFGS, at the price of linear rather than superlinear convergence. This typically results in a modest increase in iteration count.

Immutable: each minimization keeps its correction pairs and working arrays to itself. On the relative function-reduction stop the problem's gradient norm is the projected gradient's at the point returned, where QuantLib's keeps the previous iterate's (Divergences/LBFGSBTests.cs). The breakpoints of the Cauchy search are sorted stably, so equal breakpoints keep QuantLib's order up to 32 variables (MSVC's insertion sort) and their own beyond, where MSVC's introsort reorders them.
