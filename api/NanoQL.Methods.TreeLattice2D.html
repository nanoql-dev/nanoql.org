Remarks

A node at step i is the pair of the two trees' nodes, numbered index₁ + index₂·n₁(i), n₁ the first tree's size at the step; a branch is the pair of the trees' branches, numbered branch₁ + branch₂·3. A branch's probability is the product of the trees', corrected for the correlation ρ by |ρ|·M[branch₁, branch₂]/36, QuantLib's matrix M mirrored where ρ is negative.

A derived class implements Discount(int, int). QuantLib's grid isn't implemented, and Grid(double) refuses with QuantLib's text. An extension point, as in QuantLib: the two-factor model's short-rate tree derives from it.
