The high-performance, high-precision American engine based on a fixed-point iteration for the exercise boundary (L. Andersen, M. Lake and D. Offengenden, "High Performance American Option Pricing", 2015; L. Andersen and M. Lake, "Fast American Option Pricing: The Double-Boundary Case", 2021), seeded by QD+'s boundary.

Remarks

The engine reports the value. Immutable: the three schemes QuantLib keeps as function statics are static singletons; each price builds its boundary, and the fixed-point steps' new values give a new interpolation on the same nodes (WithY(ReadOnlySpan<double>)), which the boundary function reads, where QuantLib updates its interpolation in place. The static Calculate builds an engine and prices through it. An extension point, as in QuantLib.
