Remarks

An extension point, as in QuantLib: the volatility matrix and the volatility cubes derive from it, and read the grid through QuantLib's protected data, kept as protected read-only members. QuantLib's structure whose reference date moves with the evaluation date recomputes its option dates, times and swap lengths when the date moves; a built structure here has a fixed reference date (a derived structure's factory computes it from the context, as Create(Calendar, BusinessDayConvention, IEnumerable<Period>, IEnumerable<Period>, Matrix, DayCounter, EvaluationContext, bool, VolatilityType, Matrix?) does), so its grid is computed once, in the constructor.

The option tenors and the swap tenors must be positive and increasing, the option dates after the reference date and increasing; the dates two tenors give aren't checked, as in QuantLib. Empty tenors or dates, which QuantLib reads at their first element, are refused there. The constructor from option dates keeps QuantLib's behaviour: its option tenors are zero periods, and its date interpolation maps every time to serial 0, so OptionDateFromTime(double) always throws.

The constructor reads DayCounter, Calendar and BusinessDayConvention to compute the grid, so they are sealed here: in C#, a call from a base constructor runs a derived override before the derived constructor has run, where C++ runs the base's own. A derived structure that answers another structure's conventions, as QuantLib's cube answers its ATM structure's, passes them to the constructor instead.

The date, its serial number the interpolated one truncated toward zero.

Remarks

QuantLib converts the interpolated serial to an integer with static_cast, whose result is undefined for NaN and for a value outside the integers; MSVC's conversion, the platform the vectors are generated on, gives the smallest integer there, which Date's range check refuses. That serial is taken here in those cases, so the refusal is QuantLib's.

Exceptions

ArgumentOutOfRangeException

The serial number is outside Date's range; always so for a structure built from option dates.
