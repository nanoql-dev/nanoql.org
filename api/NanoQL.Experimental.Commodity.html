Remarks

An extension point: EnergyCommodity derives from it. QuantLib's SecondaryCosts, a map from a name to a std::any, is a dictionary from a name to a CommodityUnitCost (a cost per unit delivered) or a Money amount (a fixed cost), kept in QuantLib's key order (ordinal); a value of any other type is ignored, as QuantLib's calculation skips it.

QuantLib keeps the secondary cost amounts and pricing errors on the instrument, mutable, its pricing errors never cleared between calculations, and lets any caller add one (addPricingError); here each calculation returns its own, in EnergyCommodityResults, and the instrument holds none.
