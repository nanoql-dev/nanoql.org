Remarks

QuantLib-Python's %template name for InterpolatedSpreadDiscountCurve<TInterpolator> on LogCubic: it adds constructors only. QuantLib's LogCubic has no default construction: a curve built without an interpolator refuses its zero value with InvalidOperationException, as the generic's does.
