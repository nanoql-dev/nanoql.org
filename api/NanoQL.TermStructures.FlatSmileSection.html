Remarks

QuantLib's date constructor without a reference date, whose section floats with the evaluation date, is Create(Date, double, DayCounter, EvaluationContext, double?, VolatilityType, double), which takes the evaluation context and fixes the date. The date forms need a day counter for the exercise time, which QuantLib's empty one can't give.
