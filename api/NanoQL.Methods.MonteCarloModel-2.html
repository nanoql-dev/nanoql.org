Remarks

The model holds a path generator and a path pricer, and in case of the control variate technique the control option's path pricer and value, with optionally the control's own path generator. Each sample is the pricer's value on a new path, corrected by the control variate, and averaged with its antithetic path's where antithetic variates are used, in QuantLib's order; it is added to the accumulator with the path's weight.

A working type: AddSamples(int) draws from its generators and adds to its accumulator, which it owns. A McSimulation<TPath, TStats> builds one per calculation and returns it. Each batch reserves the accumulator for its samples first, so a one-dimensional batch allocates nothing per sample.
