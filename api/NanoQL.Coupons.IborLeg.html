Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToLeg(EvaluationContext) builds the leg, in place of QuantLib's conversion operator; it takes the context because the default pricer it attaches reads the at-par switch when the leg has no explicit choice. A builder has no value equality: its vectors compare by reference.

A leg with neither caps, floors nor in-arrears fixing gets a BlackIborCouponPricer with no volatility, as QuantLib's does; any other leg is built without pricers, for SetCouponPricer(ImmutableArray<CashFlow>, FloatingRateCouponPricer?) to set.
