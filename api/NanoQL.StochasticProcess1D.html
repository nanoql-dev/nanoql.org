Remarks

An extension point, as in QuantLib: the 1-D processes derive from it. It implements the multi-dimensional interface of StochasticProcess through the 1-D members, on vectors and matrices of size 1, which QuantLib keeps private and nanoql exposes as the base's overrides.

Expectation(double, double, double), StdDeviation(double, double, double) and Variance(double, double, double) default to the process's discretization, as QuantLib's do; a process built without one overrides the three, or they refuse.
