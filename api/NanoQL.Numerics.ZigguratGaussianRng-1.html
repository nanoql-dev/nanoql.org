The Gaussian random-number generator by the ziggurat transformation: normally distributed deviates with average 0.0 and standard deviation 1.0, from random integers in the [0, 0xffffffffffffffff] interval supplied by TRng.

Remarks

For a more detailed description see the article "An Improved Ziggurat Method to Generate Normal Random Samples" by Jurgen A. Doornik (https://www.doornik.com/research/ziggurat.pdf). QuantLib's code is inspired by the rust implementation in https://github.com/rust-random/rand/blob/d42daabf65a3ceaf58c2eefc7eb477c4d5a9b4ba/rand_distr/src/normal.rs and https://github.com/rust-random/rand/blob/d42daabf65a3ceaf58c2eefc7eb477c4d5a9b4ba/rand_distr/src/utils.rs.

A mutable working type: each draw changes it, and it is not thread-safe. It copies the generator it is given, so the caller's later draws change nothing in it. Xoshiro256StarStarUniformRng is the only generator that implements IInt64Rng, as in QuantLib.
