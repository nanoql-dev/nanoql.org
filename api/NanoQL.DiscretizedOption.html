Remarks

The option rolls its underlying back with itself: at each time it is adjusted at, it rolls the underlying to its own time, pre-adjusts it, applies the exercise condition where an exercise time falls, then post-adjusts it. The underlying must be initialized on the option's lattice before the option's Reset(int); as QuantLib advises, a derived class creates and initializes the underlying itself.

An extension point, as in QuantLib: the discretized swaption derives from it.
