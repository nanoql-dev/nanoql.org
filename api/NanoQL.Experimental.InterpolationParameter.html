Remarks

Immutable, as every Parameter. QuantLib's holds an interpolation that reads its model's parameter array in place and is reset onto it; here the parameter holds its times and its interpolation factory, and its value at a time interpolates its own parameters, so a copy with another parameter (SetParam(int, double)) interpolates that one. Each evaluation builds the interpolation; a model that reads the parameter often builds it once from the parameter's current values.
