Remarks

A working type: QuantLib's mutable scratch is the calculator's own, its per-call vector of annuities among it, so it is owned by one computation and isn't thread-safe. The drifts' size is checked at every computation, QuantLib's extra-safety check.

QuantLib reads the curve state's annuities from the first rate, so a state set from the step's first alive rate on, all the drifts read, is refused ("invalid index"); here they are read from the first alive rate, which gives QuantLib's drifts bit for bit on a state set from the first rate (Divergences/SmmDriftAliveTests.cs).
