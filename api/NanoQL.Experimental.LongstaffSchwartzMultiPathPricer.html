The Longstaff-Schwartz path pricer for path payoffs (Longstaff and Schwartz, 2001, "Valuing American Options by Simulation: A Simple Least-Squares Approach", The Review of Financial Studies 14(1), 113-147): it stores the calibration paths, regresses the continuation value on each fixing's state, then prices on the fitted decisions.

Remarks

A working type: QuantLib's mutable calibration phase, stored paths and coefficients, owned by one engine call. At each fixing the regression's decision gives way to always or never exercising where either beats it on the calibration paths, as QuantLib's. A calibration on no path is refused, where QuantLib reads the first of none.
