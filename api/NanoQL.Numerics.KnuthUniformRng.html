Remarks

This is not Knuth's original implementation, which is available at http://www-cs-faculty.stanford.edu/~knuth/programs.html, but rather a slightly modified version wrapped in a class. Such modifications did not affect the code but only the data structures used, which were converted to their standard equivalents.

A mutable working type: each draw changes the generator, and it is not thread-safe. Its seed is explicit, in [1, 4294967295]: QuantLib's seed 0, which draws a seed from the clock, is refused. Only the seed's low 30 bits reach the state, as in QuantLib (Knuth's mask), so seeds differing above them draw one sequence.
