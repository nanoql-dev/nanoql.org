Remarks

A working type: mutable, owned by one computation and not thread-safe. The direction's operator is built at construction; SetTime(double, double) rewrites the step's operator in place with φ at the step's two ends' mean, and allocates nothing, the fitting reading the curve's forward through YieldTermStructure's internal ContinuousForwardRate, its bits ForwardRate's.

The model's dynamics are built once, at construction, where QuantLib's setTime calls model->dynamics() each step: the model is immutable, so they are the same each time.
