Remarks

Its UnderlyingSwap(Date, EvaluationContext) hides the base's and returns the overnight-indexed swap, as QuantLib's does. QuantLib overrides neither the forecast nor the maturity date, and both call the base's underlying swap, which is not virtual: so the inherited ForecastFixing(Date, EvaluationContext) and MaturityDate(Date) use a vanilla swap whose floating leg has a daily coupon on the overnight index, read as an Ibor index, and the forecast reads the at-par switch. nanoql keeps that, so the fixings are QuantLib's.

The telescopic-value-dates flag is kept, and passed to the overnight-indexed swap, which builds every daily value date. A clone is a plain SwapIndex, as in QuantLib, where the clones are inherited.
