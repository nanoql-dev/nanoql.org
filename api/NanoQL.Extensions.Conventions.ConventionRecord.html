Remarks

A record may name a base record of its kind and give only the fields it changes. A base of the record's own name is the record it replaces in the set below it; any other base is resolved through the whole set. A field comes from the record, then its base chain, then its builder's default record, then QuantLib's reference.

The kinds are closed: each is a sealed record of this assembly. A record keeps the foreign namespaced attributes and elements it was read with (Foreign), so another tool's annotations survive a read and a write.
