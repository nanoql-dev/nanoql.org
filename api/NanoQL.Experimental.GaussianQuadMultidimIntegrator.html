Remarks

Immutable; QuantLib's integration-variable buffer is a per-call buffer. The dimension runs from 1 to 15; QuantLib's entry points read integrationEntries_[dimension - 1], so a dimension of 0 or above 15 reads outside its 15 entries (multidimquadrature.hpp:193), which nanoql refuses.

The vector integration weights every node: QuantLib's applies its first node's weight inside a std::for_each that discards the result (multidimquadrature.hpp:61-64), so node n − 1 enters unweighted, E[M²] reading 1.0000000116 where the scalar rule reads 0.99999999995. nanoql's equals the scalar rule per component, bit for bit. A documented divergence (Divergences/VectorQuadratureWeightTests.cs).
