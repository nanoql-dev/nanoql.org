Remarks

The eigenvalues are sorted in decreasing order, each eigenvector with its first component non-negative. The decomposition is computed in the constructor; Eigenvalues() and Eigenvectors() return copies.

QuantLib's iteration has no bound, and on some inputs it never returns: eigenvalues in pairs of opposite sign under NoShift, and, under any strategy, a NaN, an infinite off-diagonal element or entries whose squares overflow. While one eigenvalue converges, the next step is a function of the diagonal and off-diagonal alone, so a state repeated bit for bit proves the iteration endless: Brent's cycle test on that state refuses there, and every input QuantLib answers keeps QuantLib's result (Divergences/TqrEigenDecompositionCycleTests.cs).

The test catches the inputs whose state repeats, as a zero diagonal's does, but not every pair: under NoShift a pair whose magnitudes differ slightly converges at their ratio without repeating a state, about 18.7/ε iterations for [[ε, 1], [1, ε]], and a pair equal only to rounding may never repeat one either. Such an input runs as long as QuantLib's, without end once the ratio rounds to 1: a QuantLib defect kept, since no bound on the iterations would separate these inputs from slow ones QuantLib answers. The shifted strategies, the default among them, converge on them.
