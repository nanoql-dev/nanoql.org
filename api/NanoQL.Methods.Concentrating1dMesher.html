Parameters

start double

The first point.

end double

The last point.

size int

The number of points, at least 2.

cPoints IEnumerable<(double Point, double Density, bool Required)>

The critical points: each its location, its density relative to the mesher's length, and whether it must be one of the mesher's points.

tol double

The tolerance of the differential equation's solver and of the scaling's root.

Exceptions

ArgumentNullException

cPoints is null.

ArgumentOutOfRangeException

size is negative.

ArgumentException

end isn't above start, or size is 0 or 1, where QuantLib writes past an empty array and leaves a one-point mesher's distances at its null value.

NanoQLException

The solver or a root search fails.
