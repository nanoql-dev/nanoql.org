Remarks

A working type: mutable, owned by one computation and not thread-safe. Increment() advances it in place, as QuantLib's operator++ does; Reset() returns it to the first point, so that a walk repeated every time step allocates nothing. Begin() returns a new one, as QuantLib's begin() does.
