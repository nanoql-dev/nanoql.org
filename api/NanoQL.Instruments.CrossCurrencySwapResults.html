The results an engine returns for a cross-currency swap: the swap's, in the NPV currency, with each leg's NPV and BPS in its own currency and its discount factor at the NPV date.

Remarks

Unsealed, as QuantLib's, since the constant-notional and mark-to-market swaps' results derive from it. A per-leg result QuantLib leaves null is null. Equality compares the per-leg arrays element by element.
