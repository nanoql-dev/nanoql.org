The base class of 1-D solvers: QuantLib's curiously recurring Solver1D<Impl>. It brackets the zero of a function, then hands the bracket to the solver's SolveCore<TF>(TF, double, Solver1DBracket).

Remarks

A concrete solver is declared as sealed class Foo : Solver1D<Foo, ISolver1DFunction> and implements SolveCore<TF>(TF, double, Solver1DBracket), which can assume what Solver1DBracket holds: a valid bracket, the function's values at its ends, and a valid initial guess.

Immutable: SetMaxEvaluations(int), SetLowerBound(double) and SetUpperBound(double) return a modified copy, where QuantLib's setters change the solver. The bracketing's state, which QuantLib keeps in mutable members, lives inside each Solve call.

An extension point, as in QuantLib: the other 1-D solvers derive from it.

Solve<TF>(TF, double, double, double)

The zero of f, determined with the given accuracy ε: depending on the solver, the returned x is such that |f(x)| < ε, or |x − ξ| < ε where ξ is the real zero. A bracketing routine first searches for a bracket, from the initial guess, in steps of step that grow by 1.6 each time.

Solve<TF>(TF, double, double, double, double)

The zero of f, determined with the given accuracy ε, within a bracket: either f(xMin) ≤ 0 ≤ f(xMax), or f(xMax) ≤ 0 ≤ f(xMin). Depending on the solver, the returned x is such that |f(x)| < ε, or |x − ξ| < ε where ξ is the real zero.
