Remarks

An empty selection, which the parameterless constructor builds, means broken periods fix on the leg's own index as usual. A non-empty one supplies the candidate indices used instead, as fully built objects, so that each uses its own conventions, stored fixings and forwarding curve.

For ClosestIndex, the index whose maturity is closest to the coupon's end date is used. For Interpolated, the two index maturities bracketing the coupon's end date are used for linear interpolation in calendar days. The weights depend on the accrual dates.
