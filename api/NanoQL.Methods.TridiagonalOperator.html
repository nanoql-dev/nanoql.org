Remarks

A working type: mutable, owned by one computation and not thread-safe. The row setters and SetTime(double) change it; the operators return new operators. Clone() is the deep copy, where QuantLib copies an operator by value.

An extension point, as in QuantLib: the finite-difference operators derive from it. A derived operator reads and sets the diagonals through the protected fields, and makes itself time-dependent by setting timeSetter. To use real time-dependent algebra, a time-dependent derived operator overloads the operators, which here build operators without a time setter.
