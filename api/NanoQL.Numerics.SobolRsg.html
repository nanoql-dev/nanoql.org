Remarks

The implementation relies on primitive polynomials modulo two from the book "Monte Carlo Methods in Finance" by Peter Jäckel; 21 200 of them are provided, so the dimensionality is at most 21,200. The choice of initialization numbers (also known as free direction integers) is crucial for the homogeneity properties of the sequence (SobolRsgDirectionIntegers). For more info on Sobol' sequences see also "Monte Carlo Methods in Financial Engineering," by P. Glasserman, 2004, Springer, section 5.2.3.

A mutable working type: each draw changes the generator, and it is not thread-safe. A draw returns a view of the generator's buffer, valid until its next draw. The seed, in [1, 4294967295], only affects the direction integers beyond those tabulated for the chosen set, so lower dimensionalities give the same sequence for any seed; QuantLib's seed 0, which there draws a seed from the clock, is refused.

With the Gray code, the counter stops one short of QuantLib's period: SkipTo(long) refuses 4294967295, and the draw that would take the counter there throws "period exceeded", where QuantLib's behaviour is undefined.

Remarks

The so called generating integer is chosen to be γ(n) = n if useGrayCode is false and γ(n) = G(n), where G(n) is the Gray code of n, otherwise. The Sobol integers are then constructed using formula 8.20 resp. 8.23, see "Monte Carlo Methods in Finance" by Peter Jäckel. The default is to use the Gray code since this allows a faster sequence generation.
