Remarks

An extension point, as in QuantLib. The algorithm copies its walk (Clone()) for each minimization, so each minimization starts the walk's generators from their seeds, where QuantLib's continues them from the last; it binds the copy to that minimization's population, which the protected members read, and calls Init().
