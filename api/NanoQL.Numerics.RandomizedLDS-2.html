The randomized (random shift) low-discrepancy sequence: it random-shifts a uniform low-discrepancy sequence of dimension N by adding, modulo 1 in each coordinate, a pseudo-random uniform deviate in (0, 1)^N. It is used for implementing randomized quasi-Monte Carlo.

Remarks

The uniform low-discrepancy sequence is supplied by TLds; the uniform pseudo-random sequence by TPrng; both must have the same dimension N. Inverting the two is possible, but it doesn't make sense. The construction from a seed is RandomizedLDS's.

A mutable working type: each draw changes it, and it is not thread-safe. A draw returns a view of its buffer, valid until its next draw. It copies the generators it is given, so the caller's later draws change nothing in it.

A coordinate whose sum is exactly 1.0 wraps to 0.0 here, so every point lies in [0, 1)^N; QuantLib's test is x > 1.0, which leaves it at 1.0 (Divergences/RandomizedLdsTests.cs).
