Remarks

QuantLib builds the adapter on a reference date that moves with the evaluation date, the stripper's settlement days after it: here that is Create(StrippedOptionletBase, EvaluationContext), which takes the context and fixes the date. A stripper without settlement days, on a surface built on a fixed date, is refused, as QuantLib refuses it.

The strike interpolation at each fixing date is built with the adapter, where QuantLib builds it at its first use; the time interpolation and the smile sections are built at each call, as QuantLib's are. A smile section is a cubic spline over the first fixing date's strikes, with a Lagrange boundary from four strikes and a natural one below.
