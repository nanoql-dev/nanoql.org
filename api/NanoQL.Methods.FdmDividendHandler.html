Remarks

A working type: the interpolation runs on buffers the handler holds, by LinearInterpolation's arithmetic, so applying it allocates nothing, where QuantLib copies the values at every step and builds an interpolation at each dividend.

Every line along the equity direction moves. QuantLib walks, for each other direction, only the lines through the other directions' first points (fdmdividendhandler.cpp:84-103), which covers a two-dimensional grid but in three or more dimensions leaves the rest as they were: on a 3 × 5 × 4 grid, 6 of the 12 lines. Each line here moves as QuantLib's one-dimensional handler moves it, which is QuantLib's check; in one and two dimensions the values are QuantLib's. A documented divergence.
