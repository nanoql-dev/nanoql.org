The collateralized debt obligation: a mezzanine CDO tranche, its loss given default between the attachment D₁ and the detachment D₂ > D₁. For purchased protection the value is the protection value V₁ less the premium value V₂.

Remarks

The protection leg: the probability distribution of the loss given default LGD = (1 − r)·L is built at the premium schedule's dates with intermediate steps tᵢ, the expected protection payoff Eᵢ = E[Pay(LGD)] at each, Pay(L) = min(D₂, LGD) − min(D₁, LGD), and V₁ = Σᵢ (Eᵢ − Eᵢ₋₁)·dᵢ with dᵢ the discount factor at tᵢ. The premium is paid on the protected notional, D₂ − D₁ less the expected protection payments: V₂ = m·Σᵢ (D₂ − D₁ − Eᵢ)·Δᵢ₋₁,ᵢ·dᵢ, with m the premium rate and Δ the day count fraction. The loss distribution is Hull and White's probability bucketing ("Valuation of a CDO and nth to default CDS without Monte Carlo simulation", Journal of Derivatives 12, 2, 2004), which allows varying notionals and default term structures. To be done, as in QuantLib: the cases where Eᵢ₊₁ < Eᵢ, which Error counts.

QuantLib's older CDO, computed by the instrument itself: Calculate(EvaluationContext), nothing cached. Its "today" is the yield curve's reference date, as QuantLib's. The maximum loss given default Lgd is the sum of the names' losses given default, which QuantLib's sums onto an uninitialized value (cdo.cpp:73-77). A default probability before its curve's reference date is 0, where QuantLib's refuses it.
