An early-exercise path pricer: the value of exercising an option on a given path at a given time step, the state the regression reads there, and the regression's basis functions of that state.

public interface IEarlyExercisePathPricer<TPath, TState>

Type Parameters

TPath

The path type, MonteCarloPath or MultiPath.

TState

The state type, QuantLib's EarlyExerciseTraits<PathType>::StateType: a double on a single path, a Vector on a multi-path.

Remarks

QuantLib's base class, an interface here, as its only members are abstract. Its time and value types are QuantLib's defaults, a time-step index and a real; its traits, which name the state type and a path's length, are the type parameter.
