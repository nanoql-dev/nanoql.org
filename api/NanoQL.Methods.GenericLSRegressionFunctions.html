Methods

GenericLongstaffSchwartzRegression(NodeData[][])

Regresses each exercise's continuation value on its basis functions, from the last exercise back, and adds each valid path's value at an exercise, the exercise value where it beats the estimated continuation and the cash flows after it otherwise, into the path's cash flows at the exercise before; the estimate is the paths' mean at the start.

public static GenericLSRegressionResults GenericLongstaffSchwartzRegression(NodeData[][] simulationData)

Parameters

simulationData NodeData[][]

The node data, an exercise a row and a path a column, changed in place.

Returns

GenericLSRegressionResults

The biased estimate and each exercise's coefficients.

Remarks

The data are QuantLib's: n exercises give n + 1 rows, row 0 each path's cash flows before the first exercise and row i + 1 its data at exercise i. The cash flows of every row before the last are changed in place, as QuantLib changes them.

The number of basis functions is the first valid path's (a documented divergence): QuantLib takes path 0's, valid or not, and a path ended before an exercise has none, so the valid paths' values are copied past a one-entry buffer (genericlsregression.cpp:39). An exercise no path reaches is refused, with the parametric optimisation's text.

Exceptions

ArgumentException

There's no row, a row is shorter than the one after it, or a valid path holds another number of values than the exercise's first valid path, inputs QuantLib writes past or reads stale.

NanoQLException

No path is valid at an exercise.
