Remarks

The generated calibrating swaptions have a strike floored at 0.1bp (minus the lognormal shift, if applicable); this is not true for at-the-money swaptions, whose strike the swaption helper generates. The standard swap base index should have forwarding and discounting curves, which the helpers' market prices read, so the model's prices in a calibration must read the same curves; the volatility structure should be consistent with them, and the engine's discount curve should be the index's discounting curve.

Immutable; the derived engines (Gaussian1dNonstandardSwaptionEngine and the float-float one) bind the underlying an instrument gives, where QuantLib's read the arguments they hold. A flipped match, a negative nominal read as the other swap type, gives its helper the nominal's size, where QuantLib floors the signed nominal at 1e-6 first and so gives 1e-6 (basketgeneratingengine.cpp:213-214, :230).
