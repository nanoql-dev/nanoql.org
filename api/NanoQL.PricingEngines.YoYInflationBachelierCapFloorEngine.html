Remarks

A static class: Calculate runs QuantLib's four steps (playbook §2.1) and returns the instrument's results, with QuantLib's additional results, read by Result<T>(string), each per optionlet and an ImmutableArray<T> of double: optionletsPrice, optionletsAtmForward (0 for an optionlet paid on or before the nominal curve's reference date) and optionletsStdDev, which a collar's results don't hold, as QuantLib's don't. QuantLib's setVolatility has no form: a call takes the volatility.

Each optionlet's forward is its coupon's own fixing: the published fixing once it is out, the forecast before, where QuantLib's reads the index's curve at the fixing date, a documented divergence. The index needs its year-on-year curve only where a forecast is needed, and refuses with QuantLib's empty-handle text there.
