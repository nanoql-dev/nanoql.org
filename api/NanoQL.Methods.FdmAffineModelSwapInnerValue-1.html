Remarks

QuantLib clones the swap onto relinkable handles and, at each point, links them to a new FdmAffineModelTermStructure for the point's state, whose notifications make the floating coupons forecast on it. nanoql has no relinkable handles; the inner value holds, for each exercise date as QuantLib links a new curve there, a private proxy curve pair whose state it sets at each point, the swap rebuilt on its index cloned onto the forwarding proxy. The proxies and the swap are a working state: they never leave the object, which is owned by one computation and not thread-safe. The models' dynamics are built once.

A time not in the exercise map is refused, where QuantLib reads find(t)->second on end(), undefined behaviour, which an American exercise's step condition reaches (the playbook's undefined-behaviour row).

An extension point only for QuantLib-Python's two named classes, FdmAffineG2ModelSwapInnerValue and FdmAffineHullWhiteModelSwapInnerValue.
