Remarks

A value: its zero value, default(Money), is QuantLib's Money(), 0.0 in the empty currency, a null Currency.

The operators combine amounts in one currency as QuantLib's do, and never convert: QuantLib's operators read the global Money::Settings, and these see no context, so they behave as under its NoConversion. On a currency mismatch every operator but == and != throws QuantLib's "currency mismatch and no conversion specified"; == returns false and != true, where QuantLib's throw. The conversion modes are methods that take the context, which holds the settings (MoneySettings) and the exchange rates (ExchangeRates): Add(Money, EvaluationContext), Subtract(Money, EvaluationContext), Divide(Money, EvaluationContext), Equals(Money, EvaluationContext), LessThan(Money, EvaluationContext), LessThanOrEqual(Money, EvaluationContext), GreaterThan(Money, EvaluationContext), GreaterThanOrEqual(Money, EvaluationContext), and MoneyFunctions' Close and CloseEnough.

Equals(Money) and GetHashCode() compare the currency and the value, the value by Equals(double), so that equality is reflexive, as .NET's own double keeps == IEEE's.
