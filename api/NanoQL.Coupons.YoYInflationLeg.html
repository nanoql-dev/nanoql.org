A helper class building a sequence of year-on-year inflation coupons: QuantLib's yoyInflationLeg.

Remarks

An immutable builder: each method returns a modified copy. ToLeg() builds the leg, in place of QuantLib's conversion operator, and attaches QuantLib's default YoYInflationCouponPricer, as QuantLib does when there are no caps or floors; a leg with caps or floors needs a pricer set on it, as QuantLib's comment says. A period with a zero gearing is a fixed-rate coupon paying its spread, capped and floored; a period with a cap or a floor a CappedFlooredYoYInflationCoupon. A builder has no value equality.
