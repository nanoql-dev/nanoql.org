The Longstaff-Schwartz Monte Carlo engine for early-exercise options (Francis Longstaff, Eduardo Schwartz, 2001, "Valuing American Options by Simulation: A Simple Least-Squares Approach", The Review of Financial Studies, Volume 14, No. 1, 113-147): a calibration simulation whose paths the Longstaff-Schwartz pricer regresses, then the pricing simulation on the same pricer.

Remarks

An extension point and an immutable object: a concrete engine's static Calculate builds one per call and implements LsmPathPricer(). Run() builds the pricer, adds the calibration samples on the calibration traits' generator, calibrates, prices on the same pricer and returns the model with the call's exercise probability: QuantLib's mutable pricer and calibration model are the call's working state, and the pricer reaches the pricing model as the call's argument, not as a member, so two calls can share one engine object.

The calibration samples default to 2,048, and the calibration's Brownian bridge and antithetic variates to the pricing's. The calibration seed defaults to the pricing seed plus 1,768,237,423, modulo 2³² as MSVC's 32-bit unsigned long computes it, as QuantLib's documentation says; QuantLib's code compares the narrowed Null<Size>() with Null<Real>(), so its default is always the narrowed null: a documented divergence (Divergences/LongstaffSchwartzCalibrationSeedTests.cs); QuantLib's engine with that seed passed reproduces this one's default. Where that default is 0, at the pricing seed 2,526,729,873, it is refused, since QuantLib reads 0 as a seed from the clock.

The pricer exercises only at the exercise times on the grid (ExerciseTimes(TimeGrid)): a Bermudan option's dates, and an American option's grid times from its earliest exercise.
