Remarks

Immutable (§2.2's quote row): the value is required, so QuantLib's isValid, setValue and reset, which a mutable quote with a null value needs, aren't ported; a new value is a new quote.

ISDA's conventional recoveries cover the five ISDA seniorities. QuantLib's table read for NoSeniority reads past its five entries (recoveryratequote.hpp:36-37), which nanoql refuses (Divergences/ConventionalRecoveryNoSeniorityTests.cs).
