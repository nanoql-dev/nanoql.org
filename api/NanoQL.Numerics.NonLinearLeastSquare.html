Remarks

Immutable, with QuantLib's settings: Perform(LeastSquareProblem, ReadOnlySpan<double>) takes the initial value and returns the results, where QuantLib's object holds both. QuantLib's iterationsNumber() isn't ported: it returns a member QuantLib never sets (leastsquare.cpp:109, its assignment commented out), its value undefined. The results are the point the method returns: on the conjugate gradient, the last one its line search accepted (Divergences/LineSearchReturnTests.cs), where QuantLib's is the point before; the residual norm, the function value there, is QuantLib's.
