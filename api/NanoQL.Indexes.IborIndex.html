Remarks

Unsealed, as in QuantLib, where the presets derive from it. The index holds its forecasting curve, QuantLib's handle; null is QuantLib's empty handle, with which past fixings still work and a forecast throws. QuantLib's relinking of the handle is building the index, and what holds it, on another curve, which Clone(YieldTermStructure?) does.
