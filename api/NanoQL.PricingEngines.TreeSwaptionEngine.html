Remarks

A static class: each Calculate overload runs QuantLib's four steps (playbook §2.1), the model an argument where QuantLib's engine holds it. QuantLib's constructors are its overloads: on a number of time steps, the lattice built per call on a grid through the swaption's mandatory times; on a time grid, the model's lattice on it, which QuantLib's engine builds once and nanoql builds per call; and on a built lattice, which a caller reuses by passing it in. The swaption is rolled back to its first exercise time on or after the reference date, and its value is its present value there.

The engine is not guaranteed to work if the underlying swap has a start date in the past, before the reference date: prune the swap's initial part so that it starts at t ≥ 0. The term structure is needed only when the model can't provide one: a model that is an ITermStructureConsistentModel gives the reference date and day counter of the times from its own curve, as QuantLib's engine does, whatever curve is given.

Exceptions

ArgumentNullException

An argument but the term structure is null.

NanoQLException

The swaption's terms are inconsistent, it is cash settled at the par yield curve, the model has no curve and none is given, the lattice's grid lacks one of the swaption's times, no exercise time is on or after the reference date, or the swaption can't be discretized.
