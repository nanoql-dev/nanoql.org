Remarks

QuantLib's class wraps Boost.Accumulators' weighted accumulator set (count, minimum, maximum, weighted mean, variance, skewness and kurtosis, and the sum of weights) and a second set over the negative samples (count, weighted second moment, sum of weights). This port keeps each feature's running value and updates them in Boost's order, through the ported Boost arithmetic: the weighted variance's iterative recurrence on the lazy weighted mean, the moments' powers by squaring, the minimum and maximum starting from ±MaxValue. That order gives QuantLib's results bit for bit.

A working type: Add(double, double) and Reset() change it; it isn't thread-safe. Skewness() and Kurtosis() refuse a set whose samples weigh 0 in all, with the text Mean() refuses it with, where QuantLib's divide 0 by 0 and return NaN: a documented divergence. The weighted variance's recurrence resets the variance to 0 at a sample whose predecessors' weights vanish in the sum (they weigh 0, or less than its rounding), where Boost's divides 0 by 0, or x by 0, and leaves Variance() NaN or infinite for good: a documented divergence, the variance then that of the samples that carry the weight, as GeneralStatistics' is.
