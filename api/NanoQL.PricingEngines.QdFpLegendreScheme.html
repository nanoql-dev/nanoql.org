Class QdFpLegendreScheme

Namespace
NanoQL.PricingEngines
Assembly
NanoQL.dll

The Gauss-Legendre (l, m, n)-p scheme: Gauss-Legendre integration of order l within every fixed-point step; m fixed-point steps, the first a partial Jacobi-Newton one, the rest naive Richardson ones; n Chebyshev nodes interpolating the exercise boundary; Gauss-Legendre integration of order p converting the boundary into the price.
