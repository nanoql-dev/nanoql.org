Remarks

An extension point, as in QuantLib: the methods derive from it and give the new search direction (ConjugateGradient, SteepestDescent, BFGS). Immutable: it holds its line search as a prototype and runs each minimization on a new one (NewSearch()), which it passes to GetUpdatedDirection(ProblemState, double, Vector, LineSearch), where QuantLib's method mutates one line search across minimizations and its derived classes read it as a member.

A method that keeps state through a minimization (BFGS's inverse Hessian, which QuantLib's keeps as a member across minimizations) returns it from NewMinimizationState(ProblemState) at each minimization's start and reads it in the five-argument GetUpdatedDirection(ProblemState, double, Vector, LineSearch, LineSearchBasedMethodState?); a method without state overrides the four-argument member, which the five-argument one calls by default. A method overriding neither is refused at its first direction.

The problem's current value is the last point the line search accepted at every return, where QuantLib's minimize returns on the function tolerance or the iteration cap before setting it, leaving the point before with the function value of the point after: a documented divergence (Divergences/LineSearchReturnTests.cs).
