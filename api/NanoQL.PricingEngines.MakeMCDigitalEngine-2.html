Remarks

An immutable builder: each method returns a modified copy. ToEngine() returns the engine as a function of the option and the context, its settings bound, in place of QuantLib's conversion to a pricing engine, with QuantLib's checks on the steps. A builder has no value equality.

The seed is a constructor argument (as in MakeMCHullWhiteCapFloorEngine<TRng, TStats>): QuantLib's default, 0, a seed from the clock, is refused.
