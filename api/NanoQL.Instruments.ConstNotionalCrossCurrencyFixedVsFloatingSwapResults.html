The results an engine returns for a constant-notional cross-currency fixed-vs-floating swap: the cross-currency swap's, with the fair fixed rate and the fair floating spread.

Remarks

The fair rate and spread are null where QuantLib's readers throw "Fair fixed rate is not available" and "Fair spread is not available": an expired swap's, or one whose leg's BPS is unknown or zero.
