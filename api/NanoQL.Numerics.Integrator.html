Remarks

Immutable: SetAbsoluteAccuracy(double) and SetMaxEvaluations(int) return copies. QuantLib keeps the number of evaluations and the error estimate of the last call in mutable members, the count reset by operator() (integral.cpp:76-86); here IntegrateWithStatistics(Func<double, double>, double, double) returns both with the value, the error null where QuantLib's integrator computes none, and IntegrationSuccess(IntegrationResult) reads them from the result.
