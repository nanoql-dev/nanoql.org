Remarks

A static class: Calculate takes the engine's inputs and returns the results, in place of QuantLib's engine object, whose discountCurve() accessor has no instance to belong to. A cash flow on the settlement date never counts in the settlement value, whatever the NPV counts. A bond whose engines take other arguments, such as a callable bond, is refused after the expiry check, as QuantLib's refuses it when it sets up the engine's arguments.
