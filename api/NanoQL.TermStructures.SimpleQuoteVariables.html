Remarks

A variable with a lower bound lb is optimized as log(v − lb), its value exp(x) + lb; one without is optimized as itself. As QuantLib's detail::get reads them, a variable past the guesses given takes the last guess, or 0 where none is given, and one past the bounds given takes the last bound, or none where none is given.

Immutable: QuantLib's variables are quotes the optimizer writes and the helpers read; here Values(ReadOnlySpan<double>) returns the values, which the global bootstrap's VariableHelpers reads, and the curve keeps the optimum's. Since a nanoql curve is always built afresh, Initialize(bool) gives the guesses whatever its argument, where QuantLib's reads the quotes' values, a previous bootstrap's, on a valid curve.
