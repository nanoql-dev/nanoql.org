Remarks

Let α and β be two scalars in [0, 1], x the current value of the unknown, d the search direction and t the step, and f the function to minimize. The line search stops when t verifies f(x + t·d) − f(x) ≤ −α t f′(x + t·d) and f(x + t/β·d) − f(x) > −α/β t f′(x + t·d) (see Polak, Algorithms and consistent approximations, Optimization, volume 124 of Applied Mathematical Sciences, Springer-Verlag, NY, 1997).
