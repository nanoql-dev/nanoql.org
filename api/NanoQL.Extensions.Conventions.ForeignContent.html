Another tool's content kept on a record or a document's root: the attributes and elements in a namespace other than the conventions', each as the XML text it was read as, compared by content.

Remarks

An element is kept with its namespace declarations, so it writes back alone. On a record the elements follow its fields; on a root each element keeps its place among the records (ConventionSnapshot).
