Remarks

A pricer is a stateless function of the coupon and the context: each member computes, inside the call, the per-coupon values that QuantLib's initialize(coupon) stores in the pricer before its queries. So one pricer may serve any number of coupons, on any thread, and a query never depends on another coupon's earlier one. A capped or collared coupon reads its three rates through an internal per-call view of them, which a pricer whose per-coupon state costs more than its queries overrides to build that state once, as QuantLib's one initialize serves them.
