Remarks

stats.GaussianValueAtRisk(0.99) reads as QuantLib's on GeneralStatistics (QuantLib's GaussianStatistics and, with the empirical measures, its Statistics), on IncrementalStatistics and on StatsHolder. Where QuantLib builds a distribution from mean() and standardDeviation() as constructor arguments, the standard deviation is read first, as MSVC, which built QuantLib's wheel, evaluates the arguments; it decides which refusal a set too small for both gives.
