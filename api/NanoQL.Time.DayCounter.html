Remarks

Two day counters are equal when they are of the same type and have the same name; one whose counts read data its name leaves out compares that data too: Business252 its calendar, as calendars compare, ActualActual with the ISMA or Bond convention the period dates of its schedule, and Thirty360 with the ISDA convention its termination date. QuantLib compares names alone (daycounter.hpp:135-138), which is sound there only where a name fixes the counts. Comparing the runtime types keeps equality symmetric when a derived day counter compares more than this does.

QuantLib's empty day counter, DayCounter(), is null.
