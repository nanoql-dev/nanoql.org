Remarks

An extension point, as QuantLib's template: an immutable base over McSimulation<TPath, TStats> holding one call's option and settings; a derived engine gives the path pricer and, for a control variate, its path pricer and engine. The grid runs to the reset and to expiry on the process's times, as the derived engine clocks it; the seed is explicit.
