The working state of a curve under construction, seen without its term structure's type: what a global bootstrap's penalties and initial-guess function read (BootstrapState<TTermStructure> implements it).

public interface IBootstrapState

Remarks

QuantLib's penalties and guess functions reach the curve's data and the helpers through the user's own pointers, which the bootstrap has linked to the curve. Here they receive the state, whose helpers are the copies bound to the curve under construction, so they price against the curve as QuantLib's do.
