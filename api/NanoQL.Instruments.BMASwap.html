Remarks

The type, payer or receiver, refers to the BMA leg. The Libor leg is the first leg, Ibor coupons geared by the Libor fraction with the Libor spread; the BMA leg is the second, average-BMA coupons. Each leg's payments follow its schedule's convention.

The constructor builds the Libor leg with the index's default pricer, which reads the context's at-par switch, so it takes the context. It refuses a type that isn't a member of SwapType on entry, before it builds the legs, where QuantLib refuses it after them. An engine's results are a BMASwapResults, with QuantLib's inspectors derived from the swap's results.
