Remarks

QuantLib's two constructors, a volatility and a quote, collapse into one, since a quote is a double; both take settlement days, so the reference date moves with the evaluation date, and the structure is built by Create(double, int, Calendar, BusinessDayConvention, DayCounter, Period, Frequency, bool, EvaluationContext, double, double, VolatilityType, double), which fixes it.
