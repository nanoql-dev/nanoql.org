Remarks

An immutable builder: each method returns a modified copy. ToLeg(EvaluationContext) builds the leg, in place of QuantLib's conversion operator: one coupon per schedule period, a fixed coupon at the spread where the gearing is zero, each floating coupon observing the index on a schedule of the observation tenor from its start to its end. No pricer is set. A builder has no value equality.

QuantLib's leg is built as Leg leg(n) and then filled with push_back, so it holds n null cash flows before its n coupons; here it holds the coupons alone. With no observation tenor, QuantLib's Period(), a coupon has no observation dates and QuantLib's rate is 0/0; here such a leg is refused. A missing trigger is QuantLib's Null<Rate>(), its value, which a coupon's checks and pricer read as QuantLib's do.
