Remarks

Immutable: the rollback runs in the constructor, where QuantLib's solver runs it lazily on the first query (Fdm2DimSolver's form). A value is a bicubic spline in each layer of the third coordinate, then a monotonic natural cubic spline across the layers, QuantLib's. A snapshot just after the start gives the theta.
