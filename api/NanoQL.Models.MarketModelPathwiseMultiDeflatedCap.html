Remarks

A working type: it steps its own deflated caplets (MarketModelPathwiseMultiDeflatedCaplet) and copies each caplet's cash flow into each cap holding it, QuantLib's assignment (CopyFrom(MarketModelPathwiseMultiProductCashFlow)).
