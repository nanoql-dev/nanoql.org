An interpolation factory that builds a curve a section at a time: the interpolator LocalBootstrap needs, QuantLib's localInterpolate and dataSizeAdjustment (of its interpolators, only ConvexMonotone has them).

public interface ILocalInterpolator : IInterpolator

Remarks

The members are instance members, as Calculate<TTermStructure, TTraits, TInterpolator>(BootstrapState<TTermStructure>, TInterpolator, EvaluationContext) holds the interpolator's instance and checks it at run time, where QuantLib's template fails to compile. An extension point: an interpolator of one's own implements it.
