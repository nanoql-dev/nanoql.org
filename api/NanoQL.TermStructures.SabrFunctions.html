Remarks

The expansions keep QuantLib's order of operations, so their values are QuantLib's bit for bit wherever the C runtime's functions agree with .NET's. A VolatilityType outside its members is refused on entry, where QuantLib takes any value other than Normal as lognormal.

SabrGuess(double, double, double, double, double, double, double, double, double, double, VolatilityType)

Le Floc'h and Kennedy's initial guess for a SABR calibration (Le Floc'h and Kennedy, "Explicit SABR Calibration through Simple Expansions"): the parameters matching the at-the-money volatility, skew and curvature that three volatilities around the forward give.

public static ImmutableArray<double> SabrGuess(double k_m, double vol_m, double k_0, double vol_0, double k_p, double vol_p, double forward, double expiryTime, double beta, double shift, VolatilityType volatilityType)

The guesses α, β, ν and ρ, in that order.

Remarks

A non-finite argument is refused, where QuantLib computes on it: a NaN smile gives ρ the sign of a NaN, which depends on which NaN an operation keeps, so QuantLib's value there isn't a number a caller can use. α is the smallest positive root of the guess's cubic, or its first estimate where the cubic has none, as QuantLib's.
