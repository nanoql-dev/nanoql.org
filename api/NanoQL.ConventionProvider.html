Remarks

The provider follows CultureInfo's shape. QuantLib returns QuantLib's coded values unchanged; Default is the system's defaults, QuantLib until set; Current is the innermost active scope's provider, opened by Use(ConventionProvider), or else Default. A scope flows with asynchronous calls, as a culture does, so two flows can build under two providers side by side. A provider is immutable: setting Default replaces it whole.

A preset reads Current once, in its constructor, and passes its QuantLib values, its reference, to the provider, which returns the values to use: the reference unchanged when nothing is configured. A preset's nested presets (an index's calendar, a currency's triangulation currency) are built inside the same provider's scope, so a construction takes all its values from one provider.

The provider is read only when an object is built, never while it prices, so a price doesn't depend on the scope it runs in. An index keeps the provider it was built with, and every clone of it keeps the same one. A market builder takes the provider of its index, reads its defaults for the options it isn't given from it when it builds, and builds inside it; the CDS builder, with no index, takes the provider current when it is created. An object that builds a builder inside passes its own provider to it: a swap index's underlying swap takes the swap index's provider, even on an Ibor index built under another, so its defaults are the swap index's provider's and its floating leg's conventions the Ibor index's. Whatever is built on an index after its construction follows the index: a swap index's underlying swap, a rate helper's swap when a bootstrap re-dates it, an engine's auxiliary swaps. An object that builds after its construction with no index to follow keeps Current from its construction. QuantLib's registry defaults (Default, Default and EvaluationContext's defaults) are built under QuantLib, whatever is current when they are first read.

So a change of Default reaches the objects built after it, and everything built on them. Objects built before it keep their conventions, and an object built on an index takes that index's provider, so set Default before building indexes, and rebuild them to take a change, as curves are rebuilt.

A provider of a user's own (a database's, a service's) derives from this class and overrides the members whose values it configures. Each member takes the preset's or the builder's name and its reference and returns the values to use, and the base class returns the reference. Every member is called inside the provider's own scope.

Use(ConventionProvider)

Opens a scope in which Current is the given provider on this asynchronous flow, until the returned object is disposed.

public static IDisposable Use(ConventionProvider provider)

Parameters

provider ConventionProvider

The provider.

Returns

IDisposable

The scope, which restores the previous one when disposed.

Remarks

The scope flows with asynchronous calls started inside it, and a flow started outside it doesn't see it. Scopes nest: disposing one restores the scope that was active when it was opened.

Exceptions

ArgumentNullException

provider is null.
