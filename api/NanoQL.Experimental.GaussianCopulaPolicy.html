The Gaussian latent model's copula policy: standard normal systemic and idiosyncratic factors, so that the latent variables are standard normal too, by the Gaussian's stability under convolution.

Remarks

A readonly struct built by Create(ImmutableArray<ImmutableArray<double>>, GaussianCopulaPolicyInitTraits). Its zero value isn't usable: QuantLib's default construction reads the first row of an empty weight matrix (gaussiancopulapolicy.hpp:40-43), so every member of default(GaussianCopulaPolicy) throws InvalidOperationException.
