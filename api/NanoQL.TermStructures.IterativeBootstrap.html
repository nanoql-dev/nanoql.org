The universal piecewise-term-structure bootstrapper: each node is solved in turn so that the helper whose pillar it is reprices its quote, and the passes repeat until the nodes stop moving when the interpolation is global or a pillar comes before its helper's latest relevant date.

Remarks

A configuration struct (IBootstrap): its zero value is QuantLib's default construction, every field stored so that zero reads as QuantLib's default. It reproduces QuantLib's sequence: the helpers sorted by pillar, the expired ones skipped, Brent's solver on the first pass and FiniteDifferenceNewtonSafe once the data are valid, the retries with widened brackets, the fallback without throwing, the convergence loop, and the node keeping the last value the solver evaluated, since QuantLib ignores the solver's return value.

On its first pass QuantLib builds the interpolation over the nodes solved so far before each node's values are known, and takes linear interpolation instead where a global interpolation refuses to be built over that many points. The interpolation here is built with its values in one call, so the fallback is decided by the interpolator's own construction checks, CheckPoints(int); every other refusal of the interpolation is met when the solver builds it, as QuantLib meets it when the interpolation is updated. The interpolator chosen on the first pass's last node serves the later passes and the built curve.

A curve is always built afresh, so its bootstrap starts from the traits' first guess: QuantLib re-bootstraps a curve whose quotes changed from its previous state, which the two reach within the bootstrap's accuracy (a documented divergence).

Parameters

accuracy double?

The accuracy of the bootstrap's stopping criterion; null takes the curve's.

minValue double?

The initial lower bound of each node's search; null takes the traits'.

maxValue double?

The initial upper bound of each node's search; null takes the traits'.

maxAttempts int

The attempts on each node in each pass: more than 1 implies retries.

maxFactor double

The factor widening the upper bound on each retry, at least 1.

minFactor double

The factor widening the lower bound on each retry, at least 1.

dontThrow bool

Whether a node the solver fails on takes the value of least error on a grid between its bounds instead of throwing, and a pass limit reached keeps the curve as it is.

dontThrowSteps int

The grid's steps when dontThrow is set.

maxEvaluations int

The solvers' maximum number of function evaluations.

Exceptions

ArgumentException

maxFactor or minFactor is below 1.

ArgumentOutOfRangeException

maxAttempts, dontThrowSteps or maxEvaluations is negative.
