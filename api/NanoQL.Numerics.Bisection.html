Remarks

QuantLib's exit on a midpoint whose value is close to 0 returns its running root, the bracket's low side, where the midpoint's value is above 0: x − 1.5 + 1e-30 on [0, 3] returns 0. nanoql returns the midpoint there, QuantLib's own return wherever the midpoint's value is at or below 0 (a documented divergence).
