A named calendar on a base calendar with holidays added or removed (Calendar), as QuantLib's addHoliday and removeHoliday edit one: under the base's own name, the base's edits.

Remarks

The calendar is the base's, its name the base's name (two calendars are equal by type, name and edits), with the record's edits applied after the base's. A record of a preset's name based on that name edits the preset wherever it is built under the set.
