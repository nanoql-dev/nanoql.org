Remarks

QuantLib's base class for commodity indexes, which nothing in QuantLib derives from; an extension point here too. Its stored fixings are Fixings' under its name.

ForwardPrice(Date, EvaluationContext) converts the curve's price per curve unit into a price per index unit by the factor from the index's unit to the curve's, a price's conversion; QuantLib multiplies by the factor from the curve's unit to the index's, which inverts it, and computes the factor when the index is built, where it is read from the context here.

LastQuoteDate(EvaluationContext) is null for an index with no fixings, where QuantLib's reads the empty history's last date and throws "empty timeseries", so its swaps and future refuse an index with no fixings that their own branch prices from the forward curve (Divergences/CommodityIndexNoFixingsTests.cs).
