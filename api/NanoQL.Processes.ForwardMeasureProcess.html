Remarks

QuantLib's setForwardMeasureTime changes the process; here WithForwardMeasureTime(double) returns a copy at the new time, which a derived process overrides with its own type, rebuilding there any state of its own that reads the time. A process built without a forward measure time refuses to read one, where QuantLib's reads its uninitialized member: a divergence (the playbook's undefined-behaviour row).

An extension point, as in QuantLib: G2's forward process derives from it.
