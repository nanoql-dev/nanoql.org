Remarks

An extension point, immutable: Initialize(bool) gives the optimizer's guesses for the variables, and Values(ReadOnlySpan<double>) maps the optimizer's argument to the variables' values, which VariableHelpers builds its helpers from at each evaluation. QuantLib's update writes the values into quotes the helpers read; here it returns them.
