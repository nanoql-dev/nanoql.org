Remarks

An extension point, as in QuantLib. The algorithm copies its intensity (Clone()) for each minimization and binds the copy to that minimization's population, which the protected members read; a minimization's copy is its working state.

FindBrightest() attracts each firefly to every brighter one, k < i in the sorted population, where QuantLib's loop stops at k < i − 1, skipping the next brighter one and leaving the second brightest unattracted (Divergences/FireflyAlgorithmTests.cs).
