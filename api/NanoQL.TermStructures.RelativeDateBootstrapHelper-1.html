Remarks

The mechanism lives in BootstrapHelper<TTermStructure> (its constructor taking the context, and InitializeDates(EvaluationContext)), since a family's own relative base derives from that family's base instead (RelativeDateRateHelper, QuantLib's RelativeDateRateHelper). Each relative helper overrides InitializeDates(EvaluationContext), which this class makes abstract.

Methods

InitializeDates(EvaluationContext)

Computes the helper's dates for an evaluation date: QuantLib's initializeDates(). A helper whose dates follow the evaluation date overrides it and calls it from its constructor; the bootstraps call it on a fresh copy to re-date the helper for a curve built under another evaluation date. The base does nothing.
