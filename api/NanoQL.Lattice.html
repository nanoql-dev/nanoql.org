Remarks

A lattice is immutable once built, and thread-safe, so one lattice can be built once and passed to many calculations. The assets it rolls back are working types (DiscretizedAsset), owned by one calculation: the lattice's members change the asset they are given, never the lattice.

The numerical method interface is used by discretized assets and implemented by developers writing numerical methods; users call the corresponding members of DiscretizedAsset instead. An extension point, as in QuantLib: the tree lattices derive from it.
