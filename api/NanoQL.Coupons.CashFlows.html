Remarks

QuantLib's iterators are positions in the leg: PreviousCashFlow(ImmutableArray<CashFlow>, EvaluationContext, bool?, Date?) returns −1 where QuantLib returns rend(), and NextCashFlow(ImmutableArray<CashFlow>, EvaluationContext, bool?, Date?) the leg's length where it returns end(). A date QuantLib returns as its null date is null.

The yield is solved for by NewtonSafe, QuantLib's default, or by Brent, the solvers its template is instantiated with. A Z-spread is solved for on a ZeroSpreadedTermStructure built at each evaluation, where QuantLib's rewrites the value of one curve's quote; the values are the same. QuantLib's Z-spread functions that take a day counter, which they ignore, are deprecated and not ported.
