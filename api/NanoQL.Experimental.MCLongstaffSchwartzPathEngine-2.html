Remarks

An extension point and an immutable object: a concrete engine's static Calculate builds one per call and implements LsmPathPricer(). Run() builds the pricer, adds the calibration samples, calibrates and prices on the same pricer, QuantLib's mutable pricer the call's working state.

One seed draws the calibration and the pricing paths, so the pricing run's first paths are the calibration's (Longstaff and Schwartz's in-sample estimator, QuantLib's code); there is no calibration seed, as QuantLib's path engine has none. The calibration samples default to 2,048; none is refused, where QuantLib's calibration reads the first of no path.
