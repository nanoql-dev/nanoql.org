Remarks

QuantLib's curiously recurring template: a derived class implements Size(int), Discount(int, int), Descendant(int, int, int) and Probability(int, int, int), and may override Stepback(int, ReadOnlySpan<double>, Span<double>), which are called per node and branch. The rollback's inner step is one Stepback(int, ReadOnlySpan<double>, Span<double>) into the asset's spare buffer (StepValues(int), CommitStep(int, double)), then the asset's adjustment; it allocates nothing.

State prices. A lattice is immutable once built. The rows of Arrow-Debreu state prices its construction computes, through ComputeStatePrices(int), are stored; StatePrices(int) computes any later row on each call from the last stored one, with the same operations in the same order, and keeps it nowhere. A derived class whose constructor calls ComputeStatePrices(int) reads its own Size(int), Discount(int, int), Descendant(int, int, int) and Probability(int, int, int) there, so it seals them: C# runs a further override from a constructor before that override's class has been constructed.

An extension point, as in QuantLib: the one-dimensional lattices derive from it, as later ports' two-dimensional lattice will; a binomial lattice overrides Stepback(int, ReadOnlySpan<double>, Span<double>), a convertible's lattice Rollback(DiscretizedAsset, double) and PartialRollback(DiscretizedAsset, double).

For a derived lattice's copy that differs from other only in what its later rows depend on, as a short-rate tree's copy with a spread: the stored rows are the ones QuantLib's cache holds when it is copied.

Stepback(int, ReadOnlySpan<double>, Span<double>)

Rolls values one step back: for each node, the probability-weighted sum of its descendants' values, then the node's discount.

public virtual void Stepback(int i, ReadOnlySpan<double> values, Span<double> newValues)

Parameters

i int

The step's index on the grid.

values ReadOnlySpan<double>

The values at step i + 1.

newValues Span<double>

The values at step i, written here: Size(int)(i) of them.

Exceptions

ArgumentOutOfRangeException

i isn't a step before the grid's last, where QuantLib reads past its end.

ArgumentException
