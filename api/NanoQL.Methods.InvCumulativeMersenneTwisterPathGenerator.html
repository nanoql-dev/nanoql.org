A path generator over QuantLib's pseudo-random Gaussian sequences, inverse-cumulative normal deviates of Mersenne-Twister uniform sequences (PseudoRandom::rsg_type): QuantLib-Python's InvCumulativeMersenneTwisterPathGenerator, which it also names GaussianPathGenerator.
