Remarks

A working type, as every line search is (LineSearch): Evaluate(ProblemState, ref EndCriteriaType, EndCriteria, double) changes it and reads the gradient its previous call left; a LineSearchBasedMethod runs each minimization on a new one (NewSearch()).
