Remarks

Its arguments are θ, κ, σ, ρ and v₀, in that order, each a constant parameter: θ, κ, σ and v₀ positive, ρ in [−1, 1]. Immutable: WithParams(Vector) returns a new model, whose process GenerateArguments() builds from the new parameters.

As QuantLib's, the model's process is built afresh from the given process's curves and spot and the model's parameters, with the default discretization whatever the given process's; QuantLib's engines read only its curves, its spot and the parameters.

An extension point, as in QuantLib: the Bates models derive from it, through the protected constructor, which sets the five Heston arguments of a larger argument list and builds the Heston process. No constructor calls the virtual GenerateArguments(), which in C# would run a derived override before the derived constructor has set its arguments; each builds its process through its own non-virtual member, as QuantLib's C++ base constructor runs its own generateArguments.
