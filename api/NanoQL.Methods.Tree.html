Remarks

QuantLib's curiously recurring template: a derived tree implements Underlying(int, int), Size(int), Descendant(int, int, int) and Probability(int, int, int), and Branches, QuantLib's enum { branches = N } (2 for a binomial tree, 3 for a trinomial one). Immutable once built. An extension point, as in QuantLib: the trinomial tree derives from it, as later ports' binomial trees will.
