Remarks

Immutable once built (the playbook's lattice row). Its step back is QuantLib's, the tree's first-node probabilities applied to every node: (pd·v[j] + pu·v[j + 1])·discount.

Unsealed, an extension point, as QuantLib's is: the Tsiveriotis-Fernandes lattice derives from it and reads the protected probabilities.
