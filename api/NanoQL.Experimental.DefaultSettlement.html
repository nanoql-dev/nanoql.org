Remarks

Immutable; built by DefaultEvent's constructors, as QuantLib's are protected and the event a friend. An event that hasn't settled has none (Settlement is null), where QuantLib's holds a settlement with a null date.

A settlement from a single recovery rate settles the seniority it names, and every ISDA seniority for NoSeniority, as a settlement from a map settles the seniorities it holds. QuantLib's fills every other seniority with ISDA's conventional recovery (defaultevent.cpp:63-75), so an event settled for SubLT2 at 0.3 reads 0.65 for SecDom, where each seniority settles at its own auction (ISDA's 2008 Icelandic protocols). A documented divergence (Divergences/SingleSenioritySettlementTests.cs); a seniority not settled reads null.
