Remarks

The curve bootstraps in its constructor, over a working state its helpers' bound copies price against, as PiecewiseYieldCurve<TTraits, TInterpolator, TBootstrap> does; the helpers whose dates follow the evaluation date are re-dated for the context's. It implements IInterpolatedCurve<TTraits, TInterpolator>, where QuantLib's derives from the interpolated curve. The members its bootstrap calls on the curve under construction are sealed.

QuantLib's lazy base date, a function its first calculation calls, is a function of the context here, called once by the constructor with the curve's context, and passed to the base constructor, whose seasonality check reads it. QuantLib's lazy constructor gives its base Date(), so a seasonality of more than one cycle checks itself against the null date, whose month is read before its table, which is undefined; here it checks itself against the base date the function computes, a documented divergence.

SetSeasonality<T>(T, Seasonality?, EvaluationContext) returns a copy bootstrapped again with the seasonality, from a cold start, under the context given, with a lazy base date computed again in it: QuantLib re-bootstraps warm, from the curve's own nodes, which differs from a fresh build by up to 7.9e-15 at its default accuracy, a documented divergence. Unsealed for its named class, which adds constructors only.
