Remarks

The curve bootstraps in its constructor, over a working state its helpers' bound copies price against, as PiecewiseYieldCurve<TTraits, TInterpolator, TBootstrap> does; the helpers whose dates follow the evaluation date are re-dated for the context's. QuantLib's curve derives from its traits' interpolated curve; this one derives from DefaultProbabilityTermStructure and is that curve through IInterpolatedCurve<TTraits, TInterpolator>, with the traits' formulas, so a piecewise hazard-rate curve isn't a HazardRateStructure here; no QuantLib code casts to one. The members its bootstrap calls on the curve under construction are sealed.

QuantLib's settlement-days constructors are Create(int, Calendar, IEnumerable<BootstrapHelper<DefaultProbabilityTermStructure>>, DayCounter, EvaluationContext, IEnumerable<double>?, IEnumerable<Date>?, TInterpolator, TBootstrap). Its constructor on a one-factor affine model of the default intensity is the one taking a OneFactorAffineModel, for the affine hazard-rate traits: the curve calls the traits' model-aware members when it holds a model, which other traits refuse, and the landed formulas otherwise. QuantLib's piecewise affine curve is a one-factor affine survival structure, with its conditional survival; this one can't change its base by its traits, so that structure is built on its nodes. A curve is always built afresh, as the piecewise yield curve is. Unsealed for its named class, which adds constructors only.
