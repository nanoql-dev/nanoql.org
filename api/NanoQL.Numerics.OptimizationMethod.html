Remarks

A method holds only its configuration, so it is immutable; its working state lives inside each minimization. Minimize(Problem, EndCriteria) starts from the problem's initial value and returns the results; Minimize(ProblemState, EndCriteria), QuantLib's minimize(Problem&), continues from the state's current value and leaves the results in it, for line searches and hybrid methods. Both call MinimizeCore(ProblemState, EndCriteria).

So a second minimization of one QuantLib Problem starts from the first's optimum, where Minimize(Problem, EndCriteria) starts from the initial value each time.

An extension point, as in QuantLib: each optimization method derives from it.
