Remarks

A static class: QuantLib's two constructors are Calculate overloads, the model with a number of time steps, whose tree is built per call on a grid through the bond's mandatory times, and the model with a time grid, whose tree is built per call on that grid; a third takes a built lattice, which a caller reuses across calls. The bond is discounted on the model's curve when the model is term-structure consistent, else on the term structure given.

The spread, a continuously compounded rate added to every node's short rate, is QuantLib's CallableBond::arguments::spread, which only the OAS family sets: it is each overload's last parameter, which the OAS family's engine delegate passes on. QuantLib's time-grid engine keeps its tree, so a spread it sets stays on it for later calls; a lattice here is immutable, so every call prices at the spread it is given.
