The Black-Scholes (1973) stochastic process, d ln S(t) = (r(t) − σ(t, S)²/2) dt + σ dW_t: the generalized process with no dividend yield. The interface is expressed in S; the internal calculations work on ln S.

Remarks

QuantLib builds its dividend curve as FlatForward(0, NullCalendar(), 0.0, Actual365Fixed()), whose reference date is the evaluation date, read wherever the curve is (the analytic engine measures the dividend rho's time from it). Create(double, YieldTermStructure, BlackVolTermStructure, EvaluationContext, StochasticProcess1DDiscretization?, bool) builds that curve under the context it is given, so the process takes the context where QuantLib's constructor takes none.
