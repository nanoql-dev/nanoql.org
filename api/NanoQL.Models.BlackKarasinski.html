Remarks

Its short rate is rₜ = e^(φ(t) + xₜ), xₜ an Ornstein-Uhlenbeck process and φ the deterministic fitting parameter, which can't be determined analytically: a tree fits it to the curve at each step as it is built, by Brent (1,000 evaluations, accuracy 1e-7, in [−50, 50] from the previous step's value), and Dynamics() reads the fitting of a 50-step tree over the curve's maximum time, as QuantLib's does.

Each tree owns its fitting: a divergence, QuantLib's writing the model's one fitting parameter, so a second tree on another grid rewrites the first's, which then refuses "fitting parameter not set!" at its own times (Divergences/BlackKarasinskiTreeFittingTests.cs), as the Hull-White tree already does.
