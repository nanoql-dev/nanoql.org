Remarks

Immutable. Each constructor builds what QuantLib's helper builds at its first calculation, under the context it is given: the exercise and start dates, the schedules, a swap at a zero rate whose fair rate is the forward (priced on the term structure, without the settlement date's flows), the exercise rate (the strike, or the forward when none is given) and the swap's type (a receiver, unless the strike is above the forward), the swap at that rate, the European swaption, and the market value. So the at-par choice of the swaps' Ibor coupons is the context's at construction, where QuantLib's reads its global switch whenever the helper recalculates.

An overnight index builds an overnight-indexed swap, which model-based engines treat as a vanilla swap: at best a decent proxy, at worst simply wrong; use with caution. Its value dates are QuantLib's telescopic ones, which nanoql builds in full.

The model value is the pricing engine's, set by SetPricingEngine<TModel>(Func<Swaption, EvaluationContext, TModel, InstrumentResults>?), which takes the model being calibrated as its last argument; with no engine, pricing a swaption that hasn't expired refuses with QuantLib's "null pricing engine". The settlement days' value is never read, as in QuantLib: any non-null value takes the start date the index's fixing days after the exercise date, where null takes the index's value date.
