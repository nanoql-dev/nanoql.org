Remarks

A working type: mutable, owned by one computation and not thread-safe. An optimization method works through it, and a line search or a hybrid method passes it on, as QuantLib's pass their Problem&: Minimize(ProblemState, EndCriteria) continues from CurrentValue.

Value(Vector), Values(Vector), Gradient(Vector, Vector) and ValueAndGradient(Vector, Vector) call the cost function and count the evaluations, as QuantLib's do. A new state starts from the problem's initial value with no evaluations and no function value, as after Reset(), where QuantLib leaves the counts and values uninitialized until its methods reset them.
