Interface IDefaultLossModel

Namespace
NanoQL.Experimental
Assembly
NanoQL.dll

A default loss model: the basket's contract with the algorithms that give its joint loss statistics (latent models, top-down models). QuantLib's DefaultLossModel, whose abstract class form is DefaultLossModel.

[Experimental("NQL0001")]
public interface IDefaultLossModel

Remarks

A model is an immutable configuration until it is bound: SetBasket(Basket) returns a copy bound to a basket, its per-basket precomputation run once there (QuantLib's resetModel), and a basket's SetLossModel(IDefaultLossModel?) binds it. Every statistic is a member with a body that refuses, with QuantLib's text, unless the model implements it; QuantLib's protected statistics are public here, the basket reading them through this interface.

An interface, beside the abstract class, so that a model with another base implements the contract over it, as QuantLib's constant-loss and Gaussian LHP models derive their latent model beside the loss model.
