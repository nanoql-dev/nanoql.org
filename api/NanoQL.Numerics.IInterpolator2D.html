A 2-D interpolation factory, QuantLib's 2-D interpolator concept (Bilinear and the others): an instance builds the interpolation over a grid and its function values.

public interface IInterpolator2D

Remarks

A factory is a readonly struct, stateless or holding its parameters, whose zero value is QuantLib's default construction. A consumer is generic over TInterpolator : struct, IInterpolator2D and takes the instance, where QuantLib's const Interpolator& i = {} becomes TInterpolator i = default.

An extension point: a factory of one's own implements it.
