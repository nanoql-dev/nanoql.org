Remarks

Refer to Golub and Van Loan, "Matrix computation", The Johns Hopkins University Press. QuantLib's implementation is adapted from the TNT project (JAMA), developed at the National Institute of Standards and Technology and in the public domain. It requires at least as many rows as columns; a matrix with fewer rows is decomposed transposed, and its U and V swapped, since M = (U·S·Vᵀ)ᵀ = V·S·Uᵀ.

The decomposition is computed in the constructor; U(), V(), SingularValues() and S() return copies.

A matrix with a NaN or infinite entry is refused on entry, where QuantLib's main loop, which has no test for too many iterations, never ends; and so is a finite matrix whose decomposition leaves the range of doubles, a singular value beyond it (entries near 1e307), refused at the main loop's first non-finite singular value or superdiagonal entry, where QuantLib's loop never ends either. Documented divergences (Divergences/SvdNonFiniteRefusalTests.cs). Every matrix QuantLib decomposes keeps its arithmetic.
