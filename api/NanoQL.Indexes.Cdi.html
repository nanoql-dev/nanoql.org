Remarks

CDI quotes an annually compounded rate on Business/252: the forecast is (P(s)/P(e))^(1/τ) − 1, and a coupon grows a fixing over a span τ by (1 + r)^τ (GrowthFactor(double, double)), CDI's daily factor, and an averaged coupon accrues (1 + r)^τ − 1 (SimpleAccrual(double, double)), where QuantLib's overnight pricers grow it as a simple rate, so that a coupon's amount depends on the route taken: a documented divergence.

Clone(YieldTermStructure?) returns a Cdi, where QuantLib's returns a plain overnight index, which forecasts by the generic formula: a documented divergence.
