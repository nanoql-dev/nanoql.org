Remarks

Immutable: an interpolation copies its grid and its matrix and computes what it needs when it is built. QuantLib's keep iterators and a reference into their caller's data and recompute on update(); here a change of data is a new interpolation, so update() isn't ported. Extrapolation follows Extrapolator: EnableExtrapolation<T>(T, bool) returns a copy.

An extension point, as in QuantLib: a derived interpolation passes its inputs to the base constructor, computes what it needs from X, Y and ZRow(int), and implements ValueCore(double, double), which Evaluate(double, double, bool) calls after the range check. The x and y values must be sorted; an unsorted grid is located as QuantLib's binary search locates it.
