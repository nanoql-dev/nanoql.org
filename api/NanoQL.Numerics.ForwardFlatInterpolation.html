Remarks

It copies its inputs, as every Interpolation does.

Past the last node the primitive grows at the value there, yn-1, from its value at the last node, as the interpolation's own value says. QuantLib's adds (x - x[n-2]) y[n-2] to the primitive at the second-to-last node, so its integral past the last node disagrees with its value there (forwardflatinterpolation.hpp:93-97), a documented divergence; at and before the last node it is QuantLib's expression.
