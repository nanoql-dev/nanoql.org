A discount curve fitted to a set of bonds: a discount function d(t), a fitting method's, fitted so that the bonds' cash flows discounted on it reproduce their prices in an optimized sense, the price errors weighted by the inverse of the bonds' durations.

Remarks

The curve is a generic wrapper, and its FittedBondDiscountCurveFittingMethod the implementation: a new fitting method derives from that. The fit can be slow with many bonds, and its speed depends on the method and its convergence under the optimization. Built from given parameters, the curve doesn't fit: it evaluates the method's discount function on them, up to a given maximum date, for example to use parameters fitted to bonds in one currency as a credit spread curve over a discount curve in another.

The curve fits in its constructor, as a LazyObject's work is done at construction, so a fit that fails, or an input it refuses, refuses the curve where QuantLib throws at the first read. While it fits, the curve answers at the fit's trial parameters, and its bond helpers are copies bound to the curve itself, as QuantLib binds them to this; nothing outside the constructor sees the curve change. QuantLib's quotes are doubles here, always valid, so its check of an invalid price quote has nothing to refuse. QuantLib's constructors taking settlement days, whose reference date moves with the evaluation date, are the Create(int, Calendar, IEnumerable<BondHelper>, DayCounter, FittedBondDiscountCurveFittingMethod, EvaluationContext, double, int, IEnumerable<double>?, double, int) factories.

A curve is always built afresh, fitted from the given guess, the initial guess the L2 penalty's header doc anchors it to. QuantLib's curve keeps its last solution as its guess (fittedbonddiscountcurve.cpp:294-295), so recalculated after a quote moves it starts from, and is penalized towards, its previous fit. A documented divergence. QuantLib's resetGuess, which refits in place, is ResetGuess(IEnumerable<double>, EvaluationContext), which returns the curve refitted.
