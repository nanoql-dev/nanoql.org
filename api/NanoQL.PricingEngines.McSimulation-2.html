Remarks

An extension point and an immutable object: an engine derives from it, holds its settings and its call's instrument and context, and implements the hooks, each returning a new object per call. Calculate(double?, int?, int, PathPricer<TPath>?) builds a new MonteCarloModel<TPath, TStats>, runs QuantLib's value or valueWithSamples loop on it and returns it, so QuantLib's mutable mcModel_ is the call's result and two calculations can share one engine; its errorEstimate() and sampleAccumulator() read the returned model's accumulator. QuantLib's controlPricingEngine(), which the base never reads, is declared by the engines that read it, with their own engine delegate's type.

A NaN error estimate is refused, where QuantLib's tolerance check skips it and returns the mean; and so is a next-batch estimate past the samples' range (a tolerance of 0 makes it infinite), where QuantLib's conversion to Size is undefined: documented divergences (Divergences/McSimulationUndefinedTests.cs).
