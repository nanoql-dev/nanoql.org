Remarks

Each sequence draws the factor and one variable per name from QuantLib's pseudo-random Gaussian sequences (MT19937 inverted), y = a·m + √(1 − a²)·zⱼ with a² the copula's correlation, and solves the name's default time for the probability Φ(y): Brent's solver on [0, tmax] from tmax/2, bisection where it fails.

The seed is explicit, in [1, 4294967295]: QuantLib reads 0 as a seed drawn from the clock, and its long seed is a 32-bit value on MSVC.
