Class ZeroInflationCashFlow

Namespace
NanoQL.Coupons
Assembly
NanoQL.dll

A cash flow paying a zero-inflation index ratio between the start and end dates less the observation lag: with the dates in June and a three-month lag, the ratio is taken between March fixings. It isn't a coupon: it has no accruals.
