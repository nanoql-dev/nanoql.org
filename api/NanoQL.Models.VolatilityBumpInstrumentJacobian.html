Remarks

The instruments are the swaptions, then the caps. The one-percent bump of an instrument with derivative vector v is 0.01 v / ⟨v, v⟩.

Immutable but for QuantLib's per-instrument cache, kept: each instrument's derivatives are computed at its first read, once, from the immutable inputs, thread-safe.

A refusal (a documented divergence; Divergences/VolatilityBumpInstrumentJacobianTests.cs): an instrument whose pseudo-derivative refuses its inputs refuses at every read. QuantLib marks it computed before computing it (bumpinstrumentjacobian.cpp:53), so after the refusal a second read returns zeros and the bump matrix a row it never wrote (Matrix(rows, columns) leaves its storage uninitialized).
