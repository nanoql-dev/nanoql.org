Fixing(Date, EvaluationContext, bool)

The fixing on a date. A date after the evaluation date, or on it with forecastTodaysFixing, is forecast; a date before it, or on it when the context enforces today's historic fixings, must have a stored fixing; otherwise today's stored fixing is used if there is one, and forecast if not.

public override double Fixing(Date fixingDate, EvaluationContext context, bool forecastTodaysFixing = false)
