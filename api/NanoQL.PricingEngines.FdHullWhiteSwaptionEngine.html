Remarks

A static class: Calculate runs QuantLib's four steps (playbook §2.1) on the model, an argument where QuantLib's engine holds it. The mesher is the factor's Ornstein-Uhlenbeck quantiles up to the last exercise; the swap's coupons forecast on a Hull-White with the model's parameters on the index's curve, which must share the discount curve's day counter and reference date, as QuantLib refuses otherwise; the value is read at the factor's origin.

An American exercise reaches the inner value at times off its exercise dates, which it refuses.
