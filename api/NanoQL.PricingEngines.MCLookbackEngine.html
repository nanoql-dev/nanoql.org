Remarks

A static class with one Calculate overload per lookback instrument, QuantLib's template parameter I and its four pricer overloads, over one private simulation deriving McSimulation<TPath, TStats> directly; QuantLib's four .cpp-local path pricers are two private classes here, a partial pricer the full one over its window's nodes. The full-period overloads refuse a partial-time option held as the full-period type with QuantLib's "wrong argument type". The seed is explicit.

Documented divergences. The paths and the discount run on the engine's clock, Clock(GeneralizedBlackScholesProcess, FdmQuantoHelper?), from the earliest reference date of the structures, where QuantLib's run on the risk-free curve's (Divergences/McLookbackMismatchedTimesTests.cs). The extremum observed so far is folded into the path's, where QuantLib's pricers take the extremum from the path's second node alone and price a seasoned option as a new one (Divergences/McLookbackSeasonedTests.cs), and it is read as the spot where it lies beyond it, the spot being observed. A partial option's window date is a time of the grid, its start node included, where QuantLib's pricers snap it to the closest time of a regular grid and the partial fixed pricer drops the window's first node (Divergences/McLookbackWindowTests.cs). A partial fixed window opened before the evaluation date is refused, as the analytic engine refuses it, where QuantLib's pricer starts it today, and a partial floating window closed before the evaluation date takes the extremum as given, neither the spot nor a path's node folded in, where QuantLib's folds today's spot into it; a window dated from the evaluation date to the clock's origin opens or closes at the path's start (Divergences/LookbackPartialWindowTodayTests.cs). And the partial floating option pays the terminal spot less λ times the minimum, or λ times the maximum less the terminal spot, as the instrument and the analytic engine have it, where QuantLib's pricer drops λ (Divergences/McLookbackLambdaTests.cs).
