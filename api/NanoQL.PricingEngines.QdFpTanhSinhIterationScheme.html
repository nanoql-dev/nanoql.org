Remarks

No fixed-point step is refused with the Gauss-Legendre scheme's text, where QuantLib doesn't check it here and its m − 1 naive steps wrap to 2⁶⁴ − 1, so the engine never ends: a documented divergence (Divergences/QdFpTanhSinhSchemeTests.cs). No node is QuantLib's: the engine refuses it when it prices.
