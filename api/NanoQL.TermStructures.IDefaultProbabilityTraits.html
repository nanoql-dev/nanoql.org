Remarks

As IYieldTraits does for yield curves: QuantLib's piecewise curve derives from the interpolated curve its traits name, which C# can't express, so the traits carry the kind's formulas, and the interpolated curve and the piecewise curve of that kind both call them. Where QuantLib's interpolated curve keeps the base's hazard rate (the default density over the survival probability, both read through the curve's public members, jumps included), the kind's HazardRateImpl(ReadOnlySpan<double>, ReadOnlySpan<double>, Interpolation, double, DefaultProbabilityTermStructure) computes it so on the curve it is given. A kind whose curve takes a one-factor affine model of the default intensity implements the model-aware members, which the others refuse. An extension point.
