A bootstrap's traits: what the bootstraps ask of a curve kind (QuantLib's Discount, ZeroYield and the other traits structs), as static members.

public interface IBootstrapTraits<TTermStructure> where TTermStructure : TermStructure

Type Parameters

TTermStructure

The kind of term structure bootstrapped.

Remarks

Traits are stateless, so a traits type is a readonly struct with static members only, used as a type argument. Each member reads the curve under construction through its working state, as QuantLib's read the curve through their pointer to it.

QuantLib's global bootstrap detects two optional groups of members (globalGuess, and transformDirect with transformInverse); here they are static virtual members whose defaults are QuantLib's behaviour when the traits don't define them, and HasGlobalGuess and HasTransform say whether a traits type does. An extension point: each family of term structures has its own traits.
