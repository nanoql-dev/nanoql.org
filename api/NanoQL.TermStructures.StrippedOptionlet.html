Remarks

QuantLib's quotes are their values: a new volatility is a new object. The fixing times run from the reference date, the settlement days after the context's evaluation date, computed at construction as QuantLib computes them; a later evaluation date is a new object.

The at-the-money rates are the index's fixings on the fixing dates, read from the context at each call, today's forecast, as QuantLib reads them at each call.
