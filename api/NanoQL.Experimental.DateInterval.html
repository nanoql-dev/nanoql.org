Remarks

Immutable, and the base of PricingPeriod. QuantLib's default DateInterval(), two null dates, is a DateInterval? null where QuantLib returns it (Intersection(DateInterval) of two disjoint intervals).

IsDateBetween(Date, bool, bool) includes or excludes each end as its flags say. QuantLib's excludes both ends whatever they say: its else if follows the includeFirst test, so a start date that passes date >= startDate then fails date > startDate, and the end likewise (dateinterval.hpp:51-63; Divergences/DateIntervalTests.cs).
