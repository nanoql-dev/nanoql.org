SetCouponPricer(ImmutableArray<CashFlow>, EquityCashFlowPricer?)

A leg with a pricer set on each of its equity cash flows; every other cash flow is kept as it is.

public static ImmutableArray<CashFlow> SetCouponPricer(ImmutableArray<CashFlow> leg, EquityCashFlowPricer? pricer)

Parameters

leg ImmutableArray<CashFlow>

The leg.

pricer EquityCashFlowPricer

The pricer.

Returns

ImmutableArray<CashFlow>

The new leg; this one is unchanged.

Remarks

QuantLib's sets the pricer on the flows in place and its cast skips a null cash flow (equitycashflow.cpp:44-51); here the new leg is built, and a null cash flow is refused, as every nanoql leg refuses one.

Exceptions

ArgumentException

The leg holds a null cash flow, or is default(ImmutableArray).
