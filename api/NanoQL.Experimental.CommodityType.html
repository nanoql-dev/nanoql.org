Remarks

Immutable, and an extension point: NullCommodityType derives from it, and a user may build one. QuantLib's empty CommodityType(), a placeholder whose members throw, is a CommodityType? null.

QuantLib keeps a process-wide registry keyed by code, so a second construction with a known code returns the first construction's name whatever it was given (commoditytype.cpp:28-38). There is no registry here, so every type holds the data it is given, a documented divergence (Divergences/CommodityRegistryTests.cs).

Two types are equal when their codes are, compared ordinally, as QuantLib's operator== compares them (commoditytype.hpp:107-109); the hash is the code's. The equality is sealed.
