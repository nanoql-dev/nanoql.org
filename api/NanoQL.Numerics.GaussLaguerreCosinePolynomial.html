Class GaussLaguerreCosinePolynomial

Namespace
NanoQL.Numerics

NanoQL.dll

The Gauss-Laguerre cosine polynomial: orthogonal under the weight w(x; u) = e^(−x)·(1 + cos(ux))/m₀ on [0, ∞), m₀ = 1 + 1/(1 + u²) normalising it, for the Gaussian quadrature of ∫₀^∞ f(x) dx.
