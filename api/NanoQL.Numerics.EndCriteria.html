The criteria that end an optimization: the maximum number of iterations, and the minimum number of iterations around a stationary point; a stationary point of x, the independent variable; a stationary value of y = f(x), the dependent variable; and a stationary gradient.

Remarks

Immutable. Each check returns its outcome, where QuantLib's write the stationary count and the criterion met into Size& and EndCriteria::Type& arguments: a check that returns bool holds when its own criterion is met (CheckMaxIterations(int)'s is MaxIterations), and one that counts stationary iterations returns an EndCriteriaCheck.

Exceptions

The maximum number of stationary iterations isn't more than 1, or isn't fewer than the maximum number of iterations.
