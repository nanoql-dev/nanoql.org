A finite-difference time-stepping scheme: the evolver concept QuantLib's FiniteDifferenceModel template reads, which steps the values back over a set step.

[WorkingType]
public interface IFdmScheme

Remarks

QuantLib's schemes share no base: the model's template takes any class with step and setStep. Here the model's type parameter is constrained to this interface, and every QuantLib scheme implements it. A scheme is a working type: Step(Span<double>, double) modifies the values in place, through scratch buffers the scheme holds.

An extension point: a later unit's scheme implements it.
