An immutable set of convention records, layered snapshot on snapshot, and the ConventionProvider that answers from them: QuantLib's shipped presets (QuantLib) or none (Empty), with a user's files on top.

Remarks

QuantLib is the shipped records; Default, Current and Use(ConventionProvider) are the provider's, so a set configures the system as ConventionProvider.Default = ConventionSet.QuantLib.With(...).

A lookup builds a new object each time, inside the set's scope, so a preset comes out as its own class with the set's values, and an index keeps the set as its provider. A field comes from its record, then the record's base chain, then QuantLib's reference. Calendars, day counters and currencies are code kinds: a name the set doesn't define, but a coded preset has, resolves to QuantLib's preset, with no edits, even on Empty.

A record named after a coded preset must be one the preset's class can take, since a coded construction can't become another kind: a calendar preset takes its own preset record or a calendar record based on itself, a day counter or currency preset a record of its own kind based on itself, and an alias between two presets only where QuantLib shares their implementation. With(ConventionSnapshot) refuses any other, and resolves every record of the new set, so a name a later layer breaks, a cycle or a value the core refuses fails when the file is loaded.

Two sets are equal when they hold equal snapshots in the same order on the same base.
