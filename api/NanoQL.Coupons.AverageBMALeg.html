Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToLeg() builds the leg, in place of QuantLib's conversion operator; it reads no context. A builder has no value equality: its vectors compare by reference. A notional, gearing or spread vector shorter than the schedule repeats its last element.
