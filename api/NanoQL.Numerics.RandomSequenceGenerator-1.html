Remarks

Do not use it with a low-discrepancy sequence generator. QuantLib's seed constructor is Create<TRng>(int, long), for a generator that can be built from a seed, and its nextInt32Sequence is NextInt32Sequence<TRng>(RandomSequenceGenerator<TRng>), for a generator that draws integers.

A mutable working type: each draw changes it, and it is not thread-safe. A draw returns a view of its buffer, valid until its next draw. It copies the generator it is given, so the caller's later draws change nothing in it.
