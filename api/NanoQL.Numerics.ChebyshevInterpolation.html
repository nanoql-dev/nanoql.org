Remarks

Immutable, as every Interpolation: QuantLib's updateY, which overwrites the values in place, is WithY(ReadOnlySpan<double>), a copy on the same nodes sharing the receiver's barycentric weights, which depend on the nodes alone. The value and derivative are LagrangeInterpolation's, and so are the refusals of the primitive and the second derivative.
