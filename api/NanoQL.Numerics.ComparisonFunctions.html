Remarks

comparison.hpp also declares earlier_than, the comparison of two objects by date, with no generic implementation: each dated type gives its own, as EarlierThan(CashFlow, CashFlow) does for cash flows. Its form on shared pointers forwards to the pointees' comparison; a C# reference is the object, so the type's own comparison serves for it, and neither form has code here.
