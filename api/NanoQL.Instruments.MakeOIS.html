Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToOvernightIndexedSwap(EvaluationContext) builds the swap, in place of QuantLib's conversion operators; it takes the context for the evaluation date the default start date counts from.

An option the builder isn't given that QuantLib's builder fixes takes the builder's provider's default for the index's class (Defaults(OvernightIndex, ConventionProvider)), read when the swap is built: QuantLib's values with nothing configured. Its settlement days test the index's type, as QuantLib's builder does: 0 for Sonia, 1 for Corra and 2 for any other index, so an index cloned from SONIA, a plain NanoQL.Instruments.MakeOIS.OvernightIndex, settles in 2 days.

With no fixed rate, the swap is built at its par rate, as QuantLib's builder builds it: a swap at 0% is priced with the engine given, or with DiscountingSwapEngine on the index's forwarding curve when none is. The engine computes that rate and is never stored: the swap returned holds no engine. A builder has no value equality: its vectors compare by reference.
