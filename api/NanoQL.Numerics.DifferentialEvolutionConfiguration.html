Remarks

There are seven basic strategies for creating mutant population currently implemented. Three basic crossover types are also available.

Immutable, with QuantLib's defaults: each With… method returns a modified copy, where QuantLib's setters change the configuration and return it. QuantLib's seed isn't here: the seed is the optimizer's own argument, required (DifferentialEvolution). Its vectors compare by reference, so two configurations are equal only when they share them.
