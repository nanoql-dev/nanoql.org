A market-model product, or several on the same rate times: the information of its term sheet, and, for a callable product, its exercise strategy. At each step of an evolution it generates the cash flows of that step for the state of the curve.

Remarks

A working type: a product is a state machine over a path, Reset() putting it at the path's start and NextTimeStep(CurveState, Span<int>, MarketModelMultiProductCashFlow[][]) moving it a step, so it isn't thread-safe; Clone() copies it deeply, its state included, as QuantLib's clone. A holder of products (a composite, an engine) holds its own clones, so the caller's object is never stepped by another.

NextTimeStep(CurveState, Span<int>, MarketModelMultiProductCashFlow[][]) writes into buffers the caller sizes once: a count per product and, per product, MaxNumberOfCashFlowsPerProductPerStep cash flows, so a step allocates nothing.

An extension point.
