Remarks

Each coordinate is x + y(upper − lower), y = sign(u − ½)·T·((1 + 1/T)^|2u − 1| − 1), redrawn until inside its bounds. Its draws are std::uniform_real_distribution<Real> on a std::mt19937, as MSVC draws them, on the seed, which is required: QuantLib's default seeds from the clock. A working type.

A step is at most the box's width w: below it for every draw that moves a point up, and w itself only at u = 0, which moves it down. So no draw brings in a point outside the box by w or more, nor one off a zero-width box's bound; and at T = 0 no draw but u = 0 moves a point at all. QuantLib's loop never ends there: such a point is refused, and so is a lower bound above its upper (Conventions/ExperimentalMathRefusalTests.cs). Fixed (Divergences/VeryFastAnnealingSamplerTests.cs): each coordinate is drawn at least once, where QuantLib's starts the loop from lower − 1, which rounds to the lower bound itself at every magnitude from 2⁵⁴ and at some from 2⁵³, and then returns that bound undrawn; and a temperature whose reciprocal overflows, below about 5.6e-309, takes y as sign·(T^(1 − |2u − 1|) − T), the same value rewritten, where QuantLib's y is infinite and never lands in the box, and its 0·∞ at T = 0 is NaN, which its loop returns. A temperature of 0 so holds the point, the distribution's limit. Above T 100, where 1 + 1/T loses the digits of 1/T (QuantLib's step is 2.3e-2 off at 1e14 and 0 from about 1e16, so the point is held), y is sign·T·expm1(|2u − 1|·log1p(1/T)), the same value. Elsewhere QuantLib's arithmetic.
