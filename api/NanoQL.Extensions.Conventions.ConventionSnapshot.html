One conventions document's records, in order: what Read(string) returns and With(ConventionSnapshot) layers onto a set. A name is unique within its value kind (calendars, day counters, currencies), an alias's among all of them.

Remarks

The snapshot keeps its root's foreign attributes and elements, each element at its place among the records, and each record's source (the file it was read from) for Provenance(). Two snapshots are equal when they hold equal records, sources and foreign content in the same order.
