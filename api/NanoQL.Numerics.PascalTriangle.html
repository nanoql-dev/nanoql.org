Remarks

QuantLib grows a static vector of rows on demand, unsynchronised, of BigNatural, a 32-bit unsigned long under MSVC, so its rows wrap from order 35 on Windows (C(35, 17) 242,600,354 for 4,537,567,650), where Linux's 64 bits are exact. Here the rows are 64-bit and computed once, to order 67, the last whose coefficients fit; a higher order is refused.
