Remarks

Immutable once built. A derived constructor sets its arguments with SetArgument(int, Parameter) and derives what it computes from them in GenerateArguments(); WithParams(Vector) copies the model, rewrites the copy's arguments and runs GenerateArguments() on the copy, so the receiver never changes. The arguments a derived constructor hasn't set are null parameters, where QuantLib's are default-constructed parameters with no value. SetArgument(int, Parameter) and GenerateArguments()'s writes are for a model under construction or a fresh copy only, a convention the base can't enforce.

An extension point, as in QuantLib: the short-rate models derive from it, as later ports' Heston models will. A model with another base class implements ICalibratedModel over its own, through this class's internal helpers.

A model whose parameters are constrained together, beyond each argument's own constraint, gives that constraint through ParametersConstraint(), which Constraint composes with the arguments', as QuantLib's CompositeConstraint composes two: the Cox-Ingersoll-Ross models' Feller condition, tested at each parameter vector's own values, where QuantLib's tests σ against the constructor's.
