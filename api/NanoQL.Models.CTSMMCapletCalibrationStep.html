Class CTSMMCapletCalibrationStep

Namespace
NanoQL.Models
Assembly
NanoQL.dll

One pass of a coterminal swap market model's caplet calibration: the swap rates' pseudo-roots and the failures, and what the calibration computes besides (the alpha form's α, a and b; the max-homogeneity calibration's deformation size and swaption error). CTSMMCapletCalibration's hook returns it, and the calibrations' static functions return it in place of QuantLib's out-parameters.
