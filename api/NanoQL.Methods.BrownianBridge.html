Builds Wiener process paths using Gaussian variates: it generates normalized (unit-variance) paths as sequences of variations. To obtain the actual path of the underlying, multiply the returned variations by the integrated variance (including time) over the corresponding time step.

Transform(ReadOnlySpan<double>, Span<double>)

The Brownian-bridge generator function: transforms a sequence of random variates into the sequence of variations of a Brownian-bridge path.

public void Transform(ReadOnlySpan<double> input, Span<double> output)

Parameters

input ReadOnlySpan<double>

The variates, one per step.

output Span<double>

The variations, written into its first Size elements; it must not overlap input.

Remarks

To get the canonical Brownian bridge, which starts and finishes at the same value, the first element of the input sequence must be zero. Conversely, to get a sloped bridge, set the first element to a non-zero value. In this case, the final value in the bridge will be sqrt(last time point) * (first element of input sequence).

Exceptions

ArgumentException

input has another size than the bridge, or output is shorter.
