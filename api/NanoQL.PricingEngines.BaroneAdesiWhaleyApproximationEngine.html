Remarks

The correctness of the returned value is tested by reproducing results available in literature. Where early exercise is never optimal the engine reports the European value and every Greek; otherwise the value alone.

The critical price's Newton step can leave (0, K) for a put, or (K, ∞) for a call, and the next Black formula then throws (baroneadesiwhaleyengine.cpp:83-130); so does a call's seed where h > 0 takes it below zero (:59-64, then the Black formula of :93). Here the critical price is then the root of QuantLib's own equation over that range, by Brent's method. Every case where Newton stays in range keeps QuantLib's bits (Divergences/BaroneAdesiWhaleyCriticalPriceTests.cs).

Each structure is read at the exercise date by date, nothing accrued before its own reference date; where early exercise is never optimal the theta's terms run over each structure's own time, as the analytic European engine's, where QuantLib's run over the volatility's (Divergences/ApproximationThetaMismatchedTimesTests.cs). An exercise window opening after the reference date is priced by NanoQL.PricingEngines.ApproximationWindow, where QuantLib reads the last date alone (Divergences/ApproximationWindowTests.cs).
