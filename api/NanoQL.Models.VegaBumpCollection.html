Remarks

Immutable: its checks are computed at each call, where QuantLib caches them in mutable flags.

The checks (a documented divergence; Divergences/VegaBumpCollectionCheckTests.cs): IsFull() and IsNonOverlapping() are true where no element fails; QuantLib's are true where one fails (vegabumpcluster.cpp:179, :218), so its own default collection given as its clusters reports not full, overlapping and not sensible. The default collection's flags are QuantLib's, true.
