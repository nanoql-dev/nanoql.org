Remarks

A section is built per call, as QuantLib's smileSectionImpl builds one, under the context given at construction, which the structure keeps; its reference date is the model curve's. An option time is taken to the date whose time it is, by QuantLib's Newton search over a date's fractional serial number, adjusted on the index's fixing calendar; a swap length to the nearest whole month.
