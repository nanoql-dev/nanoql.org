Remarks

An immutable builder, as MakeVanillaSwap: each method returns a modified copy, and ToSwap(EvaluationContext) builds the swap, in place of QuantLib's conversion operators; it takes the context for the evaluation date the default start date counts from, and for the at-par switch the Ibor leg reads. A builder has no value equality.

The engine, DiscountingSwapEngine on the swap index's forwarding curve unless WithDiscountingTermStructure(YieldTermStructure?) sets another curve, prices the at-the-money spread (WithAtmSpread(bool)) and is never stored: the swap returned holds no engine, where QuantLib's builder attaches it. QuantLib's two constructors taking the Ibor spread and the forward start, deprecated in 1.44, aren't ported: WithIborSpread(double) and WithForwardStart(Period) set them.

An option the builder isn't given that QuantLib's builder fixes takes the builder's provider's default (Defaults(ConventionProvider)), read when the swap is built: QuantLib's values with nothing configured.
