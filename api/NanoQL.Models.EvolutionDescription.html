Remarks

There are n + 1 rate times, the payment and reset times of n forward rates, and any number of evolution times. The relevant rates of the i-th step run from RelevanceRates[i].First to RelevanceRates[i].Second, by default 0 and n.

Immutable. QuantLib's default constructor, which leaves the number of rates uninitialized, isn't ported. Its refusal of a last evolution time past the last fixing time names the time before the one it checks; the text here names the one it checks (Divergences/MarketModelTextTests.cs).

Parameters

rateTimes ReadOnlySpan<double>

The rate times: at least two, strictly increasing, the first greater than zero.

evolutionTimes ReadOnlySpan<double>

The evolution times, strictly increasing and positive, the last at most the last fixing time; empty for every rate time but the last.

relevanceRates ReadOnlySpan<(int First, int Second)>

The relevant rates of each step; empty for 0 and n at every step.

Exceptions

ArgumentException

The times aren't strictly increasing positive times, the last evolution time is past the last fixing time, or the relevant rates aren't one per step.
