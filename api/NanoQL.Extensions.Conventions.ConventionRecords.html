Remarks

A value equal to a preset's resolved object (a calendar by type, name and edits, a day counter by its own equality) is an alias of the preset. Any other value's fields are written out, its parts that equal no preset under generated names, name/1, name/2, which a user's name takes only beside its name in one snapshot, as this output does. A day counter that carries a trade's data (Actual/Actual (ISMA) with a schedule, 30/360 (ISDA) with a termination date) is no convention and is refused. A currency is one of QuantLib's by its code, its name and numeric code QuantLib's, since the three are its identity: one that differs from the set's in its other fields is described as an override of its code, the set holding one record per code, and one whose name or numeric code isn't QuantLib's is refused. An instrument convention is records already: it is described as its record with every field its base chain gives, under the name, its names those of the set it was resolved in. A unit of measure of a preset's class is described as an override of the set's preset where its data differ, the set holding one record per preset, and an alias of it; QuantLib's null commodity type as no record, a field left out.
