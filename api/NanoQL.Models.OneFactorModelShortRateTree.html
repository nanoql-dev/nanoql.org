Remarks

QuantLib's OneFactorModel::ShortRateTree. Immutable once built: SetSpread(double) returns a copy, which shares the trinomial tree, the dynamics and the state prices this tree stored when it was built.

Hull-White's fitted tree stores each step's state prices as it fits the dynamics to the curve, before the tree is returned, as does the constructor that fits a term-structure fitting parameter numerically; the tree is sealed, so the members its state prices read are its own.
