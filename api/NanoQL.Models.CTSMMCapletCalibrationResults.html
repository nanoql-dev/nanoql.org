A coterminal swap market model caplet calibration's results: QuantLib's inspectors of a calibrated CTSMMCapletCalibration, the fit's errors, the swap rates' pseudo-roots and the model's caplet and swaption volatilities.

Remarks

Immutable: a pseudo-root read returns a copy. The deformation size is null where the calibration doesn't compute it, where QuantLib returns its initializer's 987654321 (ctsmmcapletcalibration.cpp:199).
