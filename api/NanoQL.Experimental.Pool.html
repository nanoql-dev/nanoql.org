Remarks

Immutable: QuantLib's add, clear and setTime return new pools.

DefaultKeys lists each name's key in the pool's order, the order of Names, which every basket and model read pairs it with. QuantLib's lists them in name order, iterating a map keyed by name (pool.cpp:77-82), so a pool not added in name order reads each name's probability on another name's key: names C and A entering with keys KA and KB read C's probability on KB's curve. And QuantLib's clear keeps the cleared names' keys (pool.cpp:34-38), which a name added later then reads; Clear() returns an empty pool. A documented divergence (Divergences/PoolKeyOrderTests.cs); on a pool added in name order, QuantLib's.
