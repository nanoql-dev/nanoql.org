Remarks

The correctness of the returned values is tested by checking them against known good results. The solver works to a hundredth of the accuracy asked, since tests on Black-Scholes implied volatilities show it otherwise delivers 100 times less than promised. Where √(f(mid)² − f(xMin)·f(xMax)) is close to 0 QuantLib returns its previous root, unset on the first iteration; Solver1D<TSelf, TFunction> returns first wherever |f| at a bracket end is below its accuracy, so that branch isn't reached.
