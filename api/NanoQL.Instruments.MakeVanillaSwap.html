Remarks

An immutable builder: each method returns a modified copy, so a builder kept and reused never changes under its holder. ToVanillaSwap(EvaluationContext) builds the swap, in place of QuantLib's conversion operators; it takes the context for the evaluation date the default start date counts from, and for the at-par switch the floating leg reads. A builder has no value equality: its vectors compare by reference.

With no fixed rate, the swap is built at its par rate, as QuantLib's builder builds it: a swap at 0% is priced with the engine given, or with DiscountingSwapEngine on the index's forwarding curve when none is. The engine computes that rate and is never stored: the swap returned holds no engine.

An option the builder isn't given that QuantLib's builder fixes, its fixed leg's tenor, day counter, conventions, rule and end of month and the floating leg's rule and end of month, takes the builder's provider's default for the index's currency (Defaults(Currency?, ConventionProvider)), read when the swap is built: QuantLib's values with nothing configured.

The provider has no defaults for the index's currency (a set without QuantLib's presets).

NanoQLException

Both an effective date and settlement days are set; the fixed leg's default tenor or day counter is unknown for the index's currency; a date is needed that QuantLib's empty calendar can't give; or, with no fixed rate, there is neither an engine nor a forwarding curve, the engine has no discount curve, or the par rate is not available.
