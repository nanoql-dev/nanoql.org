Remarks

Its coupons are built by CmsLeg, which gives them no pricer: the bond prices once one is set with SetCouponPricer<T>(T, FloatingRateCouponPricer?). It has no single redemption: each notional step but the last is an amortizing payment, the last a redemption, so Redemption() refuses it.

The payments at the notional steps, in base 100: step i from 1 takes element i, or the last one past the list's end, so element 0 is read only for a one-element list; null for QuantLib's default, 100.

Exceptions

ArgumentNullException

notionals, schedule or index is null.

ArgumentOutOfRangeException

settlementDays or fixingDays is negative, or the convention isn't a member of its enum.

ArgumentException

The issue date is default(Date), or there are more notionals, gearings, spreads, caps or floors than coupons.

NanoQLException

The schedule is empty, no notional is given, or a date is computed on QuantLib's empty calendar where it can't give one.
