Remarks

An immutable builder, as CmsLeg: each method returns a modified copy, and ToLeg() builds the leg in place of QuantLib's conversion operator. The coupons are built without pricers, as QuantLib's are; a CmsSpreadCouponPricer is set with SetCouponPricer(ImmutableArray<CashFlow>, FloatingRateCouponPricer?). A builder has no value equality: its vectors compare by reference. Experimental, as in QuantLib.
