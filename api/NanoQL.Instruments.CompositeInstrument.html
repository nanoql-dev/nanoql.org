Remarks

Immutable: Add(Instrument, Func<EvaluationContext, InstrumentResults>, double) and Subtract(Instrument, Func<EvaluationContext, InstrumentResults>, double) return a new composite with the component added, where QuantLib's change the composite. Each component carries the engine that prices it, a delegate from the evaluation context, as nanoql's instruments carry none; QuantLib's composite reads the engines its components carry.

It is priced without an engine: Calculate(EvaluationContext) runs QuantLib's steps, its value the components' values summed in the order they were added, each from its engine's results under the context, an expired component's 0 without its engine, as QuantLib's instrument gives it. It has expired when every component has, an empty composite included, as QuantLib's. Its error estimate is null, as QuantLib's is on a composite never expired. QuantLib's deepUpdate has no counterpart.
