Remarks

An extension point: InterpolatedYoYOptionletStripper<TInterpolator> derives from it. QuantLib's initialize strips and stores the curves in the stripper, which then answers for its strikes and slices; here Strip(YoYCapFloorTermPriceSurface, Func<YoYInflationCapFloor, EvaluationContext, YoYOptionletVolatilitySurface, InstrumentResults>, double, EvaluationContext) returns them, an immutable StrippedYoYOptionlets, and the stripper holds nothing.

The engine is a function of the instrument, the context and the trial volatility, the caller binding the index and the nominal curve, as (c, ctx, v) => YoYInflationUnitDisplacedBlackCapFloorEngine.Calculate(c, ctx, index, v, nominal): QuantLib resets the shared engine's volatility on each trial instead.
