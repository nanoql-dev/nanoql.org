Remarks

The constructors build the legs, as QuantLib's do: a fixed leg, and an Ibor leg with the index's default pricer, which reads the context's at-par switch, so they take the context; or, for an overnight index, a compounded overnight leg. A zero gearing becomes QuantLib's machine epsilon, so that the floating leg is built of floating coupons. With the capital exchanges, a redemption follows each coupon whose nominal changes after it, and the last, the nominals and fixed rates repeated (the rate as 0) beside each, as QuantLib's inspectors give them. The fixed leg is paid by a payer swap.

Converted from a fixed-versus-floating swap, it keeps an overnight-indexed swap's observation conventions, as QuantLib's does, and its rounding precision, which QuantLib's conversion drops, so a rounded swap's coupons would differ from the source's: the converted swap is worth the source's, QuantLib's own identity (testNonstandardSwapConversionPreservesObservationConventions).

Each leg's nominals are QuantLib's master's (#2956), where QuantLib 1.44 repeats the swap's constant nominal and refuses an amortizing swap (Divergences/NonstandardSwapUpstreamFixesTests.cs).
