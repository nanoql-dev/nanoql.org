The hybrid simulated annealing's probability, which decides whether a new point is accepted: QuantLib's Probability template parameter.

[Experimental("NQL0001")]
public interface IAnnealingProbability<TSelf> where TSelf : IAnnealingProbability<TSelf>

Type Parameters

TSelf

The probability's own type.

Remarks

An extension point, as in QuantLib's concept, bool operator()(Real currentValue, Real newValue, const Array& temp). A probability may keep state between calls, its generators'; the annealing copies it (Clone()) for each minimization.
