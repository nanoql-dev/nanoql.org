Remarks

QuantLib fills the caller's matrices; here the decomposition returns them in a record. QRSolve(Matrix, Vector, bool, Vector?) on a rank-deficient matrix is MINPACK's documented contract, as QuantLib's: qrsolv tests singularity by exact zeros on R's diagonal, so a diagonal of rounding size gives a large solution.
