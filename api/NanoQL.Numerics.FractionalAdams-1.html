The fractional Adams-Bashforth-Moulton predictor-corrector scheme for the fractional initial value problem D^α y(t) = f(t, y(t)), y(0) = y₀, α in (0, 1], D^α the Caputo derivative; at α = 1, the classical one-step Adams-Bashforth-Moulton method.

Remarks

QuantLib's real weights multiply the values componentwise, as C++ multiplies a std::complex by a real. The kernel's memory makes the cost O(N²) in the number of steps.

Immutable and thread-safe: it holds only its order, and each solve works on its own arrays.

Reference: K. Diethelm, N. J. Ford, A. D. Freed, A Predictor-Corrector Approach for the Numerical Solution of Fractional Differential Equations, Nonlinear Dynamics 29, 3-22 (2002).
