A latent model's factor sampler by copula inversion: each draw of a uniform sequence generator, every factor's cumulative distribution inverted by the policy. QuantLib's default LatentModel::FactorSampler<USNG>.

Remarks

A mutable working type (§2.7): each draw changes it, and it isn't thread-safe. A draw returns a view of its buffer, valid until its next draw, of weight 1, as QuantLib's. Its seed constructor is Create<TCopula, TInitTraits, TUsng>(TCopula, long), a seed in [1, 4294967295] with no default, where QuantLib's defaults to 0, the clock; a generator given instead is copied. QuantLib's two specializations by generator type are BoxMullerFactorSampler<TUrng> and PolarStudentTFactorSampler<TUrng>, chosen by the caller.
