SphereCylinderOptimizerClosest(double, double, double, double, double, double, int, double, double)

The point of the intersection of the sphere and the cylinder closest to Z: Z's projection where no iteration is asked, a golden-section search otherwise.

public static double[] SphereCylinderOptimizerClosest(double r, double s, double alpha, double z1, double z2, double z3, int maxIterations, double tolerance, double finalWeight = 1)

Parameters

r double

The sphere's radius, positive.

s double

The cylinder's radius; a negative one is 0.

alpha double

The cylinder centre's first coordinate, positive.

z1 double

Z's first coordinate.

z2 double

Z's second coordinate.

z3 double

Z's third coordinate.

maxIterations int

The search's iterations at most; 0 for the projection.

tolerance double

The search's interval at which it stops.

finalWeight double

The third coordinate's weight in the distance.

Returns

double[]

A new array of the point's three coordinates.

Exceptions

ArgumentException

The radius or the centre's coordinate isn't positive.

ArgumentOutOfRangeException

maxIterations is negative.

NanoQLException

The intersection is empty.
