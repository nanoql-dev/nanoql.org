Remarks

QuantLib's functions whose date defaults to Date(), read as the global evaluation date, take the context after QuantLib's parameters without a default, and the date as a nullable after it: the context's evaluation date is read only when the date is null.

A method of this class is named Date, which hides the type inside it, so the class writes the type NanoQL.Time.Date.
