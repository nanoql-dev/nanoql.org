Remarks

Immutable, and an extension point: a type that needs a finer match than its atomic type derives from it, as FailureToPay does. The match methods are strict: an event implied by another isn't matched; the event classes implement such hierarchies.

Equality is QuantLib's: two types are equal when their atomic types and restructuring types are, whatever a derived type adds, since equality indexes the probability curves. It is sealed, so every subclass compares the same way.
