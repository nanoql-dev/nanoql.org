A multi-model process for hybrid products: its constituents' states stacked, their factors correlated across models by a derived class's cross-model correlation.

Remarks

An extension point, as in QuantLib: a derived class gives the cross-model correlation, whether it depends on the state, the numeraire and the hooks around each step. The constituents are fixed at construction.

Each step builds its correlation from the constituents' standard deviations at the step's state, where QuantLib caches it by (t₀, dt) when the derived class says the cross-model correlation doesn't depend on the state (jointstochasticprocess.cpp:189-268): its key leaves out the state the constituents' deviations read, so a later path at the same step can reuse an earlier path's matrix, and no class in QuantLib derives the process to measure what the cache pays.
