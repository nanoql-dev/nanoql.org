A preconditioner by the incomplete LU factorisation ILU(k) of a sparse matrix (Saad 1996, Iterative Methods for Sparse Linear Systems): A ≈ L·U, the fill kept to the given level, applied by a forward and a backward solve.

Remarks

Immutable: the factors are computed at construction; L() and U() return copies, and Apply(Vector) returns a new vector, the form of the Krylov solvers' preconditioner.

QuantLib records each new entry's fill level from the levels' nonzero entries by the entries' rank among the row's nonzero values, which a value that cancels to 0 shifts, so a later row reads another entry's level; here each entry's level is its own (a documented divergence; QuantLib's factors wherever no entry cancels). QuantLib's reads of U also insert zero elements where none is stored, past its last column too, which changes U's structure but not its values; here they insert nothing. A row that keeps no entry on or right of its diagonal, where QuantLib's elimination loop never ends, is refused, and Apply(Vector) refuses a vector not of the matrix's size, which QuantLib reads unchecked.
