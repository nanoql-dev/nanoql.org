Class CTSMMCapletCalibration

Namespace
NanoQL.Models

A coterminal swap market model's calibration to caplet volatilities, the swaption volatilities given: each pass fits the swap rates' pseudo-roots to the caplet volatilities in use, then rescales those by the market's over the model's, until the caplets' root-mean-square error is within the tolerance or the passes run out.

Remarks

Immutable: it holds the inputs, a copy of the curve state given, and Calibrate(int, int, double, int, double) returns the results, where QuantLib's calibration changes itself; QuantLib's "not successfully calibrated yet" has no state to guard. Each pass's fit is the derived calibration's CalibrationImpl(int, int, double, ReadOnlySpan<double>), QuantLib's calibrationImpl_. An extension point, as in QuantLib.

A count below zero, which QuantLib's unsigned Natural wraps, is refused.
