The algorithm used for a matrix's pseudo square root where the matrix isn't positive semi-definite: QuantLib's SalvagingAlgorithm::Type, with its numeric values.

public enum SalvagingAlgorithmType

Fields

Higham = 4

Higham's nearest correlation matrix; only for correlation matrices.

Hypersphere = 2

Hypersphere: the spectral root, optimized on the hypersphere where an eigenvalue is negative.

LowerDiagonal = 3

Lower diagonal: the spectral root, optimized as a lower-diagonal root where an eigenvalue is negative.

None = 0

No salvaging: the matrix must be positive semi-definite.

Principal = 5

The principal (symmetric) square root.

Spectral = 1

Spectral: negative eigenvalues set to zero.
