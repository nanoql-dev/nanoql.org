LaplaceInterpolation(Matrix, IReadOnlyList<double>?, IReadOnlyList<double>?, double, int)

A copy of a matrix with its missing values Laplace-interpolated, the rows on the y grid and the columns on the x grid: QuantLib's laplaceInterpolation, which fills the matrix in place.

public static Matrix LaplaceInterpolation(Matrix A, IReadOnlyList<double>? x = null, IReadOnlyList<double>? y = null, double relTol = 1E-06, int maxIterMultiplier = 10)

Parameters

A Matrix

The matrix.

x IReadOnlyList<double>

The columns' grid; empty for 0, 1, 2, ..., an equidistant one.

y IReadOnlyList<double>

The rows' grid; empty for 0, 1, 2, ..., an equidistant one.

relTol double

BiCGstab's relative tolerance.

maxIterMultiplier int

BiCGstab's iterations, per grid point.

Returns

Matrix

The filled copy.

Remarks

A missing value is NaN, where QuantLib's matrix holds Null<Real>().

Exceptions

NanoQLException

BiCGstab fails to converge, with its text.

ArgumentException

x or y is given with another length than A's columns or rows, where QuantLib reads past one or the other.
