Remarks

Immutable: WithParams(Vector) returns a new model whose process is rebuilt from the parameters, QuantLib's generateArguments, on the process's curves, spot and days per year (and QuantLib's default discretization). Besides each argument's own constraint the parameters satisfy β + γ ≥ 0 (GJRGARCHModelVolatilityConstraint).

Reference: Glosten, L., Jagannathan, R., Runkle, D., 1993. Relationship between the expected value and the volatility of the nominal excess return on stocks. Journal of Finance 48, 1779-1801.
