Remarks

Constructible, as QuantLib's is: new Exercise(type) holds no dates, so LastDate() refuses it, and Date(int) and DateAt(int) refuse every index. The derived exercises give their dates to the protected constructor, where QuantLib's assign its protected dates_.

An extension point, as in QuantLib: rebated and swing exercises derive from it and from BermudanExercise. Date(int) is a method, so inside this class the Date type is written NanoQL.Time.Date.
