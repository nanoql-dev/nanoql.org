Remarks

QuantLib's implementation is a proxy for the standard library's generator: a 48-bit subtract-with-carry engine (std::subtract_with_carry_engine<std::uint_fast64_t, 48, 10, 24>) under a discard-block engine that keeps r of every p draws, QuantLib's template parameters, here the protected constructor's. Its numbers are those of MSVC's standard library, which built the Python wheel and the harness. For more detail see M. Luescher, A portable high-quality random number generator for lattice field theory simulations, Comp. Phys. Comm. 79 (1994) 100.

A mutable working type: each draw changes the generator, and it is not thread-safe. Its seed is explicit, in [1, 4294967295], with no default, where QuantLib's defaults to 19780503: the standard's seeding takes 0 as that default, and reduces a seed modulo 2147483563 through its linear congruential seed sequence, so seeds that differ by that modulus draw one sequence, and a multiple of it draws the sequence of seed 1, in QuantLib as here.
