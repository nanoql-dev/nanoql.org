Validation

Checked against QuantLib 1.44 on Windows x64.

  • The vectors: 3,348,122 reference outputs in 1,169 vector files, of which four files and 39,887 outputs check QLNet's additions against QLNet 1.13.2. Each output agrees within a relative 1e-10 of the larger of the two values and the output's scale (an amount's is its notional), except 4,854 (0.14%) held to a documented looser tolerance.
  • The tests: QuantLib's own tests, ported at QuantLib's tolerances.
  • The types: 2,265 of the 2,266 public types with executable code are run by a QuantLib-checked test, QLNet's additions by a QLNet-checked one. The one apart, FactorReductionFunctions, every output of which is QuantLib's defect fixed, is checked by its own tests. 319 more are listed apart, 291 with no executable code and 28 own-tested (22 of them extensions, five experimental and one a term structure), and three are equality-only. 89.0% of the ported lines are covered.
  • The divergences: 738 documented divergences, 722 from QuantLib and 16 from QLNet, each with its own test class.

Measured on commit cf3446031bcfc45ec7e23c2a659cba45287a3758: 8,729 tests, every one passing, and 60,928 vector cases.

These pages are built from commit 1e5d9ca, whose library code and vectors' counts are the same as the measured commit's.
